## 哲学定位

**格局 = 命局的"宪法"**——决定喜忌走向、用神排除范围、大运 / 流年的"赛道"性质。

为什么古典格局优先？
1. **千年验证胜过现代"快速法则"**——印多反忌 / 身弱用印这类规则只在普通命局上有效；遇古典格局必须先识别
2. **格局是结构性诊断**——不是经验法则，是建立在五行生克 + 月令气数 + 干支配合的严密推理上
3. **R44 突出矛盾扫描 + R45 古典格局识别** = 议会的"先抓中心 → 再用古法"双步法

**与现代规则的关系**：
- 命局**构成古典格局** → 用该格局的特定喜忌
- 命局**不构成古典格局**（普通命局）→ 才走 R1 三维扶抑 + R11 排除法
- 古典格局 ≠ 一定贵命——格局是**结构识别**，贵贱是**结构 × 大运 × 流年 × 反身性选择**的复合结果

**脱毒约束**（每个格局描述都遵守）：
- ❌ "X 格主大富贵" / "Y 格命主早夭"
- ✓ "X 格的结构倾向是 Z，在适配大运下更容易展开 Z，在逆运下张力是 W"
- 永远描述**结构倾向 + 张力 + 代价**，不描述**事件**

## 通用判定方法论（所有格局共用）

### 成格的三步走

```
Step 1: 月令本气透干？
  ├─ 是 → 月令正格立（如月支申本气庚 + 庚透 = 偏财格 / 财格）
  └─ 否 → Step 2

Step 2: 月令藏干透干？
  ├─ 是 → 月令次格立（如月支寅藏甲丙戊，丙透 = 食神格 / 比劫格视日主）
  └─ 否 → Step 3

Step 3: 特殊格局扫描
  ├─ 化气格条件？（日主与紧邻干合化）
  ├─ 专旺格条件？（某五行单一极旺）
  ├─ 从格条件？（日主极弱顺势从他）
  └─ 都不成 → 走 R1 三维扶抑判普通命局
```

### 破格的统一判定原则

**破格 = 成格的关键条件被冲、合、克破坏，使格局失效或减效**。统一判据：

| 破格类型 | 判据 | 修复条件 |
|---|---|---|
| **冲破** | 月令支被紧邻冲 | 有合解冲、有通关五行 → 部分修复 |
| **合化** | 关键透干被合住 | 看合化神是否仍助格局 |
| **克破** | 关键透干被克 | 有印护、有通关 → 部分修复 |
| **混杂** | 格局喜神 + 忌神同透 | 一清一浊 → 看清浊取舍 |

**修复不等于完全无伤**——破而能修是"格损不破"，全破是"格不成"。

### 临界判定（"假格" / "败格" / "破格"）

| 状态 | 含义 | 喜忌处理 |
|---|---|---|
| **成格** | 三条件全满足 | 走该格喜忌 |
| **假格** | 形似但根缺 / 化神不真 | 部分按该格读，临界场景以 R1 复判 |
| **败格** | 成格后被破，能修复但有伤 | 该格喜忌 + 警惕修复点 |
| **破格** | 成格后被破，无法修复 | 退回普通命局，走 R1 + R11 |

### 子平 vs 盲派分歧（详 R52 + R56）

| 维度 | 子平 | 盲派 |
|---|---|---|
| 格局的本质 | 命局的"结构形态" | 命局的"做功路径" |
| 重点 | 格局成不成 + 喜忌方向 | 谁做功 + 我宫怎么调动 |
| 临界判定 | 严判（假格不算格）| 灵活（结构倾向就有效）|
| 看用神 | 顺格局喜忌 | 看"我宫能调动什么" |

**议会立场**：两派**并陈不折中**——子平定结构方向，盲派增精度（详 R52）。

## 一、十大正格（月令格局）

> **十大正格 = 月令本气或藏干透出的十神所立之格**。是子平格局法的核心 —— 任何普通命局先扫月令立正格，再看是否需要复合格局或特殊格局接管。

### 1. 正官格

**成格条件**（三选一）：
- 月支本气为正官（如阳干日主见阴干官 = 阳日主月支正官位）
- 月支藏正官透干，且不被合化
- 月支会成正官局（地支三合或半合成官星五行）

**破格条件**：
- **伤官见官**——天干或地支伤官紧邻正官（除非有印通关）
- 正官被合化为他物（如官星被日主合走改化）
- 正官被冲（紧邻冲 → 严重破，遥冲 → 轻破）
- 正官被劫财夺（命局劫财重 + 正官失制）

**典型组合**：
- 月正官透 + 印护官 + 财生官 = "**官印相生**"或"**财官印三宝**"
- 古典原文（《子平真诠》）："**正官者，月令之正官也，正官无伤为最贵**"

**临界判定**：
- 正官**虽透但坐绝**（如丁火日主月正官壬透坐午）→ 假官格，依旺衰复判
- 正官**与日主太近被合**（如甲日主月支辛官透但与日主邻支合走）→ 看合化方向

**喜忌方向**：
- **喜**：印（化官生身）+ 财（生官）+ 身有根
- **忌**：伤官见官 + 七杀混官（清浊不分）+ 劫财夺财

**现代脱毒意象**：
- 倾向**对制度、规则、权威**有天然亲和——但能否在体制内展开取决于身能否担官 + 大运配合
- 不是"必当官"——是"对秩序结构的心理共振"

**常见误判**：
- ❌ 看到月支正官就立官格——**没查藏干透干 + 是否被合化**
- ❌ 官杀混杂直接说"格不清"——**先看清浊取舍**（去杀留官 vs 去官留杀）

**接口规则**：R1 + R11（用神排除） / R19（调候微调） / R20 v2（冲克破格判定） / R46（合化破格判定）

### 2. 七杀格（偏官格）

**成格条件**：
- 月支本气为七杀
- 月支藏七杀透干 + 身能担
- 月支会成七杀局

**破格条件**：
- 七杀过重无制——身弱杀重无印化、无食制 → 不成"杀格"反成"病"
- 七杀被合化（如乙庚合走七杀）
- 七杀被食神制过头（变成"制杀太过"）

**典型组合**：
- 七杀格三大良性变体：
  - **杀印相生**（详 R55）：杀重 + 印重 + 印化杀 + 印必透 — 古典原文："**必须庚透干头，则庚禄居申**"
  - **食神制杀**（详 R55）：食神重 + 七杀重 + 食神制杀 + 身能担食神
  - **羊刃驾杀**（月刃格变体）：羊刃 + 七杀 → 阳刃驾杀

**临界判定**：
- 杀**重于身**但**无印无食**：是"杀重身轻"破格，**不是**七杀格——按 R55 杀重身轻处理
- 杀**与官混**：先做清浊取舍（详 R56 SOP）

**喜忌方向**：
- **喜**：印（化杀）/ 食神（制杀）/ 比劫（抗杀）
- **忌**：杀再重 + 财（财生杀）+ 印被冲克

**现代脱毒意象**：
- 倾向**对压力、挑战、强对抗环境**有天然吸附力——可以是创业 / 高强度行业 / 军警等
- 不是"煞气重命苦"——是"通过压力激发动力的结构倾向"

**常见误判**：
- ❌ 看到七杀就说"凶"——**七杀有制就是用，无制才是病**
- ❌ "印化杀"和"食制杀"混用——**两者方法论不同**：印化是化解能量、食制是反击对抗

**接口规则**：R23（魁罡冲）/ R31（寄禄判杀力）/ R51（大运流年触发杀的动态）/ R55（复合格局深化）

### 3. 正印格

**成格条件**：
- 月支本气为正印
- 月支藏正印透干
- 月支会成印局

**破格条件**：
- **财破印**——天干财星紧邻正印（除非有官杀通关）
- 印过盛反成病（详 R55 "印多反忌" 的临界判定）
- 印被冲

**典型组合**：
- 印格 + 官杀生印 = **官印相生**
- 印格 + 比劫帮身 = **印比为用**

**临界判定**：
- 印**虽透但被财紧邻克**：假印格，依实际财印博弈复判
- 印**过盛**（重透 + 多根）+ **身已极强**：才是"印多反忌"——但前提是七杀不重（详 R11 v2 / R55）

**喜忌方向**：
- **喜**：官杀（生印）+ 比劫（帮身）+ 身能担
- **忌**：财破印 + 印再重（身已强情况下）

**现代脱毒意象**：
- 倾向**学习、思考、研究、师承、母性 / 庇护型关系**
- 不是"必有文凭学位"——是"通过吸收知识 / 受庇护成长的结构倾向"

**常见误判**：
- ❌ "印多就是忌"——**先看七杀状况**，杀重时印不是过盛，是化杀的工具
- ❌ 直接套"身弱用印"——**没查印是否被破**

**接口规则**：R11 v2（印多反忌的边界）/ R55（杀印相生 / 财官印三宝）

---

### 4. 偏印格（枭神格）

**成格条件**：
- 月支本气为偏印
- 月支藏偏印透干

**破格条件**：
- **偏印夺食**——食神为用时偏印克食（古名"枭神夺食"）
- 偏印被冲、被克

**典型组合**：
- 偏印 + 七杀同透 = 偏印化杀（与正印化杀相似但更直接、能量更"野")
- 偏印 + 财星制偏印 = **财制枭** —— 古典认为偏印格常以财制枭为美

**临界判定**：
- 偏印为用 vs 偏印为忌：身弱 + 杀重 → 偏印为用；身强 + 食神为用 → 偏印为忌（夺食）

**喜忌方向**：
- **喜**（身弱时）：官杀生印 + 偏印化杀
- **喜**（身强时）：财制枭 + 食神泄秀
- **忌**：偏印夺食（除非食神已过盛）

**现代脱毒意象**：
- 倾向**非主流学习、自学、神秘学 / 玄学、独特技能、灵感型思维**
- 偏印 vs 正印的区别：正印是"标准师承"，偏印是"野路子 / 自学成才 / 跨领域"

**常见误判**：
- ❌ 偏印 = 凶——**只在夺食时凶**
- ❌ 看到偏印就说"克母"——**这是命书旧说，现代脱毒禁用此类预测**

**接口规则**：R55（食神制杀 vs 偏印夺食的临界）

---

### 5. 食神格

**成格条件**：
- 月支本气为食神
- 月支藏食神透干 + 身能担食神

**破格条件**：
- **偏印夺食**——枭神紧邻克食
- 食神被合化为他物
- 食神坐绝、坐墓而无救

**典型组合**：
- **食神制杀**（详 R55）：食神 + 七杀 + 身能担 + 食神有根 → 最经典的食神格变体
- **食神生财**：食神 + 财 → 平稳进财结构
- **食神泄秀**：身强日主 + 食神泄气 → 创造性输出

**临界判定**：
- 食神**虽透但坐墓**（如丁日主月食神己坐戌墓）→ 假食神格，做功能力打折
- 食神**与伤官混**（食伤混杂）→ 先取清浊（详 R56）

**喜忌方向**：
- **喜**：食神有根 + 财星泄食 + 身能担
- **忌**：偏印夺食 + 食神被合化 + 食神制杀过头

**现代脱毒意象**：
- 倾向**创造、输出、温和表达、技艺型工作、餐饮 / 教育 / 写作**
- 食神 vs 伤官的区别：食神是"温和创造"，伤官是"叛逆突破"

**常见误判**：
- ❌ 食神制杀就一定贵——**必须身能担食神**，不然是制杀太过
- ❌ "食神生财"无条件吉——**身弱时食神也耗身**

**接口规则**：R55（食神制杀深化）/ R34（合制做功）

### 6. 伤官格

**成格条件**：
- 月支本气为伤官
- 月支藏伤官透干 + 身能担

**破格条件**：
- **伤官见官**——伤官紧邻正官（除非有印通关变成"伤官佩印"，详 R55）
- 伤官被合化
- 伤官重而身轻无救

**典型组合**：
- **伤官佩印**（详 R55）：伤官 + 印 → 印护身 + 印制伤官的张力 → 最经典的伤官格变体
- **伤官生财**：伤官 + 财 → 才华变现结构
- **伤官伤尽**（古名）：伤官重 + 官全无 → 单纯走伤官路线，反而清

**临界判定**：
- 伤官**虽透但被合化**：假伤官格
- 伤官**与正官同透但有印**：升级为"伤官佩印"（不是单纯伤官见官）

**喜忌方向**：
- **喜**：印（护身 + 制伤）+ 财（泄伤）+ 身有根
- **忌**：伤官见官（无印）+ 比劫（劫财夺财）+ 伤官再重

**现代脱毒意象**：
- 倾向**叛逆、突破规则、艺术、表演、革新型技术、表达型职业**
- 伤官的本质是"对权威的本能抵触" —— 在体制内难展开，在创造性领域有优势

**常见误判**：
- ❌ 伤官见官就是凶——**有印通关就是伤官佩印**（详 R55）
- ❌ "女命伤官无父" / "女命伤官克夫"——**这是封建命书旧说，现代脱毒强制禁用**

**接口规则**：R55（伤官见官 / 伤官佩印深化）

### 7. 正财格

**成格条件**：
- 月支本气为正财
- 月支藏正财透干 + 身能任财

**破格条件**：
- **劫财夺财**——比劫紧邻正财（除非有官杀制劫）
- 正财被合化为他物
- 财多身弱（身不能任）

**典型组合**：
- **财生官**：正财 + 正官 → 财官相生（贵气结构）
- **食神生财**：食神 + 正财 → 平稳进财
- **财官印三宝**（详 R55）：财 + 官 + 印同透 → 最经典的正格组合

**临界判定**：
- 正财**虽透但坐绝**：假财格
- 财**多于身**（财多身弱）：**不是**正财格，是"财多身弱"的破格——按 R55 处理

**喜忌方向**：
- **喜**：食伤生财 + 官杀制劫保财 + 身有根能任
- **忌**：劫财夺财 + 财再重（身已弱）

**现代脱毒意象**：
- 倾向**稳定收入、固定资产、节俭管理、长期客户、传统行业**
- 正财 vs 偏财的区别：正财是"工资 / 固定合约"，偏财是"投资 / 副业 / 流动收入"

**常见误判**：
- ❌ 财多就富——**必须身能任**，否则财多身弱反成病
- ❌ "男命正财格婚姻好"——**婚姻是关系议题，不是单纯财星位置可以判**

**接口规则**：R5（劫财重则财需官制）/ R6（偏财坐日支）/ R55（财滋弱杀 / 财官印三宝）

### 8. 偏财格

**成格条件**：
- 月支本气为偏财
- 月支藏偏财透干 + 身能任

**破格条件**：
- 劫财夺偏财（更严重——偏财本性流动易失）
- 偏财被合化
- 财多身弱

**典型组合**：
- 偏财 + 食神 = **偏财坐食伤**——典型的"非工资收入 + 创造性"
- 偏财 + 七杀 = **财滋弱杀** / **偏财养杀**（详 R55）

**临界判定**：
- 偏财**虽透但流动性强**（坐沐浴 / 坐死绝）→ 财来得快去得快
- 偏财**坐日支**：详 R6——是"财从配偶 / 投资 / 非固定来源"的结构信号

**喜忌方向**：
- **喜**：食伤生偏财 + 官杀制劫保财 + 身有根
- **忌**：劫财夺财 + 比肩分财

**现代脱毒意象**：
- 倾向**投资、副业、流动性收入、非传统行业、外部资源（异性 / 客户 / 合作方）**
- 偏财格命主常常"靠人脉 / 异性缘 / 机会"赚钱，不是靠固定职位

**常见误判**：
- ❌ 偏财格就是花花公子——**这是封建命书旧说，禁用**
- ❌ "偏财坐日支必从异性获财"——**是结构倾向不是事件预测**

**接口规则**：R6（偏财坐日支）/ R34（合制做功 — 财被合住的读法）

### 9. 建禄格

**成格条件**：
- **日干禄在月支** —— 如甲日主月寅、乙日主月卯、丙日主月巳、丁日主月午、戊日主月巳、己日主月午、庚日主月申、辛日主月酉、壬日主月亥、癸日主月子

**破格条件**：
- 月禄被冲（如甲日主寅月遇申冲）
- 月禄被合化为他物

**典型组合**：
- 建禄格本身**身较旺**——必须配官杀财来制 / 泄
- **建禄用官**：身禄 + 官杀 → 稳定结构
- **建禄用财**：身禄 + 财 + 食伤生财 → 通过财显化身的强势

**临界判定**：
- 建禄格 vs 月刃格：阳干在月旺位 = 建禄；阴干在月旺位 = 月刃（用法不同）
- 建禄**被冲**：是"破禄"——格损但常能修

**喜忌方向**：
- **喜**：官杀（制身禄）+ 财（泄身禄）+ 食伤（生财）
- **忌**：再加比劫（身已旺）+ 印（生身添堵）

**现代脱毒意象**：
- 倾向**独立性强、自我中心、有主见、不易依赖他人**
- 建禄格命主常**白手起家**或**靠自身能力独立展开**——结构上"靠自己"

**常见误判**：
- ❌ 建禄格 = 必有大事业——**身禄旺只是底盘，能否展开看用神 + 大运**
- ❌ 建禄就是身强——**还要看其他根 + 透干**

**接口规则**：R31（寄禄）/ R32（同气借禄）

### 10. 月刃格（羊刃格）

**成格条件**：
- **日干阳刃在月支** —— 甲日主月卯、丙日主月午、戊日主月午、庚日主月酉、壬日主月子
- 阴日主在月旺位 = 月刃（如乙日月寅为禄，乙日月午为食伤；阴干"刃"概念不同，常归入建禄变体）

**破格条件**：
- 月刃被冲（"刃冲"特别凶）
- 月刃被合化

**典型组合**：
- **羊刃驾杀**：月刃 + 七杀 → 用七杀制刃的能量 → 典型的"暴力但有效"结构
- **羊刃合杀**：月刃 + 七杀合化为他物 → 化解
- **羊刃见官**：月刃 + 正官 → 张力大（古典忌但可用印通）

**临界判定**：
- 羊刃**身已极旺**：刃是工具，必须有杀 / 官 / 食伤来用
- 羊刃**身偏弱**：罕见，但出现时刃是"负担"不是工具

**喜忌方向**：
- **喜**：七杀（驾刃）+ 官（制刃，需印通）+ 食伤（泄刃）
- **忌**：再加比劫 + 印（身已旺）

**现代脱毒意象**：
- 倾向**强势、果断、爆发力、不易妥协、极端化倾向**
- 羊刃格命主**两极分化**——驾驭得当是"将才 / 创业者 / 高强度行业"；驾驭不当是"易冲突 / 短视"

**常见误判**：
- ❌ 羊刃就是凶——**驾杀就是大用**，"羊刃驾杀" 是古典最贵命格之一
- ❌ "阳刃必克妻"——**封建旧说，禁用**

**接口规则**：R23（羊刃 + 魁罡的复合判定）/ R55（羊刃驾杀深化）

## 二、化气格（五种合化成局）

> **化气格 = 日主与紧邻天干合化为另一五行**——是罕见但极特殊的命局形态。一旦真化，命局五行属性彻底改变，按"专一行"读，喜忌反转。
> **化气格难真**——多数情况下是"假化"或"合而不化"。**真化要求三严**：化神得月令 + 化神透干旺 + 无破。

### 化气格的通用成格条件

**三严判定**（详 R50 天干五合）：

1. **化神得月令**——月支为化神五行 / 化神的禄旺地 / 化神的长生地
2. **化神透干旺**——化神在天干透出，且根多力强，不被克
3. **无破坏**
   - 合的两干**紧邻**（不能隔字）
   - 没有第三个字争合（妒合）
   - 化神不被原局其他干冲克

**假化的两种情况**：
- **假化得用**：化神虽不真，但化神方向就是命局用神 → 仍按化气格喜忌但减效
- **假化失用**：化神既不真，化神方向也不是用神 → 退回普通命局

---

### 1. 化木格（丁壬合化木）

**成格条件**：
- 日主丁，紧邻干（月干或时干）为壬；或日主壬，紧邻干为丁
- 月令为木（寅 / 卯 / 亥即木的长生 / 旺 / 库 / 三合木局成）
- 木气透干 + 无金克木

**破格条件**：
- 月令非木地（如月令是申酉戌金地）→ 化神无根 → 不化
- 命局**庚辛金透干**克木 → 破化
- 第三个丁或壬出现 → 妒合 → 化力大降

**典型组合**：
- 丁壬合化木 + 月令亥卯未三合木局 + 甲乙木透 = 真化木格
- 命主转化为"全木命"——按曲直格类似的喜忌读（详专旺格曲直格）

**喜忌方向**（真化后）：
- **喜**：水（生木）+ 木（同党）+ 火（泄秀木）
- **忌**：金（克木）+ 土（耗木）

**现代脱毒意象**：
- 真化命主**人格底色转向木性**——成长、扩展、仁义、文化、学术、教育、创意
- 化气格命主常有"性格转变期"——化神得运时是命主的真正展开期

**常见误判**：
- ❌ 看到丁壬透就说化木——**月令必须是木地**
- ❌ 假化按真化读——**假化要减效**

**接口规则**：R50（天干五合 + 真化判定流程）/ R47（三合木局支持化神）

---

### 2. 化火格（戊癸合化火）

**成格条件**：
- 日主戊，紧邻干为癸；或日主癸，紧邻干为戊
- 月令为火（巳午未即火的长生 / 旺 / 库 / 三合火局成）
- 火气透干 + 无水克火

**破格条件**：
- 月令非火地（如月令为亥子丑水地）→ 化神无根 → 不化
- 命局**壬癸水透干**（除被合的癸）→ 克火破化
- 妒合（双戊或双癸）→ 化力降

**典型组合**：
- 戊癸合化火 + 月令寅午戌三合火局 + 丙丁火透 = 真化火格
- 古名："**戊癸合化火，化为火格**"

**喜忌方向**（真化后）：
- **喜**：木（生火）+ 火（同党）+ 土（泄秀火）
- **忌**：水（克火）+ 金（耗火）

**现代脱毒意象**：
- 真化命主**人格底色转向火性**——表达、领导、文娱、创新、能源、活力型行业
- 戊癸合古典称"无情之合"（阳老 + 阴老）——真化命主常显"晚成 / 沉稳 / 后劲足"

**常见误判**：
- ❌ 戊癸合就说化火——**月令必须火地**
- ❌ "无情之合" 等同负面——**只是古名，不代表凶**

**接口规则**：R50 / R47

## 三、专旺格（五行单一极旺）

> **专旺格 = 命局五行单一极旺 + 日主属于该五行 + 一气不杂**——本质是"日主与命局同党"的极端形态。喜忌**顺其性**——不抗反顺，让单一五行充分展开。
> 五个专旺格分别对应五行：曲直（木）/ 炎上（火）/ 稼穑（土）/ 从革（金）/ 润下（水）。

### 专旺格的通用成格条件

1. **日主属于某五行** —— 如曲直格日主必甲乙木
2. **该五行单一极旺**——满足以下任一：
   - 地支**三合或三会该五行局**（如寅午戌 / 巳午未火局）
   - 该五行**地支占 3 支以上 + 天干透 2 个以上**
   - 月令为该五行**禄旺帝旺地**
3. **无克神** —— 命局没有强力克日主五行的字（克神微弱可忽略）
4. **不杂他气** —— 命局没有显著的他五行干扰

### 专旺格的核心特征

- **本质**："**日主就是命局**"——所有能量集中在一个五行方向
- **喜忌反转**：不要克泄耗（如曲直格忌金克），要顺生顺泄（喜水生木 + 火泄秀）
- **罕见**：真专旺格在实操中很少，多数是假专旺（有微弱克神或杂气）

---

### 1. 曲直格（木专旺）

**成格条件**：
- 日主甲或乙
- 地支三合木局（亥卯未）或三会东方（寅卯辰）
- 木气**充满命局**（多个木干 + 多木支）+ 无金克

**破格条件**：
- 命局**庚辛金透干**克木 → 破
- 木局被冲（如亥卯未 + 申冲寅 / 巳冲亥）→ 破

**典型组合**：
- 甲日 + 亥卯未三合 + 乙木透 + 无金 = 真曲直格
- 古名："**曲直者，木之曲而能伸**"——木的延展性

**喜忌方向**：
- **喜**：水（生木）+ 木（同党）+ 火（泄秀）
- **忌**：金（克木破格）+ 土（耗木）

**现代脱毒意象**：
- 倾向**长期成长、教育文化、学术研究、生命科学、创意产业、海外发展**
- 曲直格命主**常有学者气 / 文化味 / 慈悲心** —— 木的仁义之性

**常见误判**：
- ❌ 看到亥卯未就说曲直——**还要日主是木 + 无金**
- ❌ 假曲直按真专旺读——**有微金时仍是普通命局**

**接口规则**：R47（三合木局）/ R45（专旺格优先）

---

### 2. 炎上格（火专旺）

**成格条件**：
- 日主丙或丁
- 地支三合火局（寅午戌）或三会南方（巳午未）
- 火气充满命局 + 无水克

**破格条件**：
- 命局**壬癸水透干**克火 → 破
- 火局被冲（如寅午戌 + 子冲午）→ 破

**典型组合**：
- 丙日 + 寅午戌三合 + 丁火透 + 无水 = 真炎上格
- 古名："**炎上者，火之炎而上**"

**喜忌方向**：
- **喜**：木（生火）+ 火（同党）+ 土（泄秀）
- **忌**：水（克火破格）+ 金（耗火）

**现代脱毒意象**：
- 倾向**领导、表达、文娱、能源、热门行业、高曝光职业**
- 炎上格命主**常有热情 / 影响力 / 公众形象**——火的发散之性

**常见误判**：
- ❌ 双午 + 戌就说炎上——**还要日主丙丁 + 无水**
- ❌ "炎上格命短"（古书旧说）——**封建命书旧说，现代脱毒禁用**

**接口规则**：R47 / R45

**验证**：Case 006（戊辰/戊午/丙午/戊戌）—— 月日双午 + 时戌火局缺寅 + 大运甲寅补寅后**接近**炎上格倾向，但年支辰是水库带湿土 → 是"假炎上"或"火土同党"结构（详 R47 拱合补字）

**成格条件**：

- 稼穑格命主**常有承载力 / 包容性 / 平衡感**——土的中和之性

**常见误判**：

- **喜**：金（生水）+ 水（同党）+ 木（泄秀）
- **忌**：土（克水破格）+ 火（耗水）

**现代脱毒意象**：
- 倾向**智慧灵活、信息 / 流通 / 海运 / 贸易 / 互联网、艺术 / 直觉型职业**
- 润下格命主**常有变通 / 流动性 / 适应力**——水的流变之性

**常见误判**：
- ❌ 双子 + 亥就说润下——**还要日主壬癸 + 无土**
- ❌ "水多漂泊"等同凶——**水的流动性是结构倾向不是判决**

**接口规则**：R47 / R45

## 四、从格（日干极弱顺势从他）

> **从格 = 日干极弱无根 + 命局某一行或几行极旺 → 日干不抗反顺，从该旺行**。本质是"日主放弃自己 + 顺势从他"的极端形态。
> 从格的喜忌**与扶抑派完全相反**——身极弱不用印，反而顺势走该旺行的喜忌。
> **从格 vs 假从**：真从必须无根（包括天干印比、地支墓库微根都没有）；假从有微根 → 不能真从，按"身弱"普通命局处理。

### 从格的通用成格条件

1. **日干极弱**——天干无比劫 + 无印；地支无禄、刃、长生（连墓库藏干都不能透出）
2. **某五行或几行极旺**——满足以下任一：
   - 单一五行成局（三合 / 三会）
   - 单一五行**地支占 3 支以上 + 天干透 2 个以上**
   - 多五行混杂但都是**克 / 泄日主**的（从势格）
3. **无救应**——没有任何来救日主的字

### 假从的临界

- 日主有**微根**（如地支墓库藏干透天）→ 不真从
- 处理：仍按身弱普通命局走 R1 + R11（弱身用印 / 用比劫）
- **关键边界**：假从最容易被误判——见到日主弱就说从，是初学者常错

---

### 1. 从财格

**成格条件**：
- 日干极弱无根
- 命局**财星极旺**（地支三合财局或财占绝对多数 + 财透干旺）
- 无印比帮身

**破格条件**：
- 命局**有印通根**（即使微根）→ 不真从 → 退回身弱
- 命局**有比劫帮身**（即使微比）→ 不真从

**典型组合**：
- 甲乙木日 + 命局戊己土极旺（如四库全聚 + 戊己透）+ 无水印 + 无甲乙木根 = 真从财
- 古名："**从财者，从财而富**"

**喜忌方向**（从财后）：
- **喜**：财（同党）+ 食伤（生财）+ 官杀（顺势，因官杀克身但日主已弃身）
- **忌**：印（破财）+ 比劫（夺财）

**现代脱毒意象**：
- 倾向**与资本 / 资源高度同频** —— 命主与"财" 的领域共振
- 真从财命主**常有强财富吸附力**——结构上"以财为身"

**常见误判**：
- ❌ 看到日主弱 + 财多就说从财——**先查日主是否真无根**
- ❌ 从财格喜印——**完全相反**

**接口规则**：R1 v3.2（旺衰判定）/ R11 v2（用神排除）

---

### 2. 从杀格

**成格条件**：
- 日干极弱无根
- 命局**七杀极旺**（地支三合杀局 + 七杀透干旺）
- 无印化杀 + 无食制杀 + 无比劫抗杀

**破格条件**：
- 命局**有印**通根 → 不真从（变成杀印相生）
- 命局**有食神**通根 → 不真从（变成食神制杀）
- 命局**有比劫**通根 → 不真从

**典型组合**：
- 戊土日 + 命局甲乙木极旺（如亥卯未三合木局 + 甲乙透）+ 无火印 + 无戊己根 = 真从杀
- 古名："**从杀者，从七杀而贵**"

**喜忌方向**（从杀后）：
- **喜**：杀（同党）+ 财（生杀）+ 杀星根多
- **忌**：印（化杀破从）+ 比劫（抗杀）+ 食神（制杀）

**现代脱毒意象**：
- 倾向**与压力 / 挑战 / 权威环境高度共振**——结构上"以杀为身"
- 真从杀命主**常显高度执行 / 服从体制 / 在压力下展开能力**

**常见误判**：
- ❌ 杀多就说从杀——**先查是否真无根**
- ❌ 从杀格喜印——**完全相反**（印化杀就破了从）

**接口规则**：R55（杀印相生 vs 从杀的临界）

---

### 3. 从儿格（从食伤格）

**成格条件**：
- 日干极弱无根
- 命局**食伤极旺**（地支食伤局 + 食伤透干旺）
- 无印 + 无比劫（除非比劫帮食伤化食伤）

**破格条件**：
- 命局**有印**克食伤 → 不真从
- 食伤被合化为他物

**典型组合**：
- 甲木日 + 命局丙丁火极旺（如寅午戌三合火局 + 丙丁透）+ 无水印 + 无木根 = 真从儿
- 古名："**从儿者，从食伤而秀**"

**喜忌方向**（从儿后）：
- **喜**：食伤（同党）+ 财（顺泄食伤）+ 比劫（生食伤但勿过强）
- **忌**：印（克食伤）+ 官杀（克身但食伤抗官变成混战）

**现代脱毒意象**：
- 倾向**与创造 / 表达 / 输出高度共振**——结构上"以食伤为身"
- 真从儿命主**常显艺术 / 表达 / 自由职业 / 不受制度束缚的能力**

**常见误判**：
- ❌ 食伤多就说从儿——**先查日主是否真无根**
- ❌ 从儿格喜印——**完全相反**

**接口规则**：R55（食神制杀 vs 从儿的临界）

---

### 4. 从势格（综合从）

**成格条件**：
- 日干极弱无根
- 命局**财、官杀、食伤都旺**（综合克泄耗）+ 无印比
- 没有单一最旺的五行，但综合克身势力 >> 帮身势力

**破格条件**：
- 任何来救日主的字（印 / 比劫透干通根）

**典型组合**：
- 戊土日 + 命局甲木（杀）+ 庚金（食神）+ 壬水（财）都旺 + 无火 + 无戊己根 = 从势
- 古名："**从势者，势之所趋而从**"

**喜忌方向**（从势后）：
- **喜**：财 + 官杀 + 食伤都喜（命局多元）
- **忌**：印 + 比劫

**现代脱毒意象**：
- 倾向**适应多种环境**——结构上"以环境为身"
- 真从势命主**常显高度适应性 / 多元发展 / 顺势而为**

**常见误判**：
- ❌ 把"身弱多忌"误判为从势——**从势必须无救**

**接口规则**：R45（特殊格局优先）

---

### 5. 从旺格

**成格条件**：
- 日干**极旺**（与专旺格相似但更极端）
- 命局**全是印比**（生身或同党）
- 无任何克泄耗

**破格条件**：
- 命局有克泄耗字（即使微弱也破从旺）

**典型组合**：
- 甲日 + 命局壬癸水（印）+ 甲乙木（比劫）全充满 + 无金土 = 从旺
- 与曲直格类似但更极端

**喜忌方向**：
- **喜**：印 + 比劫（同党）
- **忌**：财 + 官杀 + 食伤（任何克泄耗都破）

**现代脱毒意象**：
- 倾向**自我中心 / 主体性极强 / 不依赖外部**
- **从旺 vs 专旺的区别**：专旺日主属该五行；从旺日主可能属同党其他五行

**接口规则**：R45 / 与专旺格相似处理

---

### 6. 从弱格

**成格条件**：
- 日干**极弱到完全顺从克泄耗**
- 是从财 / 从杀 / 从儿 / 从势的统称

**注**：实际操作中常细分为前面四种（从财 / 从杀 / 从儿 / 从势），"从弱格"作为统称使用较少。

## 五、复合格局（经典组合）

> **复合格局 = 两个或多个十神同时强势 + 形成特定的相互作用结构**——比单一正格更稳、更易出贵。
> 本章深化 R45 一行清单：6 个经典复合格局每个完整展开。

---

### 1. 杀印相生

**成格条件**：
- **七杀重**（透干 + 多根 / 月令支持）
- **印重**（透干 + 多根）
- **印化杀**——印贴近七杀，能化解杀气
- **印必透干**（古典关键条件——古书原文"必须庚透干头"）
- 身能担印

**破格条件**：
- **财破印**——天干财紧邻印，财克印 → 印不能化杀 → 破格
- 食神制杀——印化杀和食制杀是两种方法论，混用会乱
- 印被冲克

**典型组合**：
- 古典原文（《穷通宝鉴》论壬水生午月）："**壬日而值戊申时，杀印相生，但月令在午，为戊土之旺气，而申金虽系壬水长生，因受午火威胁，其生水之力以减，必须庚透干头，则庚禄居申**"
- 现代典型：戊七杀透 + 庚金印透 + 壬水日主有根

**临界判定**：
- 杀印**虽具备但印未透**——退回普通命局，按身弱用印处理
- 杀印**具备但被财破**——破格，按身弱被困处理

**喜忌方向**：
- **喜**：印（核心用神，越透越好）+ 比劫帮身担印
- **忌**：财（破印）+ 食伤（制杀过头 / 印被食伤泄）

**现代脱毒意象**：
- 倾向**通过学习 / 师承 / 知识权威化解压力**——通过吸收（印）转化挑战（杀）的能力
- 杀印相生格命主**常显学者 / 顾问 / 高知职业 / 转化型领导**

**常见误判**：
- ❌ 看到印多就说"印多反忌"——**先看七杀状况**（详 R11 v2）
- ❌ 杀印相生不要财——**财来生杀但同时破印 → 必须远离**

**接口规则**：R11 v2（印多反忌的边界）/ R55 中的"杀重身轻"区别 / R51（大运财来破印的触发）

**验证案例**（rules-engine.md R11 v2 已记录）：
- 1994-06-15 宁波男 `甲戌 庚午 壬申 戊申` —— 双申印 + 戊杀透 + 庚透干头 + 壬水有根 = 经典杀印相生格

---

### 2. 食神制杀

**成格条件**：
- **食神重**（透干 + 多根）
- **七杀重**（透干 + 多根）
- **食神制杀**——食神贴近七杀，能克制杀气
- **身能担食神**（食神泄身，身弱则食神反成耗）

**破格条件**：
- **偏印夺食**（枭神夺食）—— 偏印克食神 → 制杀工具被破 → 破格
- 食神被合化
- 七杀过重食神制不住（"制杀不及"）
- 食神过重无杀可制（"制杀太过"）

**典型组合**：
- 古名："**一将当关，万夫莫开**"——食神是制杀的"将"
- 现代典型：庚金食神透 + 乙木七杀透 + 戊土日主有根 + 印不夺食

**临界判定**：
- 食神虽具但身弱——食神不是用而是耗 → 退回身弱用印
- 食神具但杀更重——制杀不及 → 升级为"杀重身轻"或转杀印相生

**喜忌方向**：
- **喜**：食神有根 + 财星泄食神（食生财）+ 身有根
- **忌**：偏印夺食 + 印化杀（与食制杀方法论冲突）+ 食伤过头

**现代脱毒意象**：
- 倾向**通过创造 / 输出 / 技艺对抗压力**——把杀（压力）转化为食神（输出）的产物
- 食制杀格命主**常显技术型 / 艺术型 / 表达型领导**——通过专业能力化解外部对抗

**常见误判**：
- ❌ 食神 + 七杀就说食制杀——**必须身能担食神**
- ❌ 食制杀格喜印——**印夺食是破格**

**接口规则**：R55 中的"食神格 vs 七杀格 vs 食神制杀格"区别 / R51

---

### 3. 伤官见官

**成格条件 / 性质**：
- 命局同时有**伤官**透 + **正官**透 + 紧邻或同柱

**性质**：**伤官见官**是**忌格**——伤官本性叛逆，见到正官就要冲克，造成命局张力 / 摩擦。古典认为"伤官见官，祸患百端"。

**例外（升级为良性变体）**：

- **伤官佩印**：伤官见官 + 有**印通关**（印克伤官 + 印生官）→ 良性结构（详下方）
- **伤官伤尽**：伤官重 + 官全无 → 单纯走伤官路线，反而清

**破格条件 vs 修复**：
- **无印通关 + 伤官官同透紧邻** → 严重破格（无救）
- **印透干通关** → 升级为伤官佩印

**典型组合**（破格版本）：
- 丙日 + 月伤官己土透 + 时正官癸水透 + 无印 + 紧邻 = 典型伤官见官败格

**喜忌方向**（破格状态）：
- **喜**：印（救——通过通关变成伤官佩印）+ 食神（吸收伤官能量）
- **忌**：再加官 / 再加伤官 / 财（财生官加重冲突）

**现代脱毒意象**：
- 破格倾向**与权威 / 制度持续摩擦** —— 不是预测"必失业"，是结构上"不容易在体制内顺展开"
- 升级后倾向"**有特殊才华但需要合适表达通道**"

**常见误判**：
- ❌ 看到伤官见官就说凶——**没查印是否能通关**
- ❌ "女命伤官见官克夫"—— **封建命书旧说，严格禁用**

**接口规则**：R56（清浊取舍）/ R55 伤官佩印 / R52（子平 vs 盲派对伤官读法的分歧）

---

### 4. 伤官佩印

**成格条件**：
- **伤官重**（透干 + 多根）
- **正印重**（透干 + 多根）
- **印克伤官 + 印护身**——印能克伤官避免伤官过泄，同时印能护身
- 身能担印

**破格条件**：
- 财破印——财来克印 → 伤官失制
- 印太重——印多反成忌（详 R11 v2 边界）

**典型组合**：
- 甲日 + 月伤官丁火透 + 印壬水透 + 通根 + 财远离 = 伤官佩印良性结构
- 古名："**伤官佩印，富贵双全**"——伤官的才华 + 印的稳定 → 才华有承载

**临界判定**：
- 伤官见官 → 加印 → 是伤官佩印还是仍是伤官见官？看印是否能同时克伤护身

**喜忌方向**：
- **喜**：印（核心）+ 比劫帮身担印
- **忌**：财（破印）+ 再加伤官（过泄）

**现代脱毒意象**：
- 倾向**才华型职业**——创造力（伤官）+ 学习庇护（印）的双重支撑
- 伤官佩印格命主**常显学者型创意人 / 高知艺术家 / 跨界专家**

**常见误判**：
- ❌ 伤官+印就说伤官佩印——**必须身能担 + 印能克伤护身**
- ❌ 伤官佩印 = 必富贵——**结构倾向不是事件预测**

**接口规则**：R55 中其他复合格局 / R11 v2

### 5. 财官印三宝

**成格条件**：
- **正财透干通根**
- **正官透干通根**
- **正印透干通根**
- 三者**相生相成**：财生官 + 官生印 + 印生身
- 身能担

**破格条件**：
- 任一星被冲克 → 链条断
- 财印紧邻冲突（财克印）→ 链条乱

**典型组合**：
- 古名："**财官印三宝，文武双全**"——子平真诠经典良性结构
- 现代典型：日主身有根 + 月正财透 + 时正官透 + 年正印透 + 三者不互冲

**临界判定**：
- 三宝俱全但**财印紧邻**——清浊不分 → 看是否能用官通关
- 三宝俱全但**身极弱**——担不动 → 退回身弱

**喜忌方向**：
- **喜**：身有根 + 三宝俱全不破 + 大运配合
- **忌**：任一星被克 / 被合化

**现代脱毒意象**：
- 倾向**结构性贵气**——资源（财）+ 权威（官）+ 学识（印）+ 身能担 = 综合支撑
- 财官印三宝格命主**常显综合发展 / 多领域协同 / 稳定大事业**

**常见误判**：
- ❌ 三宝就是必大贵——**结构倾向，仍需大运 + 反身性选择展开**

**接口规则**：R56（清浊取舍 — 财印紧邻的处理）

### 6. 杀重身轻

**成格条件 / 性质**：
- **七杀重**（透干 + 多根 + 月令支持）
- **身偏弱**（日主无强根 / 比劫少 / 印缺）
- **无救应**（既无印化杀，也无食制杀，也无比抗杀）

**性质**：**杀重身轻**是**破格**或**败格**——命局有"被压制"的结构倾向。

**修复条件 vs 退路**：
- **加印** → 升级为杀印相生（详 #1）
- **加食神** → 升级为食神制杀（详 #2）
- **加比劫** → 抗杀但需谨慎（比劫帮身但耗财）
- **完全无救** → 走"接受压力 / 顺势"路线，类似从杀格但不真从

**典型组合**：
- 日主无根 + 月时七杀透 + 杀坐禄 + 无印无食无比劫 = 典型杀重身轻

**喜忌方向**：
- **喜**：印（化杀 + 护身）+ 比劫（抗杀，但勿过强）+ 食神（制杀，但需身能担）
- **忌**：财（生杀加重）+ 再加杀

**现代脱毒意象**：
- 倾向**长期承受压力**——不是预测"必失败"，是结构上"在高压环境中需要特殊修复机制"
- 杀重身轻命主**常需要外部支持（学习 / 师承 / 团队）作为修复点**

**常见误判**：
- ❌ 杀重身轻 = 注定凶——**结构倾向，可通过印 / 食 / 比修复**
- ❌ 把杀重身轻误判为从杀——**关键看日主是否真无根**

**接口规则**：R55 杀印相生 / R55 食神制杀 / R51 大运补救的机制

## 七、杂格附录（争议大，临界使用）

> **以下杂格在古典命书（《三命通会》《滴天髓》等）中有记载，但现代命理实操中争议较大、误判率高**。
> 议会立场：**仅作"额外信号"使用，不作主格局判定**。任何杂格判断都不应覆盖正格 / 化气 / 专旺 / 从格 / 复合的主结构识别。

**通用警示**：
- ❌ 不要见到杂格表面条件就直接判格
- ❌ 不要用杂格做事件预测（如"金神格主立功封爵"）
- ✓ 杂格作为"命局有特殊倾向"的额外说明 —— 永远配合主格走

---

### 1. 飞天禄马（暗冲格）

**简述**：日主与月支或时支某字组合，**暗冲**出隐藏的禄或马（驿马）。

**举例**：庚日见多个子（子暗冲午，午中有丁正官）→ "暗合官星"

**议会立场**：极少独立成格——多数情况下是主格的"附加信号"。**禁用单独判贵贱**。

---

### 2. 拱禄拱贵

**简述**：两支之间**隔字拱出**日主的禄或贵人。

**举例**：日柱甲寅 + 时柱甲辰 → 寅辰之间拱出"卯"（甲禄）

**议会立场**：拱合在 R47 已有完整处理。**杂格中的"拱禄"判定与 R47 重叠**——建议走 R47 拱合的标准判定，不另立杂格。

---

### 3. 金神格

**简述**：日柱时柱见**乙丑、己巳、癸酉**（古名"金神三日"）+ 命局有制（火制金神）。

**议会立场**：古典认为"金神主刚毅 + 建功立业"。现代命理对金神格的判定标准不一，**议会暂不纳入主判定**。

---

### 4. 井栏叉格

**简述**：庚日生 + 地支**申子辰**三合水局 + 时柱见井栏字。

**议会立场**：与从格、专旺格高度重叠——按从格 / 专旺处理更安全。

---

### 5. 倒冲格 / 朝阳格 / 其他

**简述**：通过特殊地支组合"冲出"虚字、"朝向"特定方位等的杂格集合。

**议会立场**：**统一不纳入主判定**——这些杂格在《三命通会》中数量极多（数十种），但现代实操经验显示误判率高、与主结构判定容易冲突。如有命主自行了解过相关杂格，可作为补充讨论，但不作议会主断。

### 关键决策点

#### 决策点 1：特殊格局 vs 月令正格

**判据**：
- **极端命局**（一气专旺 / 极弱无根 / 真化）→ 特殊格局
- **一般命局**（多种五行 + 日主有根）→ 月令正格

**误判预防**：
- 真专旺 vs 假专旺（有微弱克神时是假）
- 真从 vs 假从（日主有微根时是假）
- 真化 vs 合而不化（化神不得月令时是假）

#### 决策点 2：单一正格 vs 复合格局

**判据**：
- **月令正格 + 另一十神同等突出** → 检查是否构成复合格局
- **月令正格 + 其他十神都弱** → 走单一月令正格

**例**：月令正官透 + 印也透通根 → 不是单纯正官格，而是"官印相生"复合

#### 决策点 3：清浊取舍

**当命局喜神 + 忌神同透时**，必须做清浊取舍：

| 场景 | 取舍方向 | 判据 |
|---|---|---|
| **官杀混杂** | 去杀留官 vs 去官留杀 | 看哪个更突出 + 月令支持哪个 |
| **食伤混杂** | 留食伤秀气，去抑制者 | 看哪个能担当用神 |
| **印枭混杂** | 留正印 vs 留偏印 | 看与日主搭配 |
| **财劫混战** | 用官杀制劫保财 | 看官杀位置 |

#### 决策点 4：调候何时升一级（R19）

**调候升一级条件**：
- 月令气候**极端**：大寒（亥子丑月）/ 大热（巳午未月）/ 极燥（戌月燥土）/ 极湿（辰丑月湿土）
- 命局缺**修正气候的五行**（如夏月命局无水）

**调候 vs 格局喜忌冲突时**：调候**优先**（详 R19）

#### 决策点 5：破格的修复可能性

**判据**（详九章详细总论）：
- **能修**：破格点有救应字（如财破印有官通关）→ 格损不破
- **不能修**：破格点孤立无救 → 退回普通命局

## 九、破格条件总论

### 破格的统一判定原则

**破格不是"格局完全失效"，而是"格局的关键支撑被攻击"**——通常分四类：

#### A. 冲破

**判据**：月令支或关键透干支被紧邻冲

| 冲的位置 | 严重度 |
|---|:-:|
| 月日冲（核心位置）| ★★★ 严重 |
| 月时冲 / 年月冲 | ★★ 中度 |
| 年时冲（遥冲）| ★ 轻度 |

**修复**：
- 合解冲（详 R51）→ 部分修复
- 通关五行（如金克木有水通关）→ 部分修复

#### B. 合化破

**判据**：关键透干被合化为他物

**修复**：
- 化神方向就是格局喜神 → 不算破，反成助力（如官星被合化为印星，若印星是用 → 不破）
- 化神方向是忌神 → 严重破

#### C. 克破

**判据**：关键透干被紧邻克

**修复**：
- 有印通关 → 部分修复
- 克神远离 → 减效

#### D. 混杂（清浊不分）

**判据**：格局喜神 + 忌神同透紧邻

**修复**：清浊取舍（详上 SOP 决策点 3）

### 破格修复的等级

| 等级 | 判定 | 处理 |
|---|---|---|
| **成格** | 破格点全无 | 走该格喜忌 |
| **格损不破** | 破格点有救应 | 走该格喜忌 + 警惕修复点 |
| **败格** | 破格点无救但格局基本结构仍在 | 走该格喜忌 + 重大减效 |
| **破格** | 破格点无救且格局基本结构崩塌 | 退回普通命局，走 R1 + R11 |

### 子平 vs 盲派对破格的分歧（详 R52）

| 维度 | 子平 | 盲派 |
|---|---|---|
| 破格判定 | 严判，三破即不成格 | 灵活，结构倾向仍有效 |
| 修复要求 | 救应必须紧邻 | 看做功路径整体 |
| 临界处理 | 退回普通命局 | 仍部分按格读 |

**议会立场**：**两派并陈**——子平严判用于"格成不成"的二元决策；盲派灵活用于"结构倾向"的连续描述。
