# 规则引擎 · Rules Engine

**定位**：八字 subagent 内部的**技术推理层**。由 22 条从真实案例蒸馏的规则组成，负责"能不能发/什么行业/什么时候/方位"等结构性判断。

**与 SKILL.md 的关系**：
- SKILL.md = 框架层（议会、三派正交、伦理边界、术语脱毒）
- 本文件 = 推理层（被 `bazi-agent` subagent 调用）
- **规则输出在进入 Step 5 合成前必须经 SKILL.md 的"输出前自检 Checklist"脱毒**
- 未脱毒的直接技术断语（"身旺喜金水"→"你该去北方"）属于违规输出

**验证来源**：5 个真实案例（见 `examples/`），含事实反馈与星盘截图确认。

## 起手式（固定四步）

每次八字分析必须按此顺序执行，不可跳步：

1. **日元旺衰判断**（滴天髓）→ 触发 R1
2. **特殊格局检查**（子平格局法）→ 触发 R10
3. **月令定格局**（子平格局法）→ 成格 / 破格 / 假格
4. **调候用神**（穷通宝鉴）→ 触发 R19

四步完成后才进入 R11（用神排除法）做最终裁决。

## A. 基础判断规则

### R1（v3）· 三维旺衰判定（定性优先 + 量化辅助）

**规则**：身强身弱判定**必须以传统子平三维法（得令 / 得地 / 得势）为主**。R24 量化工具只作**辅助参考**，不能单独判决。

---

**第一层 · 定性三维（必先走）**

| 维度 | 检查 | 判定标准 |
|---|---|---|
| **得令** | 月令是否助我？ | 比劫 / 印 = 得令；财 / 官杀 / 食伤 = 失令 |
| **得地** | 地支是否有我的根？ | 通根（同类或有禄）= 得地；至少一根为准 |
| **得势** | 天干是否有助我的字？ | 比劫 / 印透 = 得势；过半字助我为强势 |

**判决表**：
| 三项占几项 | 身强弱判定 |
|---|---|
| 3 项全占 | **身强 / 身极旺** |
| 2 项（含得令）| **身强** |
| 2 项（不含得令）| **身中和偏强** |
| 1 项 | **身偏弱 / 中和偏弱** |
| 0 项 | **身弱 / 从格候选** |

---

**第二层 · 日元 vs 最强对手**（精度判定）

在第一层结论基础上，检查命局中最强对手是什么：

| 日元 + 对手状况 | 喜用路线 |
|---|---|
| 身强 + 对手不重 | 克泄耗（官杀 / 食伤 / 财星）|
| 身强 + 对手更强 | **印通关**（不是克泄耗）|
| 身弱 | 生扶（印 / 比劫）|
| 身中和偏强 + 财独旺 | **担财为用**（身能胜财）|
| 身中和 + 财独旺 | **官制劫护财 + 财官同用**（身中和能担） |
| 身中和偏弱 + 财独旺 | 印帮身 + 官通关（印+官）|
| 身中和 + 官杀独旺 | 印化杀（杀→印→身）|
| 身中和 + 食伤独旺 | 印克食伤（若不伤调候）或比劫帮身 |
| 身中和 + 比劫独旺 | 官杀制劫 + 食伤泄秀 |

**关键**：**"身中和"不等同于"身弱"**——身中和命盘可以担财官，只是需要结构配合。

**第三层 · R24 量化辅助（可选，非判决）**

#### R1 常见误判模式（v3.1 警示）

经验教训：三维法本身正确，但**某些信号会触发"快速归类反应"导致误判**。以下三种模式必须警惕：

**误判模式 A · 双根帝旺导致"身强"幻觉**
- 信号：地支某干有 2 个及以上的帝旺/临官位
- 陷阱："看到双帝旺 / 双禄 → 直接判身强"
- **必查 3 项**：
  1. **月令本气是否直接克身**（月令克 = 失令是硬伤，不能被地支根抵消）
  2. **帝旺根是否被墓 / 绝 / 冲克拉扯**（如双亥帝旺被双未墓夹）
  3. **是否缺印**（缺印的"身强"往往担不起官杀）
- 案例：1995-07-31 13:45 长沙 F · `乙亥 癸未 癸亥 己未`
  - 错判路径：双亥帝旺 → 身中和偏强 → 食神制杀
  - 正判路径：失令（未月七杀本气）+ 墓夹根（月时双未克双亥）+ 缺印 + 七杀双根透干 → **身偏弱、杀重缺印、比劫抗杀**
  - 教训：**月令克身 + 墓夹帝旺根 + 缺印** = "看着强其实弱"的经典命盘

**误判模式 B · "食神制杀"的滥用**
- 食神制杀的前提是：**身能担食神再分力制杀**
- 身偏弱时强用食神制杀 = 越制越虚（食神再泄身）
- **判定流程**：
  1. 先确认身能否担起食神（身偏弱时食神是负担不是工具）
  2. 再看食神是否能有效制约七杀（食神坐墓 / 被合 → 制杀力打折）
  3. 若身担不起 → 改走"**印化杀**"（有印）或"**比劫抗杀**"（缺印有比劫）
- 误判信号：天干"看到食神 + 看到七杀" → 不查身就直接套食神制杀

**误判模式 C · 缺印盲点**
- 命局**缺印**（无金 / 印星不透不藏）+ **官杀重** → 这是结构性短板，必须显式标注
- "杀印相生"框架在**缺印命盘**不成立
- 修正方向：**印星代偿（学习 / 智识 / 老师 / 距离感 / 跨界知识）作为外部资源**——把命局短板用"造命"补足
- 此时八字 subagent 的输出**必须**包含"缺印警告"和"印代偿建议"，否则等于漏掉这个命局最关键的张力

**统一审计 checklist**（每个新命盘走 R1 必检）：
- [ ] 月令本气对日元什么关系（生 / 克 / 比 / 泄 / 耗）—— 这是"得令"的真实判据
- [ ] 帝旺/禄根是否被墓/绝/冲拉扯
- [ ] 印星状态：透 / 藏 / 缺
- [ ] 官杀状态：透 / 藏 / 多根 / 单根
- [ ] 食伤状态：透 / 藏 / 缺
- [ ] 比劫状态：透 / 藏 / 多根 / 单根
- [ ] 综合：身和"最强对手"力量对比 + 是否有"通关枢纽"（印 / 食伤）
- [ ] 是否触发误判模式 A / B / C 的警示信号

### R10 · 特殊格局优先

**规则**：特殊格局优先于普通格局。检查点：
- 日柱是否命中特殊格局（魁罡、专旺、从格、化格、两神成象等）
- 地支是否合化某五行力量过大
- 成特殊格局则用神规则改变

**来源**：子平格局法
**验证**：Case 003（戊戌日 = 魁罡格）、Case 005（双庚辰月日并立 + 戊戌日）
**边界**：破格与否看干支配合是否被冲破

### R11 · 用神排除法

**规则**：用神不是"一眼看出"，是**排除法**：
1. 列出所有候选用神（通常 2-3 个五行）
2. 每个候选代入命局试运行，追踪引发的连锁反应
3. 排除会引发关键副作用的候选
4. 剩下的才是真用神

**典型副作用**：
- 喜 X 但 X 会冲动忌神 → 排除
- 喜 X 但 X 会合绊关键用神 → 排除
- 喜 X 但 X 五行气偏枯燥 → 需搭配调候

**来源**：子平实操
**验证**：Case 003（排除木因生火忌神、排除水因子午冲 → 最喜金）
**用法**：R1 裁定"方向"后，R11 裁定"具体哪个"

### R19 · 调候的决定性作用（一级规则）

**规则**：格局定骨架，调候定血肉。**同一格局在不同气候下展开完全不同**。**当命局气候极端时，调候升为一级规则**（起手式第 4 步先于第 2-3 步执行），覆盖扶抑/格局给出的方向。

**来源**：《穷通宝鉴》
**验证**：Case 002 vs Case 004（都是杀印相生格，一个太寒喜火、一个太燥喜水）

**气候极端量化判据**（命中任一即触发"调候优先级升一级"）：

| 极端类型 | 量化条件 |
|---|---|
| **大寒** | 亥/子/丑月 + 日元为水或土（湿气重）+ 天干地支都无丙/丁/巳/午火 |
| **大燥** | 巳/午/未月 + 日元为火或土（燥气重）+ 天干地支都无壬/癸/亥/子水 |
| **气偏（专旺）** | 命局出现三合局（寅午戌/申子辰/亥卯未/巳酉丑）或三会局（寅卯辰/巳午未/申酉戌/亥子丑），某行成局 |
| **气偏（独旺）** | 某五行在天干地支占比 ≥ 60%（结合 R24 十二长生力量计算）|

**命中时的处理**：
1. 先定调候用神（寒用火、燥用水、湿用火土、偏用反制之行）
2. 格局法给出的用神若与调候冲突 → 以调候为主
3. 若调候与格局一致 → 用神双重确定，象征强度高
4. 非极端命局 → R19 回到二级，与格局法并用（见 R2）

### R23 · 魁罡冲的专项处理

**规则**：魁罡格（庚辰、庚戌、戊戌、壬辰四日）的冲刑有专属判据，不适用普通刑冲规则（R20）。

**经典依据**（《九流之命·魁罡歌》）：
> 魁罡四日最为先，叠叠相逢掌大权，
> 庚戌庚辰怕官显，戊戌壬辰畏财连。
> 主人性格多聪慧，好杀之心断不偏，
> 柱有刑冲兼破害，一贫彻骨受答鞭。
> 戊戌庚辰杀最强，壬辰庚戌号魁罡，
> 日加重者方为福，身旺逢之贵异常，
> 如逢一位冲刑重，彻骨贫寒不可当。

**三条核心判据**：

1. **叠叠相逢掌大权**：命局出现两个及以上魁罡（年月日时任意柱），主大权位
2. **四日各有忌神**：
   - **庚戌、庚辰日** → 怕官显（丙丁火透或通根）
   - **戊戌、壬辰日** → 畏财连（壬癸水/丙丁火对应日主的财星透显）
3. **冲刑破害 + 财官显露 → 祸**：
   - "日主独逢冲刑重"= 魁罡日逢一位冲（刑、破、害亦同）
   - 若同时满足"财官显露"→ 彻骨贫寒
   - 若不满足财官显露 → 有冲但冲的是闲神/忌神，仍可保身

**与 R20 的关系**：
- R20 适用于普通命局的刑冲判断
- R23 **优先**于 R20 处理魁罡日主的冲
- 本规则是 R20 的专项例外

**判定流程**：
```
日柱是否魁罡？
├─ 否 → 用 R20
└─ 是 → 进入 R23
    ├─ 有无叠加？（多个魁罡）
    │  ├─ 有 → 保留"掌大权"基础加成
    │  └─ 无 → 无加成
    ├─ 有无相应忌神显露？（庚日怕官、戊壬日畏财）
    │  ├─ 有 → 进入破格判定
    │  └─ 无 → 保留魁罡格
    └─ 日柱有无冲刑破害？
        ├─ 有 + 财官显露 → 破格，彻骨贫寒
        ├─ 有 + 财官不显 → 格损但不破，看身旺与否
        │  ├─ 身旺 → 仍贵（"身旺逢之贵异常"覆盖冲的负面）
        │  └─ 身弱 → 格力受限
        └─ 无冲 → 保留魁罡格全效
```

**来源**：《九流之命·魁罡歌》
**验证**：Case 005（庚辰月 + 戊戌日 = 双魁罡叠 + 辰戌冲）
- 叠加 ✓ 掌大权基础加成
- 戊戌畏财连：命局财（水）仅辰中藏癸微弱，不显 → **不算犯禁**
- 日主逢冲 ✓（辰戌月日冲）
- 财官显露判定：乙卯七杀通根透显（官杀显）→ 部分命中
- 身旺 ✓（戊土得令得地）→ "身旺逢之贵异常"覆盖
- **结论**：格损但未破，身旺为盾 → 命格仍成立但有冲的代价（成长期拉扯、人生节奏被打断）

**配合 R1**：魁罡格破后按普通格局处理，回到 R1 三层判断路径

### R24 · 十二长生力量分级（**辅助工具，非独立判决**）

> ⚠️ **使用边界（v3 修订）**：
> - ✅ **工具**：帮助理解"每个地支对日元贡献了多少气"——定性判断得地时的**精度支撑**
> - ❌ **禁用**：单独作为"身强身弱"的判决器
> - ❌ **禁用**："日元总分 vs 对手总分"的对决式计算——这种思维不是子平
> - **身强身弱的最终判决权在 R1 三维法**（得令 / 得地 / 得势）
> - 当 R24 结果与 R1 三维冲突时，**R1 三维优先**
>
> **Case 001 污染修复**：早期版本用 R24 量化对决判"丁火 160 vs 金 300 → 身中和偏弱"——这是越权判决。真正的子平三维判定是：不得令但得地（巳禄+酉长生）+ 得势（丙丙丁+乙印）= **两项占 → 身中和偏强**。

**规则**：判定"得地"的**力量强度**时（不是有无），按十二长生位分级。日元坐某地支的气息强弱：

| 十二长生 | 状态 | 力量值 | 说明 |
|---|---|:-:|---|
| **帝旺** | 能量顶峰 | 100 | 最强，自身当令之地 |
| **临官（禄）** | 成年当权 | 80 | 日元的禄地，次强 |
| **冠带** | 成长将成 | 60 | 渐趋强势 |
| **衰** | 盛极转衰 | 50 | 仍有余力 |
| **长生** | 新生起势 | 40 | 有气但无力，"气息起始" |
| **沐浴** | 脆弱不稳 | 30 | 易动摇 |
| **病** | 衰败中 | 30 | 弱但未死 |
| **墓/库** | 入库收藏 | 30 | 闭藏（被冲开时升至 60）|

**使用方法**：
1. 查表找日元坐日支/月支/时支/年支的十二长生位
2. 对应力量值
3. 加总日元在四柱地支的力量（日支 ×1.5 权重、月支 ×1.5 权重、时支×1.0、年支 ×0.7）
4. 与"对手"五行的同类力量比较 → 辅助 R1 第二层判断

**示例（Case 001 丁酉日主，v3 正确用法）**：

R24 **辅助描述**（不做判决）：
- 日支酉：丁长生 → **40 分**（气息起始，力量有限）
- 时支巳：丁帝旺 → **100 分**（禄旺之地，最强根）
- 月支申：丁沐浴 → 30 分但被金本气占
- 年支子：丁绝 → 0 分

**描述意义**：丁火在命局中**有两个根**（帝旺+长生），其中时支巳是最强根。这是"**得地**"的精度信息。

**不做的事**：不算"日元 160 vs 对手 300" 然后判身弱——这是越权。

**R1 三维判决（正确路径）**：
- 不得令（申月）
- ✓ 得地（巳禄 + 酉长生 = 两根含帝旺）
- ✓ 得势（天干丙丁丙 + 乙印贴身 = 四字助）
- 三维占两项 → **身中和偏强**（不是偏弱）
- 喜用：**金（财）+ 水（官）**，用官制天干双丙劫财

**来源**：传统子平 + 2026-04-24 方法论修正
**教训**：R24 作为独立判决器会在临界命盘上误判。必须**定性优先，量化辅助**。

### R31 · 十干寄禄表（盲派基础事实）

**规则**：十干各有正禄地支。这是基础结构知识，必须熟记：

| 天干 | 正禄 | 天干 | 正禄 |
|---|---|---|---|
| 甲 | 寅 | 乙 | 卯 |
| **丙** | **巳** | **丁** | **午** |
| 戊 | 巳 | 己 | 午 |
| 庚 | 申 | 辛 | 酉 |
| 壬 | 亥 | 癸 | 子 |

**读盘应用**：任何命盘都应先做"寄禄核查"——每个天干的禄在原局中有没有、在谁的宫位。

**与子平 R24 的区别**：
- R24 说"临官位 = 80 分"——量化工具
- R31 说"**这个禄对日元（或其他天干）是可调动的工具**"——结构工具
- 两者并用，不冲突

**来源**：盲派段建业体系 + 传统八字基础
**验证**：所有案例都应做此核查；Case 001 最初漏掉了"丙禄在巳" + "丁可借丙禄"的判断

### R32 · 同气借禄

**规则**：阴阳同五行之干可互借禄地支：

| 五行 | 可互借禄 |
|---|---|
| 木 | 甲 ↔ 乙 |
| 火 | **丙 ↔ 丁** |
| 土 | 戊 ↔ 己 |
| 金 | 庚 ↔ 辛 |
| 水 | 壬 ↔ 癸 |

**借禄强度**：低于自禄，但仍作"有根"计算。

**借禄的判断条件**：
- 借禄来自的同气干必须**在命局中存在**（例：丁借丙禄，前提是命局有丙透）
- 禄地支最好**落在我宫**（见 R33）——效力最强

**来源**：盲派"同气连枝"原理
**验证**：Case 001（丁借丙禄在巳 = 时支我宫 = 强根）、Case 002（癸借壬禄在亥 = 双亥两根）、Case 006（丙借丁禄在午 = 双午两根）

### R33 · 体用分野 · 我宫识别

**规则**：八字四柱在盲派分为我宫 / 他宫：

| 柱 | 区分 | 含义 |
|---|---|---|
| 年柱 | **他宫** | 祖上、外部、先天环境 |
| 月柱 | **他宫** | 父母、生长环境、早年基盘 |
| **日柱** | **我宫（体）** | 我自己 + 配偶（日支） |
| **时柱** | **我宫（用）** | 我追求的、子女、我能调动的工具、人生终点 |

**读盘应用**：
- 当**重要气机**（禄 / 用神 / 财 / 官）落在我宫 → 效力**显著增强**，代表"我可以直接调动"
- 当重要气机落在他宫 → 需要通过合冲刑害的"渠道"才能被动调动
- 盲派说："**重点都在我宫**"——我宫的气机决定命主自己能做什么

**来源**：盲派体用分野核心
**验证**：
- Case 001 时支巳（丙禄借给丁）在**我宫** → 丁火有强根可用
- Case 002 时支午（癸的偏财）在**我宫** → 我能直接拿到财
- Case 006 月日双午（丙借禄）在**月柱+我宫** → 禄气既是外部也是自己的

### R34 · 合制做功（合 ≠ 合化）

**规则**：地支六合、三合、半合在盲派的核心读法是"**收拢做功**"——**不是合化**。

| 传统读法 | 盲派读法 |
|---|---|
| 合化 → 两地支变成另一五行 | 合 → 两地支**能量收拢到一起** |
| 看五行转变 | 看"**谁把谁收在手里**" |
| "合则消失" | "**合则能去，效率远高于克**" |

**做功效率**：
- **克**：直接对抗，内耗偏强
- **合**：收拢控制，效率高
- **合 > 克**

**判断"谁合谁"**：看合的两方**谁更接近我宫 / 谁代表我**——代表我的那个"主合"另一个。

**应用到 Case 001**：
- 巳（时支我宫禄神）合申（月他宫偏财）= **我用禄神合财**
- 巳（时支我宫禄神）半合酉（日支我宫正财）= **我宫内禄神合财**
- 两次"**禄合财做功**"= 我直接把财攥在手里
- 这**不是**"巳申化水损禄"——原局力量分布不变

**来源**：盲派合制原理
**验证**：Case 001（两次禄合财）、Case 002（原局合的结构）、Case 006（辰戌冲冲开两库）

---

### R35 · 我宫见用神 / 财官

**规则**：当财、官、用神**落在我宫**时，代表"我能直接调动这份资源"。

| 落位 | 读法 |
|---|---|
| **财在我宫** | 我能拿到财（不需通过他人）|
| **官在我宫** | 我有权威可以代我做事 |
| **用神在我宫** | 用神可直接激活 |
| **忌神在我宫** | 忌神就在我身边，难避免 |
| **用神在他宫** | 需要通过合冲等渠道才能调动 |

**读盘扫描顺序**：
1. 先标出命盘的用神、忌神、财、官位置
2. 再看各自落在哪个柱（我宫 / 他宫）
3. 我宫落用神 = 强做功结构

**来源**：盲派"重点在我宫"原理
**验证**：
- Case 001：时支巳 = 禄在我宫 + 酉偏财在我宫日支 = **双重"我宫见用神"**（按 v3 身中和+财为用计算）
- Case 002：时支午 = 财在我宫 + 时干戊 = 官在我宫（贴身七杀）= 富贵做功
- Case 006：时支戌 = 火库在我宫（戊食神墓 = 做功墓地）

---

**R31-R35 整体说明**：
- 这 5 条规则**不需要触发条件**——任何命盘都可以用
- 它们是对子平扶抑派的**精度增强**，不是替代
- 子平看"五行生克力量"，盲派看"能量流向与做功效率"——两者**互补**
- 一般命盘子平为主、盲派增精度；临界命盘两者并用可防止单派误判
- **R35 我宫见用神** 是盲派输出里**最具操作性**的诊断——能定位"命主自己能做什么"

## C. 十神结构规则

### R4 · 食伤缺位则创业能力弱

**规则**：食伤（食神+伤官）完全缺位的命局，**创业造血机器缺失** → 宜借平台之力（正财、偏财、正官大平台）。

**理由**：食伤 = 产品/创意/商业模式/表达输出。缺食伤的人可能非常勤奋、非常会赚钱，但不擅长"从零创造产品"。

**来源**：十神体系
**验证**：Case 001（食伤为零）→ 不宜创业、应走大平台 → 事实验证：创业失败经历 ✓
**边界**：食伤缺但印星旺的命局，可靠"借他人产品"盈利（代理、渠道、中介）

### R5 · 劫财重则财需官制

**规则**：天干/地支比劫数量 ≥ 2 且财星暴露，财容易被"分食"（合伙人分走、同行抢走、家人拿走）→ 需要官杀（正官/七杀）在命局中制约比劫，财才能留住。

**环境推论**：劫财重 + 无官杀制 → 宜选"制度围墙强"的环境（体制内、大型企业、持牌机构），借外部制度替代命局中缺失的官。

**来源**：十神生克
**验证**：Case 001（双丙劫财 + 巳比肩围攻申酉财星 → 需官杀子水护财，但子水孤立 → 必须靠外部制度护财）

### R20 · 刑冲的两面性

**规则**：子午冲、卯酉冲等刑冲并非"一律是坏"。在极端失衡命局中，冲掉过旺忌神反而是**好冲**（"两害相权取其轻"）。判断标准：

### R15 · 宫主星落宫（House Ruler Placement）

**规则**：占星中每个宫位有其"主星"（该宫宫头星座的守护星）。主星所落的宫位决定了该宫能量流向哪里。

**读盘优先级**：当看某个宫位时，三步走：

### R26 · 相位优先于星座宫位（占星读盘优先级）

### R27 · 相位无好坏，只有张力形态

**规则**：**没有"好相位 / 坏相位"，只有不同能量形态**。

- 和谐相位（拱 120° / 六合 60°）≠ 好：**容易但可能停滞**
- 合相（0°）= 能量融合或内在一体化
- 梅花（150°）= 能量不对称张力，需主动调整

**反直觉范例**：
- **Grand Trine（大三角）常被吹成"大吉"**——实际上常见于**"天赋流畅但缺行动力"**的懒惰命盘
- **T-Square 常被怕成"大凶"**——实际上是**大成就者常见配置**（长期拉扯=最强驱动力）

**输出脱毒**：
| ❌ 禁用 | ✓ 正确 |
|---|---|
| "你有 XX 凶相位，要小心" | "你有 XX 张力相位，会推动你在 X 领域经历痛苦的成长" |
| "你这个大三角超好" | "你的 X 领域有天赋流畅的配置，但也意味着容易因为太容易而不主动用它" |

**来源**：Tompkins 公理 2
**与 SKILL.md 同步**："张力揭示器不是选择机器"
**验证**：Case 004（火土燥烤 + 多个刑相位 → 内在压力但对应八字"先名后利"的动力源），Case 001（金火合的"触底线爆发"就是合相的动力学表达）

### R28 · 结构模式优先于单相位

**规则**：人不是一个矛盾，而是一套**系统性冲突**。读盘必须先找**结构模式**，再读单相位。

**七大结构模式**：

| 结构 | 构成 | 能量特征 | 典型输出 |
|---|---|---|---|
| **T-Square** | 2 颗对冲 180° + 第 3 颗对两者都 90° | 长期内在拉扯 = **最强驱动力** | "你在 X 和 Y 之间有长期张力，这是你最大的动力引擎" |
| **Grand Trine** | 3 颗互成 120° 等边三角 | 天赋流动 → **可能懒** | "你在某领域有天赋，但需要主动压力点激活" |
| **Grand Cross** | 4 颗互成对冲+刑 | 极度冲突 → 需长期整合 | "多维度张力同时在拉你，节奏管理是一生课题" |
| **Stellium（群星）** | 3+ 颗聚在同星座 / 同宫位 | 该领域能量**压倒性密集** | "你的人生主题集中在 X 领域，其他领域是次维度" |
| **Kite（风筝）** | Grand Trine + 一颗对冲点 | 大三角被激活 | "天赋被对冲点推动着展开" |
| **Yod（上帝之指）** | 2 颗六合 60° + 共同 150° 到第三颗 | 强制性转向 | "人生中 X 主题会反复强制你调整方向" |
| **Mystic Rectangle** | 2 对冲 + 2 拱 + 2 六合 | 稳定张力 = 平衡困难 | "你有框架把困难转成能力" |

**判定流程**：
1. 先扫描命盘找结构（容许度：合相/刑冲 8°、拱 8°、六合 4°）
2. 若命中多个结构，优先级：Stellium > T-Square > Grand Cross > Grand Trine > Yod > Kite > Mystic Rectangle
3. 无结构 → 按 R26 读关键单相位

**来源**：Tompkins 公理 4
**验证**：**Case 005 金牛 12 宫 Stellium**（火星 + 木星 + 土星集中 12 宫 = 隐藏的强者，能量压倒性在潜意识领域；这是单相位解读绝对抓不到的系统信号）
**配合 R21**：结构模式的收敛度是八字-占星交叉验证的高信号点

**操作系统框架（R28 核心升级）**：

每种结构不是"相位图鉴"，而是**人格的 operating system**。读盘不是罗列配置，是**识别当事人运行在哪个 OS 上**：

| 结构 | 操作系统本质 |

### R36 · 时间维度四层叠加诊断

**规则**：当用户问"某年/某阶段会怎样"时，**必须走四层叠加判断**，不能只看其中一层。

**核心隐喻**（来自用户 2026-04-24 框架）：
- **命盘** = 操作系统（你是谁）
- **大运** = 行业 / 赛道（10 年环境变量）
- **流年** = 市场波动（1 年触发事件）
- **Profection + Transit** = 当季天气（月级 / 季级精细节律）

**四层叠加读法**：

| 层 | 信息源 | 时间粒度 | 现有规则 | 问什么 |
|---|---|---|---|---|
| L1 命盘 | 四柱 + 十神结构 + 占星本命盘 | 终身 | R1-R15, R31-R35 | 你的底层操作系统 |
| L2 大运 | 10 步干支（paipan_engine 输出）| 10 年 | R16-R17 | 你在哪个赛道 |
| L3 流年 | 年干支 + 流年刑冲 | 1 年 | R20 | 今年市场什么波动 |
| L4 Profection + Transit | age mod 12 → 宫 + 外行星触碰 | 月 / 季 | R37 | 当季的短期天气 |

**判断流程**：
1. **先看 L1 基础倾向**：这是操作系统默认模式
2. **再看 L2 是放大还是抑制 L1**：10 年环境是助缘还是逆缘
3. **再看 L3 是否激活 L1+L2 的某主题**：流年是催化剂
4. **最后看 L4 给短期节律精度**：Profection/Transit 是当季天气

**跨层冲突的权重**：
- 通常 **L1 > L2 > L3 > L4**（结构 > 环境 > 事件 > 节律）

### R37 · Profection 计算规范

**规则**：Profection（希腊化年运）必须**按生日切换**，不是按公历年。

**公式**（两种等价系统）：
- **Modern**：house = `(completed_age % 12) + 1`
  - age 0 (出生至 1 岁生日) → 1H
  - age 37 (37-38岁生日之间) → 2H
  - age 38 → 3H
- **Hellenistic Life Year**：house = `((life_year - 1) % 12) + 1`，其中 `life_year = completed_age + 1`
  - LY1 (age 0-1) → 1H
  - LY 38 (age 37 complete) → 2H
  - LY 39 (age 38 complete) → 3H

**两系统数学等价**——只是术语不同。但**中文对"38 岁"的歧义会导致错误**：
- "38 岁" 在 Life Year 系统 = LY 38 = age 37 complete = **2H**
- "38 岁" 在 Modern 系统 = completed age 38 = **3H**

**R37 强制**：
1. 计算前先**明确约定**用哪个系统（默认 Modern，生日前/后都清晰对应一个 house）
2. 日期切换点**必须是生日**，不是公历年 1 月 1 日
3. 输出时**显式写出计算**："2025-08-01（age=37，跨过 6-20 生日）→ Modern 2H 摩羯 / LY 38 2H 摩羯"

**LOTY（Lord of the Year）**：
- LOTY = **激活宫宫头星座的传统守护星**
- 传统守护星（Hellenistic）：
  - 白羊→火星 / 金牛→金星 / 双子→水星 / 巨蟹→月亮 / 狮子→太阳 / 处女→水星
  - 天秤→金星 / 天蝎→火星 / 射手→木星 / 摩羯→土星 / 水瓶→土星 / 双鱼→木星
- **不用**现代守护星（Uranus/Neptune/Pluto）——Profection 是古法，用古配
- LOTY 的**本命落宫**很重要——该宫也被同步激活

**常见错误**：
- ❌ "38 岁 2 宫"（Modern 下应是 3 宫；Hellenistic 下 LY 38 可以是 2 宫但需说明）
- ❌ "水瓶 ruler 是 Uranus" → Profection 下是 **Saturn**（传统守护星）
- ❌ 公历年整体归一个 profection（必须按生日切）

**来源**：Hellenistic 复兴派（Chris Brennan《Hellenistic Astrology》+ Demetra George）+ 2026-04-24 skill 真实部署测试捕获的 off-by-one 错误
**验证**：Case 006 Profection
- 2025 早（age 36 / LY 37）→ 1H 射手，LOTY 木星落金牛 6H
- 2025-06-20 生日后（age 37 / LY 38）→ 2H 摩羯，LOTY 土星落射手 1H
- 2026-06-20 生日后（age 38 / LY 39）→ 3H 水瓶，LOTY 土星落射手 1H

**实现**：paipan_engine.py 的 `calculate_profection()` 同时输出两系统结果，避免约定歧义

### R38 · 八字日干互动判定

**规则**：合盘第一步是判定双方日干（日柱第一字）的五行 + 阴阳互动关系。

**七种互动类型**：

| 关系 | 含义 | 中式合婚类别 |
|---|---|---|
| **A 生 B**（A 的五行生 B） | A 是 B 的"印养" | **滋养型**（吉配之一）|
| **B 生 A** | B 是 A 的印养 | 同上反向 |

| **A 同 B**（同五行异阴阳）| 劫财——竞争型 | 平等带张力 |
| **A 不生不克 B** | 中性互动 | 看其他维度判断 |

**关键边界**：日干互动**只是基础**——不是"日干生身就一定好 / 克身就一定不好"。必须结合 R39 喜用神互补 + R40 地支配合 + R41 占星 Synastry 综合判断。

### R39 · 双方喜用神互补检查

**规则**：合盘第二步是把双方各自的喜用神（已通过 R1 v3 + R11 排除法判定）放一起对比。

**四种互补类型**：

| 类型 | 判据 | 含义 |
|---|---|---|
| **互补型** | 一方喜的是另一方有的 + 双方都各自需要的 | 极佳：互相填补缺口 ✓✓ |
| **共喜型** | 双方喜用神有显著重叠 | 良好：共同方向、价值观一致 ✓ |

**关键判定**：

#### 翻译合成流程（主 agent 必走）

收到 subagent JSON 后：


#### 输出前自检 checklist（最终输出每段过一遍）

- [ ] 这一段里**有没有** `R[数字]` 形式的规则号？有 → 删
- [ ] 这一段里**有没有未翻译的术语**？查词表，有 → 翻译或加括号注释
- [ ] 这一段里**每个抽象判断**是否接了"具体场景画面"或"具体行动"？没有 → 加
- [ ] 这一段读出来**像朋友讲话还是像学术论文**？像论文 → 重写
- [ ] 这一段是**让用户更清楚 / 更有行动感**还是**更焦虑 / 更不敢动**？后者 → 重写
- [ ] 是否使用了**生动的画面**和**具体生活情境**？没有 → 加
