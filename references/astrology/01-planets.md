# 01 · 10 行星完整光谱

**定位**：每颗行星的**四层诊断结构**——原型 / 健康表达 / 阴影面 / 扭曲防御。配合 R29（行星关系=角色冲突）使用。

**关键原则**：行星不是"吉凶标签"，是**内在子人格**。同一颗行星的健康形态和阴影形态差距可以比两颗不同行星还大。读盘时必须判断当事人**当前活在哪一层**（健康 / 阴影 / 防御）——这直接决定建议路径。

---

## 行星 ↔ 八字 "松散概念邻近性"（不是翻译表）

> ⚠️ **重要原则**：以下对照是**松散的概念邻近性**（loose conceptual proximity），仅用于跨体系思维的 orientation。
> **不做 1:1 映射。不用来翻译。** 两套体系独立发声，R21 交叉验证——不硬互译。

| 占星行星 | 八字邻近概念 | 备注 |
|---|---|---|
| 太阳 ☀ | 日元（日主） | 核心自我，但占星多了"生命力"层 |
| 月亮 ☽ | 印星（正偏印合并） | 情绪、母亲、滋养（注：八字印星也管"学业"，占星月亮不管）|
| 水星 ☿ | 食伤（食神偏伤官） | 思维、表达、信息（但食伤更多讲"输出"，水星讲"处理"）|
| 金星 ♀ | 财星（正财偏财合并） | 价值、关系、愉悦（八字财星是"被克之物"、占星金星是"被吸引之物"——哲学底层不同）|
| 火星 ♂ | 七杀 / 伤官（攻击性那面） | 行动、欲望、冲突 |
| 木星 ♃ | 正印 / 食神（扩张型）| 意义、信念、成长 |
| 土星 ♄ | 正官 / 偏印（限制型） | 结构、责任、延迟满足 |
| 天王星 ♅ | 无直接对应（伤官 + 七杀的"叛逆"极端）| 独立、断裂、突破 |
| 海王星 ♆ | 无直接对应（偏印 + 比劫的"消融"）| 融合、梦、边界溶解 |
| 冥王星 ♇ | 七杀极端 / 十二运中的"死绝墓"| 权力、转化、重生 |

**说明**：
- 天王、海王、冥王是现代行星（1781/1846/1930 发现），古典占星和八字体系都没有直接对应。它们承载的是**集体心理 / 世代主题**，个人层面的投射取决于宫位与相位。
- **哲学底层差异**：十神是"**关系对日元的作用**"（以日主为中心的相对论），行星是"**原型/心理功能**"（以集体心理为中心的绝对论）。所以"火星 ≈ 七杀"成立的是**现象层**（冲突能量）——**不是本体层**（同一东西）。

## ☀ 1. 太阳（Self · 核心自我）

**原型**：
- 自我认同 · 生命力 · "我是谁"

**健康表达**：
- 清晰自我感
- 有方向、有中心
- 不需要外界证明

**阴影面**：
- 自我膨胀（"我必须是中心"）
- 或完全失去自我（"我是谁不重要"）

**扭曲防御**：
- 用控制 / 权力证明存在感
- 或依赖外界定义自己

**读盘诊断线索**：
- 太阳落宫 = 自我投射的主要领域
- 太阳相位 = 自我表达遇到的内在阻力 / 助力
- 太阳 vs 上升的张力 = "我是谁" vs "我如何呈现"

---

## ☽ 2. 月亮（情绪系统 · 生存本能）

**原型**：
- 情绪 · 安全感 · 依附模式

**健康表达**：
- 情绪流动自然
- 能自我安抚
- 有内在安全感

**阴影面**：
- 情绪绑架（用情绪控制他人）
- 过度依赖
- 情绪反应过激 或 完全麻木

**扭曲防御**：
- 情绪操控（哭、冷暴力、PUA、愧疚绑架）

**读盘诊断线索**：
- 月亮星座 = 情绪默认反应模式
- 月亮宫位 = 安全感需要在哪个领域被满足
- 月亮 □ 土星 = 典型的"情感克制"主题（见 R29 范例表）

---

## ☿ 3. 水星（思维 · 认知系统）

**原型**：
- 思考 · 表达 · 信息处理

**健康表达**：
- 清晰、灵活、可沟通
- 能抽离情绪看问题

**阴影面**：
- 过度分析
- 焦虑型思维
- 话多但没结构

**扭曲防御**：
- 用理性逃避情绪（"讲道理型逃避"）

**读盘诊断线索**：
- 水星相位多 → 思维风格复杂，需要看是顺还是刑
- 水星刑月亮/上升 = 表达与情感/自我呈现不同步（典型"讲不清自己"）
- 水星逆行 = 信息处理走内向路径，慢但深

---

## ♀ 4. 金星（价值 · 关系 · 愉悦）

**原型**：
- 爱 · 审美 · 价值感

**健康表达**：
- 能建立平等关系
- 享受但不过度依赖
- 有审美和界限

**阴影面**：
- 讨好
- 情感依赖
- 用关系换价值感

**扭曲防御**：
- 表面优雅，内在空洞依附

**读盘诊断线索**：
- 金星落宫 = 价值感和愉悦的主要来源
- 金星相位 = 爱的表达模式
- 金星 □ 土 = 情感吝啬 / 晚婚 / 价值感与安全感绑定
- 金星 □ 海 = 牺牲型关系 / 无条件付出（见 Case 004）

---

## ♂ 5. 火星（行动 · 欲望 · 冲突）

**原型**：
- 直接行动 · 性能量 · 竞争力

**健康表达**：
- 直接表达欲望
- 有边界、有行动力

**阴影面**：
- 攻击性失控
- 冲动
- 压抑后爆发

**扭曲防御**：
- 被动攻击（冷战 / 隐性报复 / 讽刺）

**读盘诊断线索**：
- 火星星座 = 怎么打仗（白羊直接 / 天蝎隐藏 / 天秤讲道理）
- 火星宫位 = 能量用在哪个战场
- 火星 □ 冥 = 隐藏怒火 / 极致竞争议题

---

## ♃ 6. 木星（扩张 · 信念 · 意义）

**原型**：
- 意义系统 · 乐观 · 成长

**健康表达**：
- 有信念但不盲目
- 能成长、整合经验

**阴影面**：
- 过度乐观
- 膨胀
- 逃避现实问题

**扭曲防御**：
- 用"信念正确"掩盖问题（宗教性自欺 / 政治性站队）

**读盘诊断线索**：
- 木星落宫 = 先天"得贵人/扩张"的领域（配合 R14）
- 木星相位顺 → 天然幸运感
- 木星相位刑 → 信念系统需要经过痛苦校准

---

## ♄ 7. 土星（结构 · 责任 · 限制）

**原型**：
- 现实结构 · 规则 · 延迟满足

**健康表达**：
- 稳定、可靠
- 能承担现实压力

**阴影面**：
- 恐惧失败
- 压抑情绪
- 自我否定

**扭曲防御**：
- 冷漠、控制、过度克制

**读盘诊断线索**：
- 土星落宫 = 生命中的"课题宫位"（需要长期打磨）
- 土星回归（29 岁、58 岁）= 人生结构重整的关键节点
- 土星相位是"成熟之痛"的定位器

---

## ♅ 8. 天王星（自由 · 觉醒 · 断裂）

**原型**：
- 独立性 · 突破系统 · 突然变化

**健康表达**：
- 真正独立思考
- 不依附系统

**阴影面**：
- 反叛成瘾
- 逃避承诺
- 关系断裂

**扭曲防御**：
- 用"我不需要任何人"保护脆弱

**读盘诊断线索**：
- 天王落宫 = 生命中"规则必须被打破"的领域
- 天王与个人行星的相位 = 断裂/觉醒议题的具体舞台
- 天王相位刑 → 生活可能突然出现"被迫改变"

---

## ♆ 9. 海王星（融合 · 梦 · 解构边界）

**原型**：
- 连接性 · 灵性 · 想象

**健康表达**：
- 共情
- 创造力
- 灵性连接现实

**阴影面**：
- 逃避现实
- 成瘾
- 幻觉 / 理想化

**扭曲防御**：
- 自我欺骗（活在幻想）

**读盘诊断线索**：
- 海王落宫 = 生命中边界最模糊的领域（易理想化，也易被滥用）
- 金 □ 海 = 典型的"爱情理想化"主题
- 海王与上升合相 = 自我形象模糊，易被他人投射

---

## ♇ 10. 冥王星（权力 · 崩塌 · 重生）

**原型**：
- 深层控制力 · 转化 · 极端体验

**健康表达**：
- 面对阴影
- 深度重建
- 心理韧性

**阴影面**：
- 控制欲
- 操控关系
- 极端情绪

**扭曲防御**：
- 通过摧毁 / 控制 避免脆弱

**读盘诊断线索**：
- 冥王落宫 = 生命中必须经历"崩塌-重建"循环的领域
- 冥王与金星/火星相位 = 感情中的权力议题
- Case 005 的 7 宫冥王逆行 = 亲密关系中极致控制-放手议题

## 使用 SOP（配合 R29）

**读一个相位时的四层追问**：

1. **这两颗行星是谁**（原型层）
2. **当事人活在哪一层**（健康 / 阴影 / 防御）——关键问题：哪些具体行为体现他的"阴影"/"防御"？
3. **相位类型决定怎么互动**（见 `04-aspects.md`）
4. **连到具体生活场景**（不能停在"月土刑 = 情感压抑"这种标签）

**输出脱毒要求**：
- 不说"你金星刑土星"
- 说"你在**享受关系的愉悦**和**害怕被消耗**之间拉扯——这表现为你对投入感情保持距离，或只在可控场景里表达情感"
