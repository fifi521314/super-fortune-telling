## 1. 技术体系

### 1.1 排盘法

**四柱 = 年柱 + 月柱 + 日柱 + 时柱**，每柱各一天干一地支，合八字。

- **年柱**：以**立春**为分界（非农历正月初一），立春前生人年柱算上一年。
- **月柱**：以**节**（非中气）为分界。立春到惊蛰为寅月，惊蛰到清明为卯月，依此类推。月干用"**五虎遁**"口诀起："甲己之年丙作首，乙庚之岁戊为头，丙辛必定寻庚起，丁壬壬寅顺水流，若言戊癸何方觅，甲寅之上好推求"。
- **日柱**：查万年历 / 甲子表，无口诀。
- **时柱**：时支按 23-1 子时、1-3 丑时……固定对应。时干用"**五鼠遁**"口诀："甲己还加甲，乙庚丙作初，丙辛从戊起，丁壬庚子居，戊癸何方发，壬子是真途。"

**特殊处理**：

- **子时**：传统分"早子时"（0-1 点，算当日）与"晚子时"（23-0 点，算当日但时干按次日日干推）——此点即为一派分歧，梁湘润等主张晚子时仍以当日日干起时。
- **真太阳时**：八字本以真太阳时而非北京时间为准，需经度校正。公式：真太阳时 = 北京时间 + (当地经度 − 120°) × 4 分钟。
- **夏令时**：中国 1986-1991 年实行过夏令时，此期间出生者需减 1 小时。

**藏干**（人元）：地支内部藏天干，分本气/中气/余气。例：寅藏甲（本）、丙（中）、戊（余）；午藏丁（本）、己（中）。藏干是取格局与看用神的关键依据。

**纳音**：六十甲子配五行，如甲子乙丑海中金、丙寅丁卯炉中火。古法（李虚中、三命通会）重纳音论命，子平主流（明清以来）淡化纳音，仅作辅助参考。

### 1.2 十神

以**日干为我**，按与其他干支的五行生克 + 阴阳同异，定出十种关系：

| 关系 | 同阴阳（偏） | 异阴阳（正） |
|---|---|---|
| 同我者（比劫） | 比肩 | 劫财 |
| 我生者（食伤） | 食神 | 伤官 |
| 我克者（财） | 偏财 | 正财 |
| 克我者（官杀） | 七杀（偏官） | 正官 |
| 生我者（印） | 偏印（枭神） | 正印 |

**十神心性要点**（综合《滴天髓》《子平真诠》及近代归纳）：

- **比肩**：自我、同辈、独立、竞争。过多则"比劫夺财"。
- **劫财**：冲动、社交、合伙；异性缘强但易起纠纷。
- **食神**：才华、温和、口福。《子平真诠》："食神有气胜财官。"
- **伤官**：聪明、叛逆、锋芒。古训"伤官见官，百祸其端"；女命传统忌之（现代可再议）。《滴天髓》："伤官务要伤尽。"
- **正财**：稳健、储蓄、现实；男命主妻。
- **偏财**：灵动、大财、意外；男命主父 / 偏妻。
- **正官**：规矩、责任、名誉；女命主夫，男命主子。
- **七杀**：权威、压力、凶险；未制化则伤身。
- **正印**：学问、母亲、庇护、贵人。
- **偏印（枭）**：偏门学术、继母；"枭印夺食"为凶配。

### 1.3 格局

八字格局取法核心：**月令为提纲**。

**取格法**（《子平真诠》+《渊海子平》综合）：

1. 月支本气透天干 → 以本气十神取格（如寅月透甲，取比劫/建禄）。
2. 本气不透，余气/中气透 → 以透出者取格。
3. 地支三合 / 三会成局 → 以局气取格（如寅午戌合火局可取伤官格或食神格）。
4. 比肩不能取格；禄刃另立"建禄格""羊刃格"。

**八正格**：正官、七杀、正财、偏财、正印、偏印、食神、伤官。
**附两格**：建禄格（月令为日干之禄）、羊刃格（月令为日干之刃，仅阳干有正羊刃）。

**外格 / 特殊格局**：

- **从格**：从强、从旺、从杀、从财、从儿（食伤）——日主极弱无根，被迫顺从局中强势。
- **化格**：天干五合化气成真（如甲己化土、丁壬化木），需月令配合。
- **专旺格**：曲直格（木）、炎上格（火）、稼穑格（土）、从革格（金）、润下格（水）。
- **两神成象**（滴天髓系）：两五行相等成象，如木火通明、金水相涵。

**格局成败口诀**（子平真诠）：

> "财官印食，此用神之善而顺用之者也；煞伤劫刃，用神之不善而逆用之者也。当顺而顺，当逆而逆，配合得宜，皆为贵格。"

即：吉神（财官印食）需生助配合（顺用），凶神（杀伤刃劫）需制化为用（逆用）。

**格局高低**：

> "八字既有用神，必有格局，有格局必有高低……其理之大纲，亦在有情无情、有力无力之间而已。"——《子平真诠·论用神格局高低》

### 1.4 用神

**用神 = 命局中起关键驾驭作用的五行 / 十神**。近代徐乐吾、韦千里系统化归纳为五 / 六法：

1. **扶抑用神**：日主旺则抑（官杀、食伤、财），日主弱则扶（印、比劫）。为今日**主流派**（身强身弱派）核心。
2. **调候用神**：金水生冬 / 木火生夏，寒暖燥湿过偏需调节气候。《穷通宝鉴》核心立场。
3. **病药用神**：《子平真诠》："以扶为喜，则以伤其扶者为病；以抑为喜，则以去其抑者为病。除其病者，即谓之药。"《神峰通考》："有病方为贵，无伤不是奇。"
4. **通关用神**：两行相战引一中介（如金木交战以水通、水火交战以木通）。
5. **专旺用神**：气势偏于一方，顺其旺势（从格、化格、一行得气格）。
6. **格局用神**（子平真诠本义）：用神即月令取出之格，与近代"喜用神"含义略异——此处是重要流派分歧（见 §3）。

### 1.5 大运流年

**大运排法**：从月柱起，**阳男阴女顺排，阴男阳女逆排**（阳干年甲丙戊庚壬，阴干年乙丁己辛癸）。每步大运 10 年。

**起运岁数**：

- 阳男阴女（顺）：从生日顺数至下一个**节**（非气）的天数。
- 阴男阳女（逆）：从生日逆数至上一个节的天数。
- 折算：3 天 = 1 岁；1 天 = 4 个月；1 小时 = 5 天；1 时辰（2 小时）= 10 天。

**大运层级**：

- **大运**（10 年）→ **流年**（1 年，即太岁）→ **流月** → **流日** → **流时**。
- 大运定趋势基调，流年定具体事件。《子平真诠》："先看大运，再看流年。"
- 岁运并临 / 岁运相战时尤需谨慎。

**看运法**：

- 大运干支与原局十神关系 + 与用忌神关系 → 定吉凶。
- 重要节点：**交运**（两大运交接处，常有重大变动）、**岁运相冲 / 合**（如流年冲大运、伏吟、反吟）。

## 2. 四本经典详解

### 2.1 穷通宝鉴（栏江网 / 造化元钥）

**作者 / 流传**：明代余春台整理编定，原名《栏江网》，清初入日官之手易名《造化元钥》（康熙时抄本），清季光绪间余春台得之定名《穷通宝鉴》刊行。民国徐乐吾评注《造化元钥》、《穷通宝鉴评注》两版，韦千里亦作评。

**核心贡献**：

- 系统化**调候用神**体系——以"十天干配十二月令"为框架，共 120 个组合，每月十干各自需什么五行调候，查表即有方向。
- 口诀化："立一成以驭万变，秩然有序"（徐乐吾《造化元钥·序》）。

**用神哲学（调候派）**：

> "天道贵中和，气多偏驳，阳过则刚，阴过则柔，吉凶倚伏，祸福杂糅，谈命者藉此偏胜之隙，而察其端倪，造化元匙一书，独得其秘焉。"——《穷通宝鉴原序》

**代表金句 / 原文**：

1. **十干配十二月总口诀**（举例）：
   - "甲木……正月 丙、癸，丙火为主，癸水为佐。" "十一月 丁、庚、丙，丁先庚后，若有巳寅，则为上格。"
   - "十二月癸水，落地成冰，万物不能舒泰，专用丙火解冻。"
   - "戊土：三春戊土，无丙照暖，戊土不生；无甲疏劈，戊土不灵；无癸滋润，万物不长。"
2. "金以至阴为体，中含至阳之精，乃能坚刚……故金无火炼，不能成器，金重火轻，执事繁难，金轻火重，煅炼消亡。"（论金章）
3. "水不绝源，仗金生而流远，水流泛滥，赖土克以堤防。"（论水章）

**适用场景**：

- 寒暖燥湿严重失衡之命（如冬生金水、夏生火土过旺）——调候优先于格局。
- 查表入门，十干月令对照可快速得到方向。
- **争议**：被讥"查表式"、机械，徐乐吾自己评注时亦承认"原书作者文笔不甚通顺，颇有词不达意之憾"（《造化元钥·韦序》）。

### 2.2 滴天髓（+ 滴天髓阐微）

**作者 / 流传**：传为宋代京图撰，明代刘伯温（刘基）注，清代道光年间**任铁樵**增注成《滴天髓阐微》——后者才是今天命理界读的主要版本。民国袁树珊增辑；徐乐吾另作《滴天髓补注》《滴天髓征义》。

**核心贡献**：

- 最高阶理论体系，核心是**"衰旺"与"气势"**。
- 任铁樵注本强力批判古法神煞、格局执一、奇格异局，确立**以"日主衰旺、用神喜忌"为中心**的子平正脉。

**用神哲学（扶抑派 / 气势派）**：

> "能知衰旺之真机，其于立命之奥，思过半矣。"——《滴天髓·衰旺论》

> "旺则宜泄宜伤，衰则喜帮喜助，子平之理也。然旺中有衰者存，不可损也；衰中有旺者存，不可益也。旺之极者不可损，以损在其中矣；衰之极者不可益，以在其中矣。"——同上

任铁樵在《阐微》中大力抨击时弊：

> "妄谈人命，贻误不浅，混看奇格异局，一切神煞，荒唐取用，桃花咸池，专论女命邪淫……不论日主之衰旺，总以财官为喜，伤煞为憎，定人终身……何其愚也！"——《滴天髓阐微·知命》

**代表金句 / 原文**（论十天干，句句凝练，为滴天髓之精华）：

1. **甲木**："甲木参天，脱胎要火，春不容金，秋不容土，火炽乘龙，水荡骑虎，地润天和，植立千古。"
2. **乙木**："乙木虽柔，刲羊解牛，怀丁抱丙，跨凤乘猴，虚湿之地，骑马亦忧，藤萝系甲，可春可秋。"
3. **丙火**："丙火猛烈，欺霜侮雪，能锻庚金，逢辛反怯，土众生慈，水猖显节，虎马犬乡，甲来成灭。"
4. **丁火**："丁火柔中，内性昭融，抱乙而孝，合壬而忠，旺而不烈，衰而不穷，如有嫡母，可秋可冬。"
5. **五阳从气不从势，五阴从势无情义**。（论阴阳性情）
6. **"旺者冲衰衰者拔，衰神冲旺旺神发"**——论冲法关键口诀。

**适用场景**：

- 高阶命理分析；气势、从格、化格、病药等复杂命局。
- 任铁樵注本含大量真实案例，是古典命书案例最丰富者之一。
- **局限**：文辞简古，不读注几乎无法理解；易被滥用为"什么都能解释"的理论黑洞。

### 2.3 三命通会

**作者 / 流传**：明代进士万民英（字育吾）撰，成书万历六年（1578 年）。清《四库全书》收录，评"采撷群言，得其精要"。十二卷共 146 章，为古法 / 子平法集大成之百科全书。

**核心贡献**：

- **百科全书**，兼容并蓄：纳音论命、神煞系统、十神格局、胎元小运、六亲、女命、小儿、历代著名命造等无所不包。
- 保存了**大量早期古法资料**（珞琭子、鬼谷子、徐子平原始材料），以及三十多位名家的论命赋文（《元理赋》《消息赋》《喜忌篇》《继善篇》《玉井奥诀》《四言独步》《五言独步》等）。

**用神哲学（古法 / 子平兼容）**：

- 以**五行生克 + 月令 + 格局**为骨架，但**不放弃神煞、纳音、胎元**等古法。
- 代表了八字术从李虚中三柱古法（重纳音、神煞）向徐子平四柱新法（重十神、格局、用神）过渡的整合型体系。
- 《四库提要》批："其立论多取正官正印正财，而不知偏官偏印偏财亦能得力。知食神之能吐秀，而不知伤官之亦可出奇，是则其偏执之见，未为圆彻。且胎元等论施之今日，亦多有不验。"

**代表金句 / 原文**：

1. "唐李虚中独以日干为主，却以年月时合看生克制化，旺相休囚，取立格局。此发前贤所未发，故今术家宗之。"（卷三·子平说辨，也是 "子平术"命名的关键史料）
2. "天皇氏始制干支之名，以定岁之所在。"（卷一·原造化之始）
3. "运者，人生之传舍。探命之说，先以三元、四柱、五行、生死、格局致合，以定根基，然后考究运气，协而从之。"（卷二·论大运）
4. "继善篇"："用者，月令中所藏者……如甲木生于十一月，乃建子之月，就以子中所藏癸水为用神，其余以此类推。"——此即**月令即用神**的古典观念，与后来扶抑派"日主强弱定用神"不同。

**适用场景**：

- 查阅神煞、纳音、古赋、历代案例的工具书。
- 入门后拓展视野、理解八字术的历史层次。
- 不适合直接作入门教材——体系庞杂、古法新法杂陈，初学易迷失。

### 2.4 八字提要

**作者 / 流传**：韦千里（1911-1988），浙江嘉兴人，复旦中文系毕业，与袁树珊、徐乐吾并称"上海命学三大家"，与袁树珊有"南袁北韦"之誉。1946 年（35 岁）出版《八字提要》，1949 年移居香港。其嫡传弟子包括香港风水师李居明。

**核心贡献 / 独特形式**：

- 独创"**日干为主体，月支为提纲，时辰为归宿**"的四字组合查表法。
- 10 日干 × 12 月 × 12 时辰 = **1440 条组合**，每条给出简要评断。
- 极度适合职业批命师作为"起手思路"参考，是民国以来八字入门 / 应用教材的标杆。

**用神哲学（格局 + 扶抑 + 调候综合型）**：

- 继承《穷通宝鉴》调候传统（韦氏本人亦评注过穷通），兼采《子平真诠》格局与《滴天髓》衰旺。
- 比较务实、白话化，承担了民国以来子平古法现代化的关键过渡角色。

**代表金句 / 原文 / 案例**：

1. **韦千里自评八字**（辛亥 庚寅 庚午 辛巳，或另版辛亥 辛卯 庚子 庚辰，八字有不同版本记载，以下为广为流传的自评版本）：

   > "此为千里自造。识者咸谓憾于无火。然春金固非当令，乏土之生，则且无根，纵天干庚辛林立，《子平真诠》云'得三比肩，不如得一长生禄刃'。可见徒多比劫，而日元无气，非是真强。矧又亥卯会成木局，子辰会成水局，水与木皆有挫于金乎。火能熔金，有火固可显达，无火则一寒儒而已。然寒弱之金，逢微火当可得志，逢巨火则不胜其克……然则富贵皆无大望，我将永自韬养矣。"

   > ——此段为近代八字自批之最著名文字，展示了"身弱论 + 调候缺火 + 行运补救"的综合思路。

2. 《八字提要》序："看命先看此四字（日干、月支、时辰组合），此而知其轻重宜忌，则于整个命造，已思过半矣。"

**适用场景**：

- 职业命师快速查案参考。
- 近代中文命理语汇的标准教材（把文言术语翻译成白话）。
- 局限：1440 条毕竟是"大方向"，真正批命仍需回到原局整体分析。

## 3. 流派分歧（不调和，直接并列）

### 3.1 扶抑派 vs 调候派（《滴天髓》 vs 《穷通宝鉴》）

**核心冲突**：日主强弱是命理的第一出发点，还是月令寒暖才是？

- **滴天髓 / 任铁樵派**：命理第一要义是"能知衰旺之真机"。日主旺则泄伤，衰则帮助。调候只是衰旺体系下的子问题。
- **穷通宝鉴 / 余春台 / 韦千里调候派**：寒暖燥湿的调候是"头等大事"——无论格局多好，若寒暖失调，万物不生。寒木无火，纵有正官七杀，亦是空中楼阁。
- **现代调和派看法**（大陆主流）：调候用神具有"一票否决"的优先性——"凡四柱八字需调候者，虽见官杀印食伤，一概暂缓论之"（二手归纳）。但格局派反驳：这是抹杀《子平真诠》本义。
- **原文证据对照**：
  - 滴天髓："能知衰旺之真机，其于立命之奥，思过半矣。"
  - 穷通宝鉴："天道贵中和……造化元匙一书，独得其秘焉。"

### 3.2 格局派 vs 盲派（子平正脉 vs 江湖师承）

**核心冲突**：命局以"月令格局 + 用神"为纲，还是以"做功 / 体用 / 宾主"为纲？

- **格局派（子平正脉，又称书房派）**：《渊海子平》→《三命通会》→《子平真诠》→ 现代。以月令格局为中心，把八字按结构分类，用神贯穿全局。代表：沈孝瞻、任铁樵、韦千里、徐乐吾。
- **盲派（江湖派，口传心授）**：号称仅在盲师中口口相传，未见于古书（**但源头仍在《渊海子平》《三命通会》里**，近年未师姐、段建业均承认"盲派与子平同源"）。段建业 2002 年正式创立现代盲派体系（段氏命理）。
  - 核心概念：**宾主、体用、做功、功神、废神、贼捕、墓绝**。
  - **不看日主旺衰，不看用神**，只看八字整体的"做功关系"（刑、冲、克、穿、合、墓）。
  - 强调"一动就是应期"——对事件时间点、六亲、生死、生男生女、排行判断特准（二手归纳）。
  - 代表人物：段建业（山西，理论派）、杨清娟（实战派）、郝金阳（盲师源头）。
- **证据 / 文献对照**：
  - 段建业派："盲派不用大小运、命宫、胎元、息元等，只看命局中的八个字，就能断出好几条甚至 10 多条命主的信息"（《段建业盲派技法研究综述》）。
  - 书房派反驳：盲派口诀无一不出自《渊海子平》《三命通会》《玉井奥诀》《气象篇》《女命八法》等古籍，仅是某些技法被练到极致（未师姐 2026 观点）。
- **现实张力**：盲派快、狠、准于具体事件；格局派系统、逻辑完整但常"算不准具体什么时候"。

### 3.3 古法 vs 新法（纳音论命 vs 十神论命）

- **古法（李虚中 → 珞琭子 → 三命通会前半）**：年柱为主（李虚中原本是三柱），重**纳音五行**（如"海中金""炉中火""大林木"）+ **神煞**（天乙贵人、将星、华盖、劫煞、亡神）。
- **新法（徐子平以后）**：日干为主，四柱八字，重**十神 + 格局 + 用神**。纳音降为辅助，神煞被任铁樵等斥为"荒唐取用"。
- **《三命通会》的独特价值**：它是两套系统的**最后一本共存之书**，之后的命理书基本只剩新法。

### 3.4 真诠派 vs 真铨派 vs 月令格局派（子平格局派内部）

近代格局派内部细分（二手归纳）：

- **月令格局派**：直接以月令主气取格，不必透干。代表《渊海子平》《三命通会》。
- **子平真诠派**：重视月令透干，透干才能定格。代表《子平真诠》。
- **子平真宗格局派**：根据月令人元司令透干与否分格，最严格。

### 3.5 身弱论 vs 从格论（关于弱极命局）

- **扶抑主流**：日主弱则扶。
- **滴天髓从格说**："五阳从气不从势，五阴从势无情义"——阴干日主弱到极点时可顺从，阳干则不轻易从。任铁樵补：弱极不可益，益则反凶——即从格的理论基础。

## 4. 预测域边界

### 4.1 擅长

1. **命格层次判断**：格局高低（贵贱富贫的整体量级）。
2. **六亲结构**：父母、兄弟、配偶、子女的多寡、吉凶、大致性情（盲派在此尤强）。
3. **财官层次**：事业、财富的类型和量级。
4. **大运阶段性趋势**：十年一大运，哪十年顺、哪十年背。
5. **身体结构 / 疾病倾向**：通过五行缺失、冲克（如子水肾、午火心）看身体先天结构。
6. **性格心性**：十神配置（伤官叛逆、食神温和、比劫冲动、印星保守）。
7. **适合行业方向**：格局 + 用神指向（如食神生财适合创意、伤官配印适合学术）。

### 4.2 不擅长

1. **具体事件时间点**：八字给趋势，精确到"何月何日发生何事"需结合**六爻、奇门、梅花**等占卜类（即时事件预测）。盲派在此相对强，但系统性仍有限。
2. **人际互动细节**：谁是朋友、谁是小人、具体关系走向——**紫微斗数**以 12 宫分人事关系更细。
3. **空间 / 方位**：方位吉凶是**风水**的范畴，八字只能给出大方向（喜神方位）。
4. **现代生活具体场景**：古代命书未覆盖现代职业（程序员、UP 主、DAO 成员），需类比，误差大。
5. **同盘不同命**：双胞胎、同时辰生人命运差异大——八字理论本身有天花板，需结合出生地、家世、教育背景看（现代学者陆致极等人试图量化修正，仍在探索）。

## 5. 经典案例

### 5.1 乾隆皇帝（爱新觉罗·弘历，1711-1799）

**八字**：辛卯（康熙五十年）丁酉（八月）庚午（十三日）丙子（子时）
**大运**（6 岁起）：丙申、乙未、甲午、癸巳、壬辰、辛卯、庚寅、己丑、戊子

此八字为**《清宫档案》**正式记载的官方八字——乾隆出生后由康熙御用命理师批断，当时批命者不知该婴儿将为皇帝。后《滴天髓阐微》任铁樵亦收此案例，清后诸多命理家用作案例研习。

**康熙朝原批语**（清宫档案）：

> "此命富贵天然，这是不用说。占得性情异常，聪明秀气出众，为人仁孝，学必文武精微。幼岁，总见浮灾，并不妨碍。运交十六岁为之得运，该当身健，诸事遂心，志向更佳。命中看得妻星最贤最难，子息极多，寿元高厚。柱中四方成格祯祥，别的不用问。"

**格局分析要点**：

- 日主庚金生酉月，**羊刃格**（酉中辛金）；时上丙火七杀透出 → **羊刃驾杀**（古典贵格）。
- 地支**子午卯酉四位纯全**——滴天髓所谓"支全四正，气贯八方"，为天赋极厚的强势命造。
- 杀刃相当、又无食伤破格 → 威权名望之格。批语"子午酉卯成大格，文武经邦"即指此。
- 中年大运南方火运（甲午、癸巳、壬辰）助杀制刃，为鼎盛期。61 岁辛卯运以后盛极而衰。

**意义**：展示"羊刃驾杀"+"四位纯全"两个古典贵格如何叠加，是子平派分析帝王命的标准案例。

### 5.2 徐乐吾（1886-1949，民国命理大家）

**八字**：丙戌 壬辰 丙申 丙申
**大运**：癸巳 甲午 乙未 丙申 丁酉 戊戌（10 岁起运）

**徐乐吾自批**（《滴天髓补注》或《古今名人命鉴》载）：

> "天干三丙，通根戌库，弱是之微旺，三月天热，火微泄气于土，故必须壬甲并透……但用杀不可以言制，壬水通根于申，又得辰申相拱，独杀顽强，丙临申位绝地，虽通根戌库，干得两丙一辛，亦非强势……六十二岁丁亥冲命，火又被泄克，寿元至此而终……"

**分析要点**：

- 丙生辰月杂气，壬水七杀透出，申辰拱水局，**七杀立格**。
- 唯一印星乙木藏辰中，制杀乏力；以戊土食神制杀。
- 日时**丙申伏吟**——申为妻星 + 偏财（父），故二妻两子两女，父早亡。
- 徐自言戊运为忌，遂把名字"徐乐吾"改为"徐乐戊"（把忌神放入名中），果于戊运丁亥年（1947，其预言的 62 岁）去世（实际 1948/1949 年卒，略有出入，二手转述）。

**意义**：命师自批 + 自我验证的罕见范例，展示"七杀格 + 食神制杀"的实战分析流程；也暴露了命理"预测自己死期"的局限性争议。

### 5.3 韦千里自造（见 §2.4）

已在"八字提要"部分详引。此案例的独特价值：**身弱论者自批自身"富贵皆无大望"**——展示了子平派对"徒多比劫而日元无气"的判断逻辑，以及"火为用神而无火"的调候观，同时也说明命师对自己的预测常常悲观。
