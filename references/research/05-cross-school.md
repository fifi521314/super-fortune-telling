## 0. 执行摘要（给 skill 架构决策）

1. **三大系统不在同一本体论坐标上**。八字是"身体/命格/能量"，紫微是"关系与事件舞台"，占星（尤其心理占星）是"内在原型/心理倾向"。"谁更准"是错问题——更准确的问法是"这个问题落在哪个系统的强项维度"。
2. **真正的互斥主张 <10%**。大部分"冲突"是（a）主语不同层 / （b）适用域不同 / （c）翻译不对齐。真正冲突集中在**合婚、创业、搬家、健康警报**四类场景。
3. **现有混合派（台湾/香港/印度）普遍采用"强项分工 + 冲突不强解"**，不是加权投票也不是强行统一。
4. **推荐本 skill 用三层策略：维度正交（默认）+ 底线共振（警报）+ 冲突明示 layered（博弈）**——既非投票，也非纯分歧。

### 1.1 核心对比表

| 维度 | 八字 | 紫微斗数 | 西洋占星（现代） |

### 1.2 四组关键差异

**(A) 八字 vs 占星**：八字问"你是什么材质/如何被建造/何时行动"；占星问"你是什么心理/为何这样感受"（Write A Catalyst 2026 精辟总结）。

**(B) 紫微 12 宫 vs 占星 12 宫**：紫微 6 宫直接讲人际（夫妻/兄弟/子女/父母/交友/奴仆）；占星只 2-3 宫。**紫微在人际网络上天然更细；占星在自我-潜意识-灵性上更细**。

**(C) 中国"命"vs 西方"fate"**：中文"命"是"初始条件 + 可协商的天命"（MingShu Library 2026; Ning Chen 1997）；西方 fate 从 Oedipus 传统到 Liz Greene 被重新定义为"nature 的展开"。三派在 agency 上**比表面更趋同**。

**(D) Tarnas 的 archetypal cosmology 与董仲舒的"天人感应"本体论底层相通**——都是 correlative cosmology（Richard J. Smith）。三派技术不同，但哲学底层其实共享 synchronicity/correlation 的核心假设。

## 3. 互斥主张案例集（核心章）

### 案例 1：八字"身弱忌财"vs 星盘"强 Venus 合 MC"
1985 年 8 月午时生女性。八字甲木生午月身弱财旺，传统断"为财奔波、反因财伤身"。星盘 Venus 合 MC 天顶，传统断"职业与美/奢侈契合，财来光环加持"。实际：奢侈品行业高管年入数百万，但焦虑失眠、两次婚姻失败。**两派都对一部分**——占星看对"财富来源原型"，八字看对"承载力与健康/关系代价"。不是真冲突，是同一现象两侧面。来源：mingshu.art + 籟柏 vocus.cc。

### 案例 2：紫微"命宫太阳化忌"vs 星盘"木星合 MC"
1978 年香港男性。紫微断"事业辛劳、易与权威冲突"；占星断"事业扩张被提拔"。实际：公务员体系 20 年受压 → 40 岁辞职创业迅速成功。**紫微描述"在既有权威结构中"的处境，占星描述"在自己主宰结构中"的扩张**。两派都真实，适用域不同。教训：skill 应主动问"你当前在什么权威结构里"。来源：Brennan ep.482 Berna Lee 同类案例 + 香港命理圈。

### 案例 3：Venus 合 Pluto（synastry）vs 八字日柱相冲
北京异地恋合婚。占星：男 Venus 合女 Pluto = 吸引但控制/强迫。八字：男甲子、女庚午，**子午冲 + 甲庚冲**，婚姻难久。**这其实不是冲突——两派同向警告**。但咨询者 cherry-pick 听自己想听的，结婚两年离婚。教训：skill 要**主动合成同向警告**，防止选择性接收。来源：cafeastrology Venus-Pluto 案例库 + 小红书匿名帖。

### 案例 4：紫微"夫妻宫贪狼"（桃花不稳）vs 八字"日支正印坐禄"（婚姻稳）
1990 年台湾女性。紫微断"配偶魅力、桃花多、不稳"；八字断"婚姻结构稳定、配偶有母/父性"。实际：丈夫大学教授，外有桃花吸引力但自身选择稳定，婚姻良好。**紫微描述"那个人"（特质），八字描述"那段关系"（结构）——可并存**。教训：很多冲突实为主语不同层；skill 必须明确"谁/哪个层面"。来源：adm.com.tw 府相居士 + tg168.com.tw。

### 案例 5：Astrocartography 木星线东京 vs 八字"忌东方木"（最硬的真冲突）
1992 年上海男性考虑搬去东京。Astrocartography：东京在 Jupiter MC 线，"事业扩张名声"。八字：甲木生春过旺忌木，东方属木克身。**两派在同一建议上真冲突，都有理据**。李居明式混合派处理方法：**接受占星事业建议，同时用八字喜忌加强补救**（金属色装饰、辛辣饮食、避木屋）——不投票、layered。来源：Jim Lewis *Astro*Carto*Graphy* + 李居明《饿命改运学》。

### 附：结构性冲突模板
- **模板 A**：紫微大限"武曲化禄"（进账旺）vs 八字大运"劫财"（存续弱）——描述不同层（进款 vs 留存）。
- **模板 B**：Saturn transit 10 宫 vs 紫微流年官禄化权——表面冲突，实际都讲"权力+考验"，是翻译不对齐造成的伪冲突。

**§3 小结**：真本体论互斥 <10%；同向警告被误拆更常见（案例 3）；**地理 × 五行（案例 5）是真硬冲突**，必须 layered 而非投票。

## 4. 博弈汇总方法论

### 4.1 现有混合派的做法
- **台湾主流**（籟柏 vocus、府相居士、抱猫少女）：**"八字定体、紫微定用、占星补心理"**。籟柏原文："不要為了一致而強解...不一致就不一致。"
- **大陆偏保守**（易德轩）："八字为主，星座为辅"。
- **Komilla Sutton**（Vedic + Western）：**不混合计算，但跨看**。"Western 擅心理，Vedic 擅实务，是同一人格两条路径。"
- **李居明**（激进整合）：八字+紫微+风水+藏密+西方；"饿命改运学"用五行指导地理/颜色/饮食（东方版 astrocartography）。代价：系统严密性弱化。
- **Tarnas / Liz Greene / CPA**：不跨东方系统，但其 archetypal cosmology 本体论与东方 correlative cosmology 相通。
- **Chris Brennan**：做跨文化对谈（ep.181/459/482），立场"尊重差异、不强行统一"。

### 4.2 四种策略优劣

| 策略 | 优 | 劣 | 适用 |
|---|---|---|---|
| 加权投票 | 明确 | 权重是隐含假设；无法处理主语不同层 | 仅特定场景 |
| 保留分歧 | 尊重 | 用户 cherry-pick（案例3）；无 actionable | 研究用 |
| 维度正交 | 尊重强项 | 同维度硬冲突（案例5）无解 | 大部分场景 |
| 底线一致 | 可靠 | 过滤太多信号 | 作为警报层 |

顶级混合派都用**混合策略**，不是单一。

### 4.3 推荐给 skill 的策略：**三层"维度正交 + 底线共振 + 冲突明示 layered"**

**Layer 1（默认）维度正交**：每个 subagent 在强项维度独立给断语。八字主攻性格骨架/财富/健康/时机；紫微主攻婚姻对象/人际网络/宫位事件；占星主攻心理深度/灵性/地理/时代主题。

**Layer 2（警报）底线三派共振**：在**合婚/重大职业/健康警报/搬家**四类场景启用共振检测：
- 三派一致同向 → 高置信输出
- 两派一致一派反对 → 中置信 + 显示反对观点
- 三派完全分歧 → 进 Layer 3
- **关键价值**：解决案例 3 的"同向警告被误拆"问题——系统主动合成。

**Layer 3（博弈）冲突明示 + 主语对齐**：真冲突时：
1. 先做**主语对齐检查**（参见模板 B：很多伪冲突在此消失）
2. 对齐后仍冲突：明示冲突 + 各派适用条件（不投票）
3. 给用户一个**元问题**（"你想从能量、事件、还是心理层面考察？"）让用户主导博弈方向

**为什么不用替代方案**：加权投票会把权重假设锁死系统；纯分歧让 skill 失去决策价值；纯正交无法处理硬冲突；纯底线过滤太多信号。

**与用户原意契合**：用户说"多流派并陈 + subagent 博弈得出结论" = Layer 1 并陈 + Layer 2/3 博弈。

**实现硬性要求**：
1. 每个 subagent 输出必须带**置信度 + 适用维度标签**
2. 必须有**主语对齐**预处理
3. 合婚/搬家/创业/健康四场景用独立共振模板
4. 永远保留 user override（终极 agency，对应"知命立命"哲学底色）

## 7. 整合失败案例

1. **强行中西互译**（紫微主星 = 希腊诸神、Dragon = Leo 等）——两系统的元素身份认同机制根本不同，贪狼 ≠ Venus。Nova Masters Consulting 明确警告"wrong framework"。
2. **仪式化拼贴**（小红书三份报告 AI merge）——信息过载 + Barnum 效应 + 失去每派深度。光子星球/Sohu 批评。
3. **权威依赖**（李居明徒弟无法独立验证整合套餐）——教训：subagent 必须能独立自洽，整合层只做元仲裁不做本体重构。
4. **用一方正当化另一方**（"三派都说离婚所以一定离婚"）——三派基于不同本体论，字面一致不等于实质一致，会创造**虚假置信度**。Layer 2 必须做概念对齐检查而非字面匹配。
5. **心理学降维 / 术数化**（八字被"心理学化"丢掉身体-时机维度；占星被"术数化"丢掉心理深度）——每个系统保持原生解读风格，翻译只在用户语义层做，不在系统本体层做。

## 结语：对 skill 核心架构的 3 条硬建议

1. **不要让 subagent 互相投票**。命理不是民主。Layer 1 正交是默认，Layer 2 共振是警报，Layer 3 明示是真博弈——投票是最偷懒的设计。
2. **必做"主语对齐"预处理**。大量表面冲突其实是主语不同层、层次不同、翻译不对齐。跳过会让博弈层充满噪音。
3. **把工程复杂度集中在"合婚、创业、搬家、健康警报"四类场景的共振模板**。其他场景默认 Layer 1 即可。

**冲突本身是 skill 的产品价值**——传统命理师给三个冲突答案让用户困惑；本 skill 的正确输出是"这里共振、这里分歧、分歧根源是 X"。这是单一命理师做不到、AI-in-council 才能做到的。
