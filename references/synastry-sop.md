# 合盘 SOP · 双方关系结构分析（八字合婚 + 占星 Synastry）

**定位**：当用户问"合盘 / 合婚 / 我和他合不合 / synastry / 双方匹配度 / 关系预测"等**关系比较问题**时，主 agent 必须按本 SOP 走。

**本文件配合 R38-R42（合盘核心规则）使用**。

---

## 🚫 启动前的硬边界检查（**必走，不可跳**）

### 1. 双方同意检查（Hard No #3 防御）
- 用户必须**明确说明双方都同意被分析**
- 若任何信号显示是"单方背着对方做的合盘" → **退回拒做**
  - 信号：用户问"我朋友想知道他对我的感情" / "我背着他想看看" / "他不知道我在算"等
- 应对脚本："合盘需要双方都知情同意。如果对方不知道，我可以只看你的命盘 + 你在关系中的结构张力——但不排对方盘。"

### 2. 关系操控检测（Circuit Breaker #12）
- 关键词触发：**"克星 / 克夫 / 克家 / 孤星" + 伴侣要求隐藏关系**（不见家人、不发合照、不说关系）
- → **立即退出，不排合盘**
- 应对："我不排这盘——无论盘怎么显示，都不改变一件事：要求伴侣隐藏关系不是命理问题，是关系控制模式。"

### 3. 关系决策"军火库"防御（Reframe #14 加强版）
- 若检测到"**外部命理判决已被当作分手 / 复合 / 结婚理由**"
- → **优先不排盘**，先问："如果命理显示支持，关系会回心吗？如果不会，那需要看的不是盘，是沟通。"

### 4. Hard No #4 永远生效
- ❌ 不预测"他爱不爱我 / 她对我什么感觉"
- ❌ 不预测"会不会结婚 / 何时分手"
- ❌ 不给"应不应该在一起"的判决
- ✅ 只描述"双方结构上如何互动 / 哪些维度互补 / 哪些维度需工作 / 代价是什么"

### 5. Reframe 强制
- 用户原问："我和他合不合 / 我们能不能成"
- **Reframe 后**："你们的结构在哪些维度互动？哪些张力是你们的合作素材？哪些代价需要双方主动认识？"

## 📥 输入收集

| 必需 | 说明 |
|---|---|
| **双方完整生辰** | 年月日 + 时间 + 出生地 + 性别 |
| **双方同意确认** | 用户明确说明 |
| **关系当前状态** | 已在关系中？刚开始？考虑中？分开后回看？——决定输出语气 |
| **关注主题（可选）** | 长期承诺 / 日常相处 / 工作伙伴 / 师友 / 不指定 |

## 🀄 八字合盘流程（5 步）

### Step 1 · 日干互动（R38）

排盘后获取双方日干（日柱第一字）。判定基础互动：

| 关系 | 含义 | 中式合婚类别 |
|---|---|---|
| **A 生 B**（A 的五行生 B 的五行）| **A 是 B 的"印养"** | 滋养型（经典吉配之一）|
| **B 生 A** | B 是 A 的印养 | 同上反向 |
| **A 克 B**（同阴阳）| 七杀克——压制感强 | 克伐型 ⚠️ |
| **A 克 B**（异阴阳）| 正官克——温和约束 | 克伐型轻 |
| **A 同 B**（同五行同阴阳）| 比肩——同伴型 | 平等型 |
| **A 同 B**（同五行异阴阳）| 劫财——竞争型 | 平等带张力 |
| **A 不生不克 B** | 中性互动 | 看其他维度 |

**输出**：
> "双方日干 [A] vs [B] = [互动名]——**[滋养 / 平等 / 克伐 / 中性]**型基础"

### Step 2 · 喜用神互补检查（R39）

获取双方各自的喜用神（已通过 R1 v3 + R11 排除法判定）。

**四种互补类型**：

| 类型 | 判据 | 含义 |
|---|---|---|
| **互补型** | 一方喜的是另一方有的 + 双方都各自需要的 | 极佳：互相填补缺口 |
| **共喜型** | 双方喜用神有重叠 | 良好：共同方向、价值观一致 |
| **相反型** | 一方喜的是另一方忌的 | 警示：生活方式偏好结构相反 ⚠️ |
| **单向型** | 一方对另一方有用、反向无用 | 不平等：A 滋养 B 多于 B 滋养 A |

**输出**：
> "互补类型 = [类型]——
> A 能给 B 的：[A 喜用神中 B 需要的]
> B 能给 A 的：[B 喜用神中 A 需要的]
> 共同警惕：[共忌神]"

### Step 3 · 地支刑冲合害扫描（R40）

把双方四柱 8 个地支放一起扫描：

**关键互动类型**（按重要度）：
1. **伏吟**（同地支重复）：双方地支有相同字 = **加重共同能量**——是好是坏取决于这个字是双方的喜还是忌
   - **若是双方共喜** = 极佳的"能量共振"
   - **若是双方共忌** = ⚠️ **互相加重对方失衡**——长期相处加重消耗
2. **冲**（六冲：子午 / 卯酉 / 寅申 / 巳亥 / 辰戌 / 丑未）：双方核心位置之冲 = 节奏摩擦
3. **三合 / 半合**（亥卯未 / 寅午戌 / 巳酉丑 / 申子辰）：能量集结 = 共同氛围被强化
4. **六合**（子丑 / 寅亥 / 卯戌 / 辰酉 / 巳申 / 午未）：温和结合
5. **刑**（寅巳申 / 丑戌未 / 子卯 / 辰午酉亥自刑）：内在张力
6. **害**（子未 / 丑午 / 寅巳 / 卯辰 / 申亥 / 酉戌）：暗中拉扯

**输出**：
> "地支互动：
> - 伏吟 [字]（共[喜/忌]）= [加重某能量]
> - 冲 [对]（位置：双方[柱]）= [节奏 / 决定 / 关系核心摩擦]
> - 合 [对] = [能量集结 / 共同氛围]"

### Step 4 · 配偶星呼应（R38 衍生）

每个人的命局有自己的"配偶星"五行：
- 男命的妻星 = 财（正财 + 偏财）
- 女命的夫星 = 官（正官 + 七杀）

判定：
- **对方的日干五行 = 自己的配偶星五行** → **直接对应** = 命局自然认对方为伴侣
- **对方日干五行 ≠ 自己的配偶星五行** → **不直接对应** = 关系可能更像师友 / 朋友 / 工作伙伴而非传统"夫妻位"
- **配偶星在原局位置**（透干 / 藏支 / 在哪柱）= 影响该人对配偶的潜意识需求

**输出**：
> "配偶星结构：
> - A 的配偶星 = [五行]，[B 的日干是否对应]
> - B 的配偶星 = [五行]，[A 的日干是否对应]
> 解读：[直接对应 / 不直接对应] = [关系定位偏向]"

### Step 5 · 大运 / 流年同步性（R42）

获取双方各自当前大运 + 当年流年（paipan_engine 输出）。

**判定维度**：
1. **大运起止时间是否重叠**
2. **大运十神能量方向**（顺 / 逆 / 异向）
3. **当前流年对双方的影响**（一方顺另一方逆？同顺？同逆？）

**四种节奏**：
| 类型 | 含义 |
|---|---|
| **同步顺** | 双方都在用神大运 = 共振扩张期 |
| **同步逆** | 双方都在忌神大运 = 共振承压期 |
| **逆向** | 一方顺一方逆 = 节奏不同但可互补 |
| **完全异向** | 大运能量主题完全不同 = 各走各的 |

**输出**：
> "节奏分析：
> - A 当前 [大运] = [顺 / 逆]
> - B 当前 [大运] = [顺 / 逆]
> - [当前年份] 流年对 A = [影响] / 对 B = [影响]
> 综合：[同步顺 / 同步逆 / 逆向 / 异向]"

## 🔮 占星 Synastry 流程（5 步）

### Step 1 · 关键互相相位（R41 第一优先级）

扫描双方行星之间的相位（一方的行星 vs 另一方的行星）。

**优先级排序**（重要性）：
1. **个人行星之间**（日 / 月 / 水 / 金 / 火 互相）—— 最直接
2. **个人行星 ↔ 社会行星**（个人 ↔ 木 / 土）—— 性格骨架对话
3. **个人行星 ↔ 外行星**（个人 ↔ 天 / 海 / 冥）—— 世代议题投射
4. **个人行星 ↔ 四轴**（个人 ↔ ASC / MC / IC / DSC）—— **极重要**

**经典关系相位（必查）**：
| 相位 | 含义 |
|---|---|
| Sun-Moon | 灵魂层基础（"灵魂伴侣"信号之一）|
| Sun-Venus / Moon-Venus | 爱与认同 |
| Venus-Mars | 化学反应 / 性吸引 |
| Sun-Sun / Moon-Moon | 自我表达 / 情感节奏匹配度 |
| Saturn 接触个人行星 | 长期承诺潜质 / 限制感 |
| Pluto 接触个人行星 | 转化深度 / 控制议题 |
| Mars-Mars | 行动节奏 |

**容许度**：
- 0-1° = ★ 极紧（强信号）
- 1-3° = 紧
- 3-5° = 中
- 5-8° = 宽松（仅参考）

### Step 2 · 行星落宫（R41 第二优先级 · 极重要）

**这是 Synastry 最核心的部分**：A 的行星落在 B 的什么宫位 = A 在 B 的命盘里激活什么场域。

**计算**：
- 取 A 的行星黄经
- 比较 B 的 12 宫宫头（Placidus 默认）
- 该黄经在 B 的哪个宫内 = A 落 B 的某宫

**关键解读**：
| 落宫 | 含义 |
|---|---|
| **A 多颗行星落 B 1H** | A 强烈影响 B 的自我表达 / 身份感 |
| **A 多颗行星落 B 7H** | **A 在 B 的命盘里扮演"伴侣型"角色** ⭐ |
| **A 多颗行星落 B 8H** | A 触动 B 的深度 / 共享资源 / 转化议题 |
| **A 多颗行星落 B 12H** | A 在 B 的潜意识 / 隐性维度——**不一定公开伴侣型** ⚠️ |
| **A 落 B 4H** | A 触动 B 的家 / 根基 / 情绪基底 |
| **A 落 B 5H** | A 激活 B 的创造 / 浪漫场域 |
| **A 落 B 11H** | A 是 B 的社群 / 朋友 / 理想型存在 |

**重要诊断**：**双方落宫是否对称**
- 对称（A 落 B 7H + B 落 A 7H）= **互相认对方为伴侣** ✓
- **不对称**（A 落 B 7H + B 落 A 12H）= **公开 / 隐性定位不对等** ⚠️

### Step 3 · 操作系统配合（R28 应用到合盘）

把双方各自的主操作系统（T-Square / Grand Trine / Stellium / Kite / Yod）放一起：

| 配合 | 含义 |
|---|---|
| **同型 OS** | 共振强但缺乏互补 |
| **驱动型 + 顺流型**（T-Square + Grand Trine）| **极强互补**：一方提供动力一方提供天赋 |
| **聚焦型 + 漫游型**（Stellium + Multiple aspects）| 一方专一 / 一方多元 |
| **结构型 + 突破型** | 一方稳定 / 一方颠覆 |

### Step 4 · Composite Chart（可选 · 关系本身的命盘）

Composite = 双方行星的中点 = 关系本身作为"独立实体"的命盘。

**计算**：每颗行星 = (A 的该行星黄经 + B 的该行星黄经) / 2（按短弧计算）

**作用**：
- 描述"**这段关系本身**"的能量特征
- 不是"A 看 B 怎样"也不是"B 看 A 怎样"——是**双方共同创造的"第三个存在"**

**当前实现注意**：paipan_engine 暂未支持 Composite Chart 自动计算——需要手动算或在未来扩展。

### Step 5 · 主题共振（R21 应用到合盘）

把八字层 + 占星层的所有信号合并扫描：
- 共振主题（双方都喜 / 都忌 / 都强 / 都弱的领域）
- 互补主题（一方有的另一方没有）
- 张力主题（结构性差异 / 节奏差异）

## 📊 双轨综合判断（R21）

把八字 5 步 + 占星 5 步的输出**合并扫描**：

### 收敛信号（双轨共振 = 高象征强度）
- 双方在某主题上**双轨都识别为"匹配"** → 这个主题的结构性匹配度高
- 双方在某主题上**双轨都识别为"张力"** → 这个张力是结构性的（不是表面问题）

### 分歧信号
- 八字说"互补" + 占星说"张力"——是不同层的同时真实，需要主语对齐

## 边界外的拒答清单

- 单方背着对方的合盘 → Hard No #3
- 用合盘做关系决策军火库 → Reframe #14 加强
- 涉及第三人（出轨对象 / 暧昧对象）的盘 → Hard No #3
- 预测对方对自己的感情意图 → Hard No #4
- 预测具体事件（结婚日期 / 离婚时间 / 出轨对象）→ Hard No #8
- "克夫 / 克家 / 孤星" + 伴侣要求隐藏关系 → Circuit Breaker #12

## 📌 实操注意

1. **paipan_engine 当前不支持双盘模式** —— subagent 需要分别调用两次（一次 A、一次 B）然后合并
2. **占星 Synastry 的相位 / 落宫**需要 subagent 手算（用双方行星黄经和宫头数据）
3. **未来工程改进**：在 paipan_engine 里加 `--paipan2` 模式自动算 Synastry 相位 + 落宫 + Composite Chart

## 哲学锚点（不可忘）

> 合盘不告诉你"能不能在一起"——
> 合盘告诉你"**如果你们决定建立关系或已在关系中，结构上需要做什么样的工作**"。
>
> 命盘说**结构倾向**，**真实关系**取决于**双方的觉察 + 选择 + 沟通 + 边界 + 投入**。
>
> 这些**永远不在命盘里**——只在你们手里。
>
> **权在你们的秤上。**
