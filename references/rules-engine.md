# 规则引擎 · Rules Engine

**定位**：八字 subagent 内部的**技术推理层**。由 22 条从真实案例蒸馏的规则组成，负责"能不能发/什么行业/什么时候/方位"等结构性判断。

**与 SKILL.md 的关系**：
- SKILL.md = 框架层（议会、三派正交、伦理边界、术语脱毒）
- 本文件 = 推理层（被 `bazi-agent` subagent 调用）
- **规则输出在进入 Step 5 合成前必须经 SKILL.md 的"输出前自检 Checklist"脱毒**
- 未脱毒的直接技术断语（"身旺喜金水"→"你该去北方"）属于违规输出

**验证来源**：5 个真实案例（见 `examples/`），含事实反馈与星盘截图确认。

## 起手式（固定四步）

每次八字分析必须按此顺序执行，不可跳步：

1. **日元旺衰判断**（滴天髓）→ 触发 R1
2. **特殊格局检查**（子平格局法）→ 触发 R10
3. **月令定格局**（子平格局法）→ 成格 / 破格 / 假格
4. **调候用神**（穷通宝鉴）→ 触发 R19

四步完成后才进入 R11（用神排除法）做最终裁决。

## A. 基础判断规则

### R1（v3）· 三维旺衰判定（定性优先 + 量化辅助）

**规则**：身强身弱判定**必须以传统子平三维法（得令 / 得地 / 得势）为主**。R24 量化工具只作**辅助参考**，不能单独判决。

---

**第一层 · 定性三维（必先走）**

| 维度 | 检查 | 判定标准 |
|---|---|---|
| **得令** | 月令是否助我？ | 比劫 / 印 = 得令；财 / 官杀 / 食伤 = 失令 |
| **得地** | 地支是否有我的根？ | 通根（同类或有禄）= 得地；至少一根为准 |
| **得势** | 天干是否有助我的字？ | 比劫 / 印透 = 得势；过半字助我为强势 |

**判决表**：
| 三项占几项 | 身强弱判定 |
|---|---|
| 3 项全占 | **身强 / 身极旺** |
| 2 项（含得令）| **身强** |
| 2 项（不含得令）| **身中和偏强** |
| 1 项 | **身偏弱 / 中和偏弱** |
| 0 项 | **身弱 / 从格候选** |

---

**第二层 · 日元 vs 最强对手**（精度判定）

在第一层结论基础上，检查命局中最强对手是什么：

| 日元 + 对手状况 | 喜用路线 |
|---|---|
| 身强 + 对手不重 | 克泄耗（官杀 / 食伤 / 财星）|
| 身强 + 对手更强 | **印通关**（不是克泄耗）|
| 身弱 | 生扶（印 / 比劫）|
| 身中和偏强 + 财独旺 | **担财为用**（身能胜财）|
| 身中和 + 财独旺 | **官制劫护财 + 财官同用**（身中和能担） |
| 身中和偏弱 + 财独旺 | 印帮身 + 官通关（印+官）|
| 身中和 + 官杀独旺 | 印化杀（杀→印→身）|
| 身中和 + 食伤独旺 | 印克食伤（若不伤调候）或比劫帮身 |
| 身中和 + 比劫独旺 | 官杀制劫 + 食伤泄秀 |

**关键**：**"身中和"不等同于"身弱"**——身中和命盘可以担财官，只是需要结构配合。

---

**第三层 · R24 量化辅助（可选，非判决）**

- 当第一层得到"身中和偏强"或"身中和偏弱"时，**可以**用 R24 做每支力量的量化参考
- 但**量化结果与定性冲突时，定性优先**
- R24 不是"日元分数 vs 对手分数"的对决工具——这种对决式思维本身就偏离子平

---

**来源**：《滴天髓》扶抑派 + 《穷通宝鉴》调候 + 子平真诠格局 + 多次方法论修正
**重大修订历史**：
- v1：二元（强/弱）
- v2：三层（+ vs 对手）但 R24 量化越权
- **v3：定性三维为主，R24 降级为辅助**——修复 Case 001 误判（曾判身中和偏弱，实为身中和偏强）
- **v3.1（2026-04-27）**：补"常见误判模式"警示章节
- **v3.2（2026-04-28）**：**强制"格局判定先于扶抑判定"**——传统格局（杀印相生、食神制杀、伤官见官等）的成立判定**优先于**身强身弱的扶抑分析（详见 R45）

**配合规则**：R24 辅助量化 · R31-R35 盲派增强 · R19 极端气候时调候优先 · **R45 古典格局优先**

#### R1 v3.2 强化 · 格局判定优先于扶抑判定

**新增强制步骤**（先于扶抑三维）：

**Step 0**：先做**传统格局识别**（详见 R45）
- 月令本气透干？→ 立月令格
- 月令本气未透但中气透干？→ 立中气格
- 月令本气未透但天干有特殊透干组合？→ 检查是否构成传统格局：
  - **杀印相生**（七杀+偏印同透 + 七杀有月令支持）
  - **食神制杀**（食神+七杀同透 + 身能担）
  - **伤官见官**（伤官+正官同透 — 多忌）
  - **杀邀禄**（七杀+日主禄地）
  - **从格 / 化格 / 魁罡**（特殊格局）

**Step 0 命中时**：
- 用传统格局的喜忌规则**优先**于纯扶抑规则
- 例：杀印相生格 → 喜印水忌财食（不是身弱标准的"喜印比"）
- 例：食神制杀格 → 喜身能担食神 + 食神有根 + 不被合（不是简单的"身弱用印"）

**Step 0 不命中时**：才走扶抑 R1 三维（得令/得地/得势）

**严禁**：跳过格局判定直接套"身弱用印"或"印多反成忌"等现代规则——会误判经典格局。

**案例教训**：
- 1994-06-15 16:40 宁波 M `甲戌 庚午 壬申 戊申`
- 错判 1：直接说"食神制杀格"（没看月令本气）
- 错判 2：纠正后说"正财格 + 食神制杀辅"（仍漏看古典杀印相生）
- 错判 3：套"印多反成忌" → 喜木火（这是杀印相生格被严重误读）
- 古书原话：**"壬日戊申时，杀印相生，必须庚透干头"** —— 这是**经典杀印相生格**，喜印水忌财食
- 正判：**杀印相生格**（古典格局）→ 喜金水忌火木 → 当前癸酉运是用神最旺期

#### R1 常见误判模式（v3.1 警示）

经验教训：三维法本身正确，但**某些信号会触发"快速归类反应"导致误判**。以下三种模式必须警惕：

**误判模式 A · 双根帝旺导致"身强"幻觉**
- 信号：地支某干有 2 个及以上的帝旺/临官位
- 陷阱："看到双帝旺 / 双禄 → 直接判身强"
- **必查 3 项**：
  1. **月令本气是否直接克身**（月令克 = 失令是硬伤，不能被地支根抵消）
  2. **帝旺根是否被墓 / 绝 / 冲克拉扯**（如双亥帝旺被双未墓夹）
  3. **是否缺印**（缺印的"身强"往往担不起官杀）
- 案例：1995-07-31 13:45 长沙 F · `乙亥 癸未 癸亥 己未`
  - 错判路径：双亥帝旺 → 身中和偏强 → 食神制杀
  - 正判路径：失令（未月七杀本气）+ 墓夹根（月时双未克双亥）+ 缺印 + 七杀双根透干 → **身偏弱、杀重缺印、比劫抗杀**
  - 教训：**月令克身 + 墓夹帝旺根 + 缺印** = "看着强其实弱"的经典命盘

**误判模式 B · "食神制杀"的滥用**
- 食神制杀的前提是：**身能担食神再分力制杀**
- 身偏弱时强用食神制杀 = 越制越虚（食神再泄身）
- **判定流程**：
  1. 先确认身能否担起食神（身偏弱时食神是负担不是工具）
  2. 再看食神是否能有效制约七杀（食神坐墓 / 被合 → 制杀力打折）
  3. 若身担不起 → 改走"**印化杀**"（有印）或"**比劫抗杀**"（缺印有比劫）
- 误判信号：天干"看到食神 + 看到七杀" → 不查身就直接套食神制杀

**误判模式 C · 缺印盲点**
- 命局**缺印**（无金 / 印星不透不藏）+ **官杀重** → 这是结构性短板，必须显式标注
- "杀印相生"框架在**缺印命盘**不成立
- 修正方向：**印星代偿（学习 / 智识 / 老师 / 距离感 / 跨界知识）作为外部资源**——把命局短板用"造命"补足
- 此时八字 subagent 的输出**必须**包含"缺印警告"和"印代偿建议"，否则等于漏掉这个命局最关键的张力

**统一审计 checklist**（每个新命盘走 R1 必检）：
- [ ] 月令本气对日元什么关系（生 / 克 / 比 / 泄 / 耗）—— 这是"得令"的真实判据
- [ ] 帝旺/禄根是否被墓/绝/冲拉扯
- [ ] 印星状态：透 / 藏 / 缺
- [ ] 官杀状态：透 / 藏 / 多根 / 单根
- [ ] 食伤状态：透 / 藏 / 缺
- [ ] 比劫状态：透 / 藏 / 多根 / 单根
- [ ] 综合：身和"最强对手"力量对比 + 是否有"通关枢纽"（印 / 食伤）
- [ ] 是否触发误判模式 A / B / C 的警示信号

### R10 · 特殊格局优先

**规则**：特殊格局优先于普通格局。检查点：
- 日柱是否命中特殊格局（魁罡、专旺、从格、化格、两神成象等）
- 地支是否合化某五行力量过大
- 成特殊格局则用神规则改变

**来源**：子平格局法
**验证**：Case 003（戊戌日 = 魁罡格）、Case 005（双庚辰月日并立 + 戊戌日）
**边界**：破格与否看干支配合是否被冲破

### R11（v2）· 用神排除法 + 古典格局优先

**规则**：用神不是"一眼看出"，是**排除法 + 格局检查**：

**Step 0（v2 新增）· 先做格局判定（R45）**
- 命局是否构成传统古典格局？（杀印相生 / 食神制杀 / 伤官见官 / 从格 / 化格 等）
- **若构成**：用该格局的喜忌规则**直接定用神**（详见 R45）
- **若不构成**：才走 Step 1-4 的扶抑排除法

**Step 1**：列出所有候选用神（通常 2-3 个五行）
**Step 2**：每个候选代入命局试运行，追踪引发的连锁反应
**Step 3**：排除会引发关键副作用的候选
**Step 4**：剩下的才是真用神

**典型副作用**：
- 喜 X 但 X 会冲动忌神 → 排除
- 喜 X 但 X 会合绊关键用神 → 排除
- 喜 X 但 X 五行气偏枯燥 → 需搭配调候

#### v2 关键修正 · "印多反成忌" 的边界

**❌ 误用模式**：看到"印星多透 / 多藏" → 直接判"印过盛反成忌" → 喜木火忌金水

**✅ 正确判定**：
- "印多反成忌" 的**前提条件**是 **"七杀不重 / 不需要化"**
- 当**七杀也同样重**时（七杀透干 + 多根 + 月令支持任一），印不是"过盛"——是 **"正好用来化杀"** = **杀印相生格**
- 杀印相生格里印是**核心用神**——越透越好（古书"必须庚透干头" 之类）

**判定流程**：
1. 印多 → 先看七杀状况
2. 七杀也重 + 印有透干 → **杀印相生格** → 喜印水忌财食 ⭐
3. 七杀不重 / 杀已被制 + 印仍多 → 才是**"印多反成忌"** → 喜财食破印

**来源**：子平实操 + 案例修正
**验证**：
- Case 003（排除木因生火忌神、排除水因子午冲 → 最喜金）—— 普通排除法
- 1994-06-15 宁波男 `甲戌 庚午 壬申 戊申`（双申伏吟 = 印杀同时加倍 → 杀印相生格 → 喜印水）—— **杀印相生反例修复**

**用法**：R1 + R45 裁定"格局 / 方向"后，R11 裁定"具体哪个五行"

### R19 · 调候的决定性作用（一级规则）

**规则**：格局定骨架，调候定血肉。**同一格局在不同气候下展开完全不同**。**当命局气候极端时，调候升为一级规则**（起手式第 4 步先于第 2-3 步执行），覆盖扶抑/格局给出的方向。

**来源**：《穷通宝鉴》
**验证**：Case 002 vs Case 004（都是杀印相生格，一个太寒喜火、一个太燥喜水）

**气候极端量化判据**（命中任一即触发"调候优先级升一级"）：

| 极端类型 | 量化条件 |
|---|---|
| **大寒** | 亥/子/丑月 + 日元为水或土（湿气重）+ 天干地支都无丙/丁/巳/午火 |
| **大燥** | 巳/午/未月 + 日元为火或土（燥气重）+ 天干地支都无壬/癸/亥/子水 |
| **气偏（专旺）** | 命局出现三合局（寅午戌/申子辰/亥卯未/巳酉丑）或三会局（寅卯辰/巳午未/申酉戌/亥子丑），某行成局 |
| **气偏（独旺）** | 某五行在天干地支占比 ≥ 60%（结合 R24 十二长生力量计算）|

**命中时的处理**：
1. 先定调候用神（寒用火、燥用水、湿用火土、偏用反制之行）
2. 格局法给出的用神若与调候冲突 → 以调候为主
3. 若调候与格局一致 → 用神双重确定，象征强度高
4. 非极端命局 → R19 回到二级，与格局法并用（见 R2）

### R23 · 魁罡冲的专项处理

**规则**：魁罡格（庚辰、庚戌、戊戌、壬辰四日）的冲刑有专属判据，不适用普通刑冲规则（R20）。

**经典依据**（《九流之命·魁罡歌》）：
> 魁罡四日最为先，叠叠相逢掌大权，
> 庚戌庚辰怕官显，戊戌壬辰畏财连。
> 主人性格多聪慧，好杀之心断不偏，
> 柱有刑冲兼破害，一贫彻骨受答鞭。
> 戊戌庚辰杀最强，壬辰庚戌号魁罡，
> 日加重者方为福，身旺逢之贵异常，
> 如逢一位冲刑重，彻骨贫寒不可当。

**三条核心判据**：

1. **叠叠相逢掌大权**：命局出现两个及以上魁罡（年月日时任意柱），主大权位
2. **四日各有忌神**：
   - **庚戌、庚辰日** → 怕官显（丙丁火透或通根）
   - **戊戌、壬辰日** → 畏财连（壬癸水/丙丁火对应日主的财星透显）
3. **冲刑破害 + 财官显露 → 祸**：
   - "日主独逢冲刑重"= 魁罡日逢一位冲（刑、破、害亦同）
   - 若同时满足"财官显露"→ 彻骨贫寒
   - 若不满足财官显露 → 有冲但冲的是闲神/忌神，仍可保身

**与 R20 的关系**：
- R20 适用于普通命局的刑冲判断
- R23 **优先**于 R20 处理魁罡日主的冲
- 本规则是 R20 的专项例外

**判定流程**：
```
日柱是否魁罡？
├─ 否 → 用 R20
└─ 是 → 进入 R23
    ├─ 有无叠加？（多个魁罡）
    │  ├─ 有 → 保留"掌大权"基础加成
    │  └─ 无 → 无加成
    ├─ 有无相应忌神显露？（庚日怕官、戊壬日畏财）
    │  ├─ 有 → 进入破格判定
    │  └─ 无 → 保留魁罡格
    └─ 日柱有无冲刑破害？
        ├─ 有 + 财官显露 → 破格，彻骨贫寒
        ├─ 有 + 财官不显 → 格损但不破，看身旺与否
        │  ├─ 身旺 → 仍贵（"身旺逢之贵异常"覆盖冲的负面）
        │  └─ 身弱 → 格力受限
        └─ 无冲 → 保留魁罡格全效
```

**来源**：《九流之命·魁罡歌》
**验证**：Case 005（庚辰月 + 戊戌日 = 双魁罡叠 + 辰戌冲）
- 叠加 ✓ 掌大权基础加成
- 戊戌畏财连：命局财（水）仅辰中藏癸微弱，不显 → **不算犯禁**
- 日主逢冲 ✓（辰戌月日冲）
- 财官显露判定：乙卯七杀通根透显（官杀显）→ 部分命中
- 身旺 ✓（戊土得令得地）→ "身旺逢之贵异常"覆盖
- **结论**：格损但未破，身旺为盾 → 命格仍成立但有冲的代价（成长期拉扯、人生节奏被打断）

**配合 R1**：魁罡格破后按普通格局处理，回到 R1 三层判断路径

### R24 · 十二长生力量分级（**辅助工具，非独立判决**）

> ⚠️ **使用边界（v3 修订）**：
> - ✅ **工具**：帮助理解"每个地支对日元贡献了多少气"——定性判断得地时的**精度支撑**
> - ❌ **禁用**：单独作为"身强身弱"的判决器
> - ❌ **禁用**："日元总分 vs 对手总分"的对决式计算——这种思维不是子平
> - **身强身弱的最终判决权在 R1 三维法**（得令 / 得地 / 得势）
> - 当 R24 结果与 R1 三维冲突时，**R1 三维优先**

### R33 · 体用分野 · 我宫识别

**规则**：八字四柱在盲派分为我宫 / 他宫：

| 柱 | 区分 | 含义 |
|---|---|---|
| 年柱 | **他宫** | 祖上、外部、先天环境 |
| 月柱 | **他宫** | 父母、生长环境、早年基盘 |
| **日柱** | **我宫（体）** | 我自己 + 配偶（日支） |
| **时柱** | **我宫（用）** | 我追求的、子女、我能调动的工具、人生终点 |

**读盘应用**：
- 当**重要气机**（禄 / 用神 / 财 / 官）落在我宫 → 效力**显著增强**，代表"我可以直接调动"
- 当重要气机落在他宫 → 需要通过合冲刑害的"渠道"才能被动调动
- 盲派说："**重点都在我宫**"——我宫的气机决定命主自己能做什么

**来源**：盲派体用分野核心
**验证**：
- Case 001 时支巳（丙禄借给丁）在**我宫** → 丁火有强根可用
- Case 002 时支午（癸的偏财）在**我宫** → 我能直接拿到财
- Case 006 月日双午（丙借禄）在**月柱+我宫** → 禄气既是外部也是自己的

### R34 · 合制做功（合 ≠ 合化）

**规则**：地支六合、三合、半合在盲派的核心读法是"**收拢做功**"——**不是合化**。

| 传统读法 | 盲派读法 |
|---|---|
| 合化 → 两地支变成另一五行 | 合 → 两地支**能量收拢到一起** |
| 看五行转变 | 看"**谁把谁收在手里**" |
| "合则消失" | "**合则能去，效率远高于克**" |

**做功效率**：
- **克**：直接对抗，内耗偏强
- **合**：收拢控制，效率高
- **合 > 克**

**判断"谁合谁"**：看合的两方**谁更接近我宫 / 谁代表我**——代表我的那个"主合"另一个。

**应用到 Case 001**：
- 巳（时支我宫禄神）合申（月他宫偏财）= **我用禄神合财**
- 巳（时支我宫禄神）半合酉（日支我宫正财）= **我宫内禄神合财**
- 两次"**禄合财做功**"= 我直接把财攥在手里
- 这**不是**"巳申化水损禄"——原局力量分布不变

**来源**：盲派合制原理
**验证**：Case 001（两次禄合财）、Case 002（原局合的结构）、Case 006（辰戌冲冲开两库）

### R35 · 我宫见用神 / 财官

**规则**：当财、官、用神**落在我宫**时，代表"我能直接调动这份资源"。

| 落位 | 读法 |
|---|---|
| **财在我宫** | 我能拿到财（不需通过他人）|
| **官在我宫** | 我有权威可以代我做事 |
| **用神在我宫** | 用神可直接激活 |
| **忌神在我宫** | 忌神就在我身边，难避免 |
| **用神在他宫** | 需要通过合冲等渠道才能调动 |

**读盘扫描顺序**：
1. 先标出命盘的用神、忌神、财、官位置
2. 再看各自落在哪个柱（我宫 / 他宫）
3. 我宫落用神 = 强做功结构

**来源**：盲派"重点在我宫"原理
**验证**：
- Case 001：时支巳 = 禄在我宫 + 酉偏财在我宫日支 = **双重"我宫见用神"**（按 v3 身中和+财为用计算）
- Case 002：时支午 = 财在我宫 + 时干戊 = 官在我宫（贴身七杀）= 富贵做功
- Case 006：时支戌 = 火库在我宫（戊食神墓 = 做功墓地）

---

**R31-R35 整体说明**：
- 这 5 条规则**不需要触发条件**——任何命盘都可以用
- 它们是对子平扶抑派的**精度增强**，不是替代
- 子平看"五行生克力量"，盲派看"能量流向与做功效率"——两者**互补**
- 一般命盘子平为主、盲派增精度；临界命盘两者并用可防止单派误判
- **R35 我宫见用神** 是盲派输出里**最具操作性**的诊断——能定位"命主自己能做什么"

## C. 十神结构规则

**环境推论**：劫财重 + 无官杀制 → 宜选"制度围墙强"的环境（体制内、大型企业、持牌机构），借外部制度替代命局中缺失的官。

### R20（v2.0）· 地支六冲完整体系

**完整六冲表**（含力度分级）：

### R28 · 结构模式优先于单相位

**规则**：人不是一个矛盾，而是一套**系统性冲突**。读盘必须先找**结构模式**，再读单相位。

**七大结构模式**：

| 结构 | 构成 | 能量特征 | 典型输出 |
|---|---|---|---|
| **T-Square** | 2 颗对冲 180° + 第 3 颗对两者都 90° | 长期内在拉扯 = **最强驱动力** | "你在 X 和 Y 之间有长期张力，这是你最大的动力引擎" |
| **Grand Trine** | 3 颗互成 120° 等边三角 | 天赋流动 → **可能懒** | "你在某领域有天赋，但需要主动压力点激活" |
| **Grand Cross** | 4 颗互成对冲+刑 | 极度冲突 → 需长期整合 | "多维度张力同时在拉你，节奏管理是一生课题" |
| **Stellium（群星）** | 3+ 颗聚在同星座 / 同宫位 | 该领域能量**压倒性密集** | "你的人生主题集中在 X 领域，其他领域是次维度" |
| **Kite（风筝）** | Grand Trine + 一颗对冲点 | 大三角被激活 | "天赋被对冲点推动着展开" |
| **Yod（上帝之指）** | 2 颗六合 60° + 共同 150° 到第三颗 | 强制性转向 | "人生中 X 主题会反复强制你调整方向" |
| **Mystic Rectangle** | 2 对冲 + 2 拱 + 2 六合 | 稳定张力 = 平衡困难 | "你有框架把困难转成能力" |

**判定流程**：
1. 先扫描命盘找结构（容许度：合相/刑冲 8°、拱 8°、六合 4°）
2. 若命中多个结构，优先级：Stellium > T-Square > Grand Cross > Grand Trine > Yod > Kite > Mystic Rectangle

**来源**：Tompkins 公理 4
**验证**：**Case 005 金牛 12 宫 Stellium**（火星 + 木星 + 土星集中 12 宫 = 隐藏的强者，能量压倒性在潜意识领域；这是单相位解读绝对抓不到的系统信号）

**操作系统框架（R28 核心升级）**：

### R37 · Profection 计算规范

**规则**：Profection（希腊化年运）必须**按生日切换**，不是按公历年。

**公式**（两种等价系统）：
- **Modern**：house = `(completed_age % 12) + 1`
  - age 0 (出生至 1 岁生日) → 1H
  - age 37 (37-38岁生日之间) → 2H
  - age 38 → 3H
- **Hellenistic Life Year**：house = `((life_year - 1) % 12) + 1`，其中 `life_year = completed_age + 1`
  - LY1 (age 0-1) → 1H
  - LY 38 (age 37 complete) → 2H
  - LY 39 (age 38 complete) → 3H

**两系统数学等价**——只是术语不同。但**中文对"38 岁"的歧义会导致错误**：
- "38 岁" 在 Life Year 系统 = LY 38 = age 37 complete = **2H**
- "38 岁" 在 Modern 系统 = completed age 38 = **3H**

**R37 强制**：
1. 计算前先**明确约定**用哪个系统（默认 Modern，生日前/后都清晰对应一个 house）
2. 日期切换点**必须是生日**，不是公历年 1 月 1 日
3. 输出时**显式写出计算**："2025-08-01（age=37，跨过 6-20 生日）→ Modern 2H 摩羯 / LY 38 2H 摩羯"

**LOTY（Lord of the Year）**：
- LOTY = **激活宫宫头星座的传统守护星**
- 传统守护星（Hellenistic）：
  - 白羊→火星 / 金牛→金星 / 双子→水星 / 巨蟹→月亮 / 狮子→太阳 / 处女→水星
  - 天秤→金星 / 天蝎→火星 / 射手→木星 / 摩羯→土星 / 水瓶→土星 / 双鱼→木星
- **不用**现代守护星（Uranus/Neptune/Pluto）——Profection 是古法，用古配
- LOTY 的**本命落宫**很重要——该宫也被同步激活

**常见错误**：
- ❌ "38 岁 2 宫"（Modern 下应是 3 宫；Hellenistic 下 LY 38 可以是 2 宫但需说明）
- ❌ "水瓶 ruler 是 Uranus" → Profection 下是 **Saturn**（传统守护星）
- ❌ 公历年整体归一个 profection（必须按生日切）

**来源**：Hellenistic 复兴派（Chris Brennan《Hellenistic Astrology》+ Demetra George）+ 2026-04-24 skill 真实部署测试捕获的 off-by-one 错误
**验证**：Case 006 Profection
- 2025 早（age 36 / LY 37）→ 1H 射手，LOTY 木星落金牛 6H
- 2025-06-20 生日后（age 37 / LY 38）→ 2H 摩羯，LOTY 土星落射手 1H
- 2026-06-20 生日后（age 38 / LY 39）→ 3H 水瓶，LOTY 土星落射手 1H

**实现**：paipan_engine.py 的 `calculate_profection()` 同时输出两系统结果，避免约定歧义

### R41 · Synastry 关键相位 + 行星落宫

**规则**：合盘第四步走占星 Synastry，分两个层次——**关键相位**（双方行星互动）+ **行星落宫**（A 落 B 的什么宫）。

#### 第一层 · 关键互相相位

**优先级排序**（从最重要到次要）：
1. **个人行星之间**（日月水金火 互相）—— 最直接
2. **个人行星 ↔ 四轴**（ASC / MC / IC / DSC）—— 极重要

| 相位 | 含义 |

| **Pluto 接触个人行星** | 转化深度 / 控制议题 |

**容许度**（按紧密度排）：
- 0-1° = ★ 极紧（最强信号）
- 1-3° = 紧
- 3-5° = 中
- 5-8° = 宽松（仅参考）

#### 第二层 · 行星落宫（**最核心**）

**这是 Synastry 最关键的部分**：A 的行星落在 B 的什么宫位 = A 在 B 的命盘里激活什么场域。

**重要落宫解读**：
| 落宫 | 含义 |
|---|---|
| A 多颗行星落 B **7H** | **A 在 B 的命盘里扮演"伴侣型"角色** ⭐（极关键信号）|
| A 多颗行星落 B **8H** | A 触动 B 的深度 / 共享资源 / 转化议题 |
| A 多颗行星落 B **12H** | A 在 B 的潜意识 / 隐性维度——**不一定公开伴侣型** ⚠️ |
| A 落 B **4H** | A 触动 B 的家 / 根基 / 情绪基底 |
| A 落 B **5H** | A 激活 B 的创造 / 浪漫场域 |
| A 落 B **11H** | A 是 B 的社群 / 朋友 / 理想型存在 |

**对称性诊断**（极重要）：
- **对称**（A 落 B 7H + B 落 A 7H）= **互相认对方为伴侣** ✓
- **不对称**（A 落 B 7H + B 落 A 12H）= **公开 / 隐性定位不对等** ⚠️——值得诚实标注

**来源**：现代占星 Synastry + Robert Hand / Stephen Arroyo 等
**验证**：

- 1959M + 1988F（男太阳+火星进女 7H 但女落男 12H = **不对称定位** ⚠️）

### R42 · 双方大运 / 流年同步性

**规则**：合盘第五步检查双方时间维度同步性。

**判定流程**：
1. 双方当前大运起止时间是否重叠？
2. 双方当前大运的十神能量方向（顺 / 逆 / 异向）
3. 当前流年对双方各自的影响（一方顺另一方逆？同顺？同逆？）

**四种节奏类型**：
| 类型 | 含义 |
|---|---|
| **同步顺** | 双方都在用神大运 = **共振扩张期** ✓ |
| **同步逆** | 双方都在忌神大运 = **共振承压期**（关系作为支撑系统作用大）|
| **逆向** | 一方顺一方逆 = **节奏不同但可互补** |
| **完全异向** | 大运能量主题完全不同 = 各走各的 ⚠️ |

**关键警示**：
- **完全异向**的两人 = 容易出现"我在飞你在沉 / 我在沉你在飞"的体感——需要双方诚实承认彼此处于不同节奏
- 不同步**不等于关系不好**——意味着关系在不同节奏下需要不同形态的支持

**结合 R36 四层叠加**：合盘的时间维度同样走"命盘 × 大运 × 流年 × Profection"四层——可以扩展到双方的 Profection 同步性（如：双方是否都在 7H Profection 年 = 双方关系议题同时激活）。

**来源**：现代命理 + 实证
**验证**：1959M + 1988F（男丁卯偏财大运 + 女丁巳食神大运 = 双方都有"丁火"语言但内容不同 + 2026 男大顺女大耗 = 节奏极不同步典例）

## I. 方法论层规则（分析顺序 / 古典格局）

### R44 · 突出矛盾优先识别法

**规则**：分析任何八字盘，**先扫描"最突出的特点 / 最大的失衡 / 最罕见的配置"**——这是命局的**中心引力**，所有其他分析必须**围绕它展开**，不能"特点平铺"。

**核心思路**：每个盘有 1-2 个**最关键的特点**——决定命主一生的核心命题。其他细节（用神 / 大运 / 流年）都是这个核心命题的**展开**。

**扫描清单**（优先识别）：

| 类型 | 信号 | 含义 |
|---|---|---|
| **伏吟** | 同地支重复出现（双申 / 双亥 / 双卯等）| 该地支藏的能量**加倍** —— 是用神则爆 / 是忌神则压 |
| **三刑** | 寅巳申 / 丑戌未 / 子卯（地支三个齐全或部分齐全）| 内在张力 / 反复重启 / 健康压力 |
| **天克地冲** | 命局某柱与流年 / 大运完全相克 | 重大变动节点 |
| **专旺极偏** | 某五行占 60%+ → 三合 / 三会成局 | 格局可能转变（专旺 / 从格） |
| **印杀同重** | 印多透 + 七杀也多透 + 月令支持 | **杀印相生格**（不能套"印过盛")|
| **食杀同透** | 食神 + 七杀同透 + 身能担 | **食神制杀格** |
| **罕见格局** | 魁罡 / 月刃 / 双刃 / 倒冲禄 / 飞天禄马 / 化气格 等 | 古典特殊格局 → 走特殊规则 |
| **缺位** | 五行缺一 / 食伤完全缺 / 印完全缺 | 结构性短板 |
| **天干所有透干一致服务一个目的** | 比如全是帮身 / 全是泄身 / 全是制杀 | 命局有"主旋律" |

**判定流程**：
1. **第一遍**：扫这个清单——这个盘有什么"突出的特点"？
2. **第二遍**：这个特点对命主一生意味着什么？（这是"中心引力"）
3. **第三遍**：用神 / 大运 / 事业 / 性格分析全部围绕这个特点展开

**禁用**：
- ❌ 不要"特点平铺"——把所有维度都罗列一遍而不挑重点
- ❌ 不要"教科书式分析"——按身强弱 → 用神 → 大运 → 流年的固定模板，但漏掉这个盘最特别的东西
- ✅ **要先抓重点 + 再围绕重点展开**

**来源**：用户 2026-04-28 反馈"看八字要看突出的矛盾 / 中心引力"
**验证**：
- 1994-06-15 宁波男：核心特点 = **双申伏吟（印杀同时加倍）+ 双 Yod apex Sun（八字占星双轨共振于"反复重塑"主题）**——这才是命局中心；其他用神/大运分析都围绕这个展开

### R46 · 地支六合

**规则**：地支两支相合，能量收拢——是否合化为另一五行，必须严格判定条件。

**六合表**（含合化方向）：

| 合对 | 合化方向 | 化神性质 | 现实意象 |
|---|---|---|---|
| **子 ↔ 丑** | 合化**土** | 但水气仍在（化得最难）| 子水被丑土收住 |
| **寅 ↔ 亥** | 合化**木** | 木气长生地（化得最顺）| 亥水生寅木，合木最自然 |
| **卯 ↔ 戌** | 合化**火** | 火气藏戌库（半化）| 卯木入戌火库 |
| **辰 ↔ 酉** | 合化**金** | 辰土生酉金（顺生）| 辰土养酉金 |
| **巳 ↔ 申** | 合化**水** | 但易刑（巳申也相刑）| 双重关系，详 R48 |
| **午 ↔ 未** | 合化**火土** | 同气（午火生未土）| 火土同温 |

**合化的严格条件**（子平视角，三条全满足才"真化"）：

1. **化神得令** — 化神（合化后的五行）在月令有根，或月令支持化神
2. **化神透干** — 化神在天干透出，并且不被克
3. **无破坏** — 合的两支之间无冲、无被夺合（妒合）

**满足条件的等级**：
- **真化**（三条全满足）→ 两支彻底转化为化神五行，原本气消失
- **化而不真**（满足 1-2 条）→ 化神有效力但原五行仍留余气
- **合而不化**（条件不满足）→ 两支只是能量收拢，**不转化五行**——这是**最常见的情况**

**远近距离效应**：

| 距离 | 合的力度 | 应用 |
|---|:-:|---|
| **紧邻合**（相邻两柱）| 100% | 月日合、日时合 |
| **隔位合**（隔一柱）| 50-60% | 年日合（隔月柱）、月时合（隔日柱）|
| **遥合**（年时柱）| 20-30% | 年时柱合，被中间稀释 |
| **拱合**（两支中间隔字但能拱出第三字）| 看拱出来的字 | 详 R47 |

**妒合 / 争合**（v2.0 关键概念）：

| 场景 | 现象 | 读法 |
|---|---|---|
| **两支同合一支**（如双卯合一戌）| 戌被两个卯争抢 | "争合"——合的力度被稀释，效率降低 |
| **一支夹在两个合对中间**（如卯戌酉，戌被卯合也被酉？）| 一支被多个潜在合对牵扯 | 实际优先级看距离 + 五行强弱 |
| **日支被合**（最敏感位置）| 日支是"我"的核心 | 配偶宫被合 → 婚恋议题被牵动；日支合用神 = 直接收纳 |

**子平 vs 盲派的核心分歧**（详 R52）：

| 子平视角 | 盲派视角 |
|---|---|
| 合的核心问题 = "**化不化**" | 合的核心问题 = "**做什么功**" |
| 合而不化 = 没什么用 | 合即做功 = 收拢就有效率（详 R34）|
| 重点看化神五行是否符合用神 | 重点看"谁合谁"——主合方 = 收益者 |
| 严判合化条件 | 不论是否化，合即"能量被某方控制" |

**议会读法**（综合）：
- 子平问 "化得真不真" → 决定五行平衡的变化
- 盲派问 "谁是主合方" → 决定能量归属
- 两个问题答案**可以同时为真**——不冲突，是不同视角

**与其他规则的接口**：
- 盲派"合制做功"详 **R34**
- 三合 / 三会的局成（不同于六合）详 **R47**
- 天干五合详 **R50**
- 大运 / 流年合原局的触发详 **R51**
- 合盘场景的双方地支合详 **R40**

**来源**：子平合化六条（《三命通会》《子平真诠》）+ 段建业盲派合制做功（合 ≠ 合化）+ 滴天髓注（任铁樵）合冲动静论
**验证**：
- Case 001 原局（丙子/丙申/丁酉/乙巳）：**巳申合**（时支巳隔日支酉合月支申）= 隔位合（力度 ~60%）+ 巳申亦相刑（详 R48）→ 双重关系——盲派读为"禄合偏财做功"（详 R34）；子平视角化神水非用神且月令申本气是金，"合而不化"
- Case 001 大运动作用静：**壬辰大运（2033-2042）辰** + 原局日支酉 = **辰酉合金（大运合原局）**——化神金正是用神 → 子平视角"半化有效"；盲派视角"外部资源（大运辰）喂给我宫（日支酉）"
- Case 002：原局合的结构（待 case 文件复核具体合对）

### R47 · 三合 / 三会 / 半合 / 拱合

**规则**：地支多支组合形成"局"——三合 / 三会 / 半合 / 拱合的力度差异极大，必须分级判定。

**三合局表**（"长生 + 帝旺 + 墓"三柱结合）：

| 三合局 | 三支 | 五行 | 结构原理 |
|---|---|---|---|
| **申子辰** 水局 | 申（长生）+ 子（帝旺）+ 辰（墓）| 水 | 水的生旺墓三段聚 |
| **亥卯未** 木局 | 亥（长生）+ 卯（帝旺）+ 未（墓）| 木 | 木的生旺墓三段聚 |
| **寅午戌** 火局 | 寅（长生）+ 午（帝旺）+ 戌（墓）| 火 | 火的生旺墓三段聚 |
| **巳酉丑** 金局 | 巳（长生）+ 酉（帝旺）+ 丑（墓）| 金 | 金的生旺墓三段聚 |

**三会方表**（"同方三连"，最刚性）：

| 三会方 | 三支 | 五行 | 结构原理 |
|---|---|---|---|
| **寅卯辰** 东方 | 寅、卯、辰 | 木 | 春季三月连续 |
| **巳午未** 南方 | 巳、午、未 | 火 | 夏季三月连续 |
| **申酉戌** 西方 | 申、酉、戌 | 金 | 秋季三月连续 |
| **亥子丑** 北方 | 亥、子、丑 | 水 | 冬季三月连续 |

**力度分级**（这是关键）：

| 组合 | 力度 | 化神纯度 | 备注 |
|---|:-:|:-:|---|
| **三会方**（三字齐）| ★★★★★ | 100% | 最刚性，几乎必化（春季就是春） |
| **三合局**（三字齐）| ★★★★ | 80-90% | 几乎必化，但需化神得月令支持 |
| **半合**（含子午卯酉 = 帝旺）| ★★★ | 60-70% | "帝旺半合"力度仅次于全局 |
| **半合**（不含帝旺，仅长生 + 墓）| ★★ | 30-40% | 如申辰半合，无子（帝旺）→ 力度弱 |
| **拱合**（隔字拱，能拱出第三字）| ★ | 看拱出字位置 | 详下方拱合细则 |

**半合细则**（v2.0 重要补充）：

| 半合对 | 含帝旺？ | 力度 |
|---|:-:|:-:|
| 申子 / 子辰（水）| ✓ 含子 | ★★★ 强半合 |
| 亥卯 / 卯未（木）| ✓ 含卯 | ★★★ 强半合 |
| 寅午 / 午戌（火）| ✓ 含午 | ★★★ 强半合 |
| 巳酉 / 酉丑（金）| ✓ 含酉 | ★★★ 强半合 |
| 申辰、亥未、寅戌、巳丑 | ✗ 无帝旺 | ★★ 弱半合（"拱"性质）|

**拱合**（隔字拱出虚字）：
- 例：**寅戌拱午**（寅戌之间应有午，午即虚拱出来）→ 命局如有寅戌但无午，等于命局**隐性具备火局倾向**
- 拱合**强度大幅弱化**（约半合的 30-50%）——但在大运 / 流年补出"被拱字"时**瞬间激活**（详 R51）

**三合局成的子平条件**（严判）：

1. **三字齐全** — 三合三支同时出现在四柱中（年/月/日/时任意位置）
2. **化神有根** — 化神（局五行）在月令或天干透出
3. **无冲破** — 三支之间或局外无紧邻冲（如寅午戌局，若有申冲寅 → 局破）

**满足条件的等级**：
- **三合纯局**（三条全满足）→ 命局基本是"专旺格"或"从旺格"，详 R10/R45
- **三合假局**（满足 1-2 条）→ 局成但化神不纯，力度按比例打折
- **半合 + 帝旺** → 不算全局，但化神倾向显著
- **半合无帝旺 / 拱合** → 倾向极弱，仅在大运流年补字时触发

**与格局的接口（R10/R45）**：
- 三合纯局 + 化神为日主 → **专旺格**（曲直 / 炎上 / 稼穑 / 从革 / 润下）
- 三合纯局 + 化神克日主 / 泄日主太重 → **从势 / 从儿 / 从财 / 从杀格**
- 半合 / 拱合 → 不构成格局，但是**用神判定的辅助证据**

**子平 vs 盲派分歧**（详 R52）：

| 子平 | 盲派 |
|---|---|
| 三合是"化"——五行转变 | 三合是"聚气"——同一阵营 |
| 半合"未化"价值低 | 半合"做功强"——三支虽未化但能量已聚 |
| 拱合"虚字" 几乎无意义 | 拱合 = "**潜伏的局**"，大运补字即激活 |

**议会读法**：
- 子平问 "局化成几成" → 决定结构性格局
- 盲派问 "几支聚在哪个方向" → 决定能量走向
- 三合 vs 三会的力度差异 = 子平比较严的层级；盲派看效果差异较小

**与其他规则的接口**：
- 专旺 / 从化格局判定详 **R10 / R45**
- 三合中的库（辰戌丑未）单独冲开做功详 **R51**
- 六合（两支合）详 **R46**
- 大运 / 流年补出三合缺字的触发详 **R51**

**来源**：子平三合三会理论（《三命通会》《滴天髓》"地支总论"）+ 段建业盲派"局成 vs 局聚"分级 + 子平真诠"半合从旺"
**验证**：
- Case 001：原局**巳半合酉**（时支巳半合日支酉成金局，金局缺丑——是"帝旺半合"力度 ★★★）= 命局有金的聚集倾向，财根（酉）被强化；**壬辰大运辰** 出现时 + 原局**酉** = 辰酉六合（详 R46），与已有的巳酉半合形成双重金聚结构
- Case 005：辰戌冲（双魁罡）= 库冲释放藏干，与 R23 + R51 共同处理
- Case 006（戊辰/戊午/丙午/戊戌）：**月日双午（伏吟）+ 时支戌**——午戌已构成"帝旺半合"（含午）→ 火局缺寅，是潜在拱寅结构；**大运甲寅（2023-2032）补出寅 = 寅午戌火局成纯局** —— 这是拱合在大运补字下被全效激活的经典例

### R48 · 三刑 / 自刑

**规则**：刑是"缓慢、慢性、内化的冲突"——区别于冲（剧烈、外化）。三刑 + 自刑共四组，需分别处理。

**三刑表**（三支互刑）：

| 三刑 | 三支 | 古典命名 | 性质 |
|---|---|---|---|
| **寅 → 巳 → 申** | 寅刑巳、巳刑申、申刑寅 | **"恃势之刑"** | 自恃能力、互相伤害（三支都自带"势"）|
| **丑 → 戌 → 未** | 丑刑戌、戌刑未、未刑丑 | **"无恩之刑"** | 翻脸不认人、忘恩负义（三支都是土库）|
| **子 → 卯**（双向）| 子刑卯、卯刑子 | **"无礼之刑"** | 不顾分寸、越界冒犯 |

**自刑表**（同支重复）：

| 自刑 | 五行 | 性质 |
|---|---|---|
| **辰 + 辰** | 土 | 重复积压（湿土自堆）|
| **午 + 午** | 火 | 重复消耗（火自焚）|
| **酉 + 酉** | 金 | 重复执着（金自坚）|
| **亥 + 亥** | 水 | 重复流泄（水自漫）|

**刑 vs 冲的核心区别**（v2.0 关键）：

| 维度 | 冲 | 刑 |
|---|---|---|
| **节奏** | 剧烈、瞬时、外化 | 缓慢、慢性、内化 |
| **现实意象** | 突发事件、明显冲突 | 长期消耗、内在张力、关系反复 |
| **修复难度** | 冲过即过，可修复 | 反复发作，难根除 |
| **典型场景** | 突然辞职、车祸、剧烈争吵 | 慢性疾病、长期家庭矛盾、性格内耗 |
| **大运 / 流年触发** | 易激活 | 易激活，但显效缓慢 |

**三刑的"恃势 / 无恩 / 无礼"的现代解读**：

| 三刑类型 | 古典命名 | 现代心理意象 |
|---|---|---|
| 寅巳申 **恃势** | 仗着自己的某个长处去刺别人 | "我有 X，所以你必须 Y" 型关系冲突；权力 / 能力 / 资源的滥用 |
| 丑戌未 **无恩** | 受过对方好处后翻脸 | 合作翻脸、家庭恩怨、长期亲密关系的"翻账"模式；土库互冲（详 R47）|
| 子卯 **无礼** | 不顾礼数 / 越界 | 边界模糊、亲密关系中的越界、青春期叛逆模式 |

**自刑的特征**（v2.0 重要补充）：
- 自刑 = 同字重复 → 不只是"两个同字"，而是**这个字的特质被极端放大并自我消耗**
- 例：**双午自刑** → 火过旺，**自我燃烧** 的模式（午是阳火 = 主动燃烧）
- 例：**双辰自刑** → 湿土过湿，**自我积压** 的模式（辰是水库湿土）
- 自刑也常与"伏吟"重叠（R40 / R51）——同字两次叠加 = 自刑 + 伏吟双重压力

**刑的位置距离效应**：

| 距离 | 刑的力度 |
|---|:-:|
| **紧邻刑**（相邻两柱）| 100% |
| **隔位刑**（隔一柱）| 50% |
| **三刑全齐**（寅巳申 / 丑戌未三字全在四柱）| ★★★ 全面激活 |
| **三刑缺一**（如寅巳无申）| ★ 弱激活，待大运补字 |
| **自刑**（同字两次）| 不分距离——同字出现两次即激活 |

**刑的解化条件**：

| 条件 | 效果 |
|---|---|
| 刑的支之间**有合** | 刑被合住，部分化解 |
| 刑的支**有通关五行** | 张力被疏导 |
| 三刑只有两字（如寅巳无申）| 弱刑，需大运 / 流年补出第三字才全激活 |
| 大运 / 流年**补出刑的缺字** | 触发刑全效（详 R51）|

**子平 vs 盲派分歧**（详 R52）：

| 子平视角 | 盲派视角 |
|---|---|
| 刑是命局"瑕疵" | 刑是命局"动力"——长期张力可以转化为动机 |
| 三刑全齐 = 大凶 | 三刑全齐 = 命局有"长期可挖掘的矛盾"，可做功 |
| 解刑要靠合 / 通关 | 解刑要看"刑动出的是用神还是忌神" |

**特殊场景**：
- **巳申**（六合 + 相刑同时存在）→ **合中带刑**——表面合作但内有摩擦的关系模式（合盘最常见警示）
- **辰戌丑未**（四库全聚）→ **库刑互冲**（戌未刑 + 丑戌刑 + 辰戌冲 + 丑未冲）→ 极端复杂，常见于命局年月日时四柱全是土库，按 R10 从势格或专旺格处理

**与其他规则的接口**：
- 库刑（丑戌未中的丑 / 戌）的"冲开做功"详 **R51**
- 巳申同时合 + 刑 → 详 R46 + R48 综合判断
- 合盘中的双方刑详 **R40**
- 自刑与伏吟重叠 → 详 **R51**

**来源**：《三命通会》三刑论 + 滴天髓"刑冲合害"章 + 段建业盲派"刑为长期张力"
**验证**：
- Case 001（丙子/丙申/丁酉/乙巳）：**时支巳 + 月支申** = **巳申合 + 巳申刑同时存在** → "合中带刑"的关系模式（合作但内耗）；同时巳申合化水的子平条件不满足（化神水非用神，水也无月令支持——月令申本气是金）→ 主要读法是"刑 + 合做功"并存（位置隔了日支酉，按隔位合刑处理，力度约 60%）
- Case 005（庚辰/庚辰/戊戌/乙卯）：**双辰自刑**（年月双庚辰 = 辰辰自刑，土自堆湿气重）+ 月日辰戌冲（魁罡日，走 R23 而非 R20）；辰戌是冲不是刑——不要混淆。双辰自刑 + 辰戌冲叠加 = 极重的库土张力，按 R23 + R48 + R51 共同处理
- （示例）任何带"寅巳"但缺申的命局 → 流年走申年时三刑被激活

### R49 · 六害（穿）/ 六破

**规则**：害与破是合冲刑害四大互动里**最轻**的两类——容易被忽略，但**位置敏感**时（紧邻、动到日支、命主核心字段）会显化为"暗损 / 隐性消耗"。

**六害表**（亦称"穿"）：

| 六害 | 五行属性 | 原理 | 典型意象 |
|---|---|---|---|
| **子 ↔ 未** | 水土 | 子合丑、未冲丑 → 子的合被未破坏 | 暗中拆台、关系疏离 |
| **丑 ↔ 午** | 土火 | 丑合子、午冲子 → 丑的合被午破坏 | 关系突变、利益冲突 |
| **寅 ↔ 巳** | 木火 | 寅合亥、巳冲亥 → 寅的合被巳破坏（且巳寅同时也刑！详 R48）| 合作中带刺 |
| **卯 ↔ 辰** | 木土 | 卯合戌、辰冲戌 → 卯的合被辰破坏 | 资源被截胡 |
| **申 ↔ 亥** | 金水 | 申合巳、亥冲巳 → 申的合被亥破坏 | 暗中竞争 |
| **酉 ↔ 戌** | 金土 | 酉合辰、戌冲辰 → 酉的合被戌破坏 | 渐进消耗 |

**害的判定原理**：**害 = 破坏对方的合**——A 本可合 X，但 B 冲走 X，于是 A 的合不成→A 暗中被 B 损耗。所以害是"间接攻击"。

**六破表**：

| 六破 | 性质 |
|---|---|
| **子 ↔ 酉** | 金生水反破——水太多金被泄到崩（如 Case 001 午酉破中酉被破）|
| **午 ↔ 卯** | 木生火反破——木被火烧空 |
| **巳 ↔ 申** | 注：巳申同时是合 + 刑 + 破，复合关系，破的力度极弱 |
| **寅 ↔ 亥** | 注：寅亥同时是合 + 破，破被合压制，几乎不显 |
| **辰 ↔ 丑** | 土土同破——内耗 |
| **戌 ↔ 未** | 土土同破——内耗（同时戌未也刑）|

**破的判定原理**：**破 = 一方对另一方的轻度损耗**——最弱的负面互动，但**位置极敏感时**（紧邻日支 / 时支）能显化。

**害 vs 破的力度对照**：

| 维度 | 害（穿）| 破 |
|---|---|---|
| 力度 | ★ 轻 | ½ ★ 最轻 |
| 显化条件 | 紧邻 + 涉及命主核心字段 | 紧邻 + 大运 / 流年同时触发 |
| 典型现实 | 暗中拉扯、长期消耗、关系疏远 | 局部小损耗、表面无事但实质有耗 |
| 修复 | 通过合化或通关可解 | 几乎自动衰减，除非反复触发 |

**位置距离效应**（六害 / 六破共用）：

| 距离 | 力度 |
|---|:-:|
| **紧邻**（相邻两柱）| 100%（仍是 ★ 轻级别）|
| **隔位**（隔一柱）| 30-40% |
| **遥位**（年时柱）| 几乎不显 |
| **大运 / 流年补出**害破对字 | **触发型显化**（详 R51）|

**复合关系的优先级**（v2.0 关键判定）：
当两支同时具备多重关系时——**优先级**：

```
冲 > 刑 > 合 > 害 > 破
```

例：
- **巳 + 申**：同时是 **合 + 刑 + 破**

### R50 · 天干五合

**规则**：天干两干相合——比地支合更直接（天干是显出的能量），合化条件更严，且**日主合财官**有专属读法。

**五合表**：

| 五合 | 阴阳 | 合化方向 | 化神性质 |
|---|---|---|---|
| **甲 ↔ 己** | 阳 + 阴 | 合化**土** | 中正之合（甲己合土，土性中和）|
| **乙 ↔ 庚** | 阴 + 阳 | 合化**金** | 仁义之合（乙木仁、庚金义）|
| **丙 ↔ 辛** | 阳 + 阴 | 合化**水** | 威制之合（火克金→水）|
| **丁 ↔ 壬** | 阴 + 阳 | 合化**木** | 淫慝之合（古名，现代解读：感性纠缠）|
| **戊 ↔ 癸** | 阳 + 阴 | 合化**火** | 无情之合（戊老阳合癸老阴，差距大）|

**合化的严格条件**（子平视角，三条全满足才"真化"）：

1. **化神得月令** — 化神（合化后的五行）必须在月令支持。例：甲己合土，月令须是辰戌丑未或巳午（火生土）
2. **化神透干** — 化神在天干透出且不被克
3. **无破坏** — 合的两干之间无被其他干夺合（如双甲合一己 = 妒合）

**化的等级**：
- **真化**（三条全满足）→ 两干转化为化神五行，本气消失，命局结构大变
- **化而不真**（满足 1-2 条）→ 化神有效力但本气仍留
- **合而不化**（条件不满足）→ 两干能量收拢但**五行不变**——**这是最常见情况**

**位置距离效应**：

| 距离 | 合的力度 |
|---|:-:|
| **紧邻合**（相邻两柱天干）| 100% |
| **隔位合**（隔一柱）| 50-60% |
| **遥合**（年时柱天干）| 20-30% |
| **日主合临干**（最敏感）| 100% + 心理学意义重大（见下）|

**日主合财官的专属读法**（v2.0 关键）：

当**日主天干**直接与命局中的财、官、印、食伤相合，有特殊心理意象：

| 日主类型 | 与什么合 | 心理意象 |
|---|---|---|
| **女命日主合正官**（如丙女合辛）| 正官 | 对**正配 / 婚姻 / 制度权威**有"天然吸附"——但是否成婚仍看结构 |
| **女命日主合七杀** | 七杀 | 对**有压力感 / 高强度 / 不安全感**的男性有吸附（"危险吸引"） |
| **男命日主合正财**（如甲男合己） | 正财 | 对**传统 / 稳定 / 节俭**的女性有吸附 |
| **男命日主合偏财** | 偏财 | 对**新潮 / 自由 / 流动**的女性有吸附 |
| **日主合食伤** | 食伤 | 对**自己的表达 / 输出**有强烈认同 |
| **日主合印** | 印 | 对**学习 / 母性 / 庇护**有依赖 |

**关键边界**（v2.0 强调）：
- 日主合 X **不等于"X 一定会发生"**——这是**心理倾向 / 吸附模式**，不是事件预测
- 日主合官 ≠ "命中有官"或"必然婚姻"——只是"婚恋议题与正官符号有强心理共振"

- **禁用语**："日主合官 = 命中注定的婚姻" / "日主合财 = 命中财来找人"——这些是预测引擎语言，违反 SKILL.md symbolic framework 声明

| 场景 | 现象 | 读法 |

**真化的特殊命局**：

### R51 · 动静博弈复合规则

**规则**：合冲刑害的真正威力不在单一规则，而在**复合互动**——本命原局是"静"，大运 / 流年是"动"，动静互作产生**触发 / 解化 / 释放 / 加重**四类核心效应。本条规则是**整个 J 节的总成**，是命局变化的"博弈机器"。

#### 51.1 静态原局内部的合冲互解

原局自身的合冲刑害组合在不同情况下互相牵制：

**合冲互解规则表**：

| 原局配置 | 互动效应 | 解读 |
|---|---|---|
| **A 冲 B**（紧邻） | 标准冲，按 R20 v2 | 正常冲力 |
| **A 冲 B，但 B 合 C**（B 被合住） | **合解冲**——B 被 C 收拢，冲到 B 的力被牵制 | 冲力降至 30-50% |
| **A 合 B，但 C 冲 A**（A 被冲走） | **冲开合**——A 被 C 拉走，合不成 | 合力降至 0-30% |
| **A 合 B + C 合 B**（B 被两支争合）| **妒合 / 争合**（详 R46 / R50）| 合力分散 |
| **A 合 B + A 也合 D**（A 同时合两个）| **A 妒合**——A 的合力被稀释 | 两个合都打折 |
| **三刑全齐** + **其中一支被合住** | 刑被合住的那支牵制 | 刑减弱 |
| **库冲**（辰戌 / 丑未）+ **库藏被合**（库内藏干通过其他干合住）| 库虽冲但藏干被牵制 | 释放被限制 |

**核心原理**：
- **合是"控制"** —— 把某支收拢起来，让它无法做其他事
- **冲是"动**" —— 让某支动起来，但若该支被合住则动不了
- **优先级**：合 > 冲（在解化场景）—— 合住的字几乎不能被冲掉

#### 51.2 大运 / 流年作用于原局的动静框架

**核心隐喻**：原局是**操作系统**（静态结构），大运是**赛道**（10 年环境变量），流年是**市场波动**（1 年触发事件）——见 R36 四层叠加诊断。

**大运 / 流年 vs 原局的互动类型**：

| 互动类型 | 判据 | 效应 |
|---|---|---|
| **大运 / 流年支冲原局某支** | 流年支冲日支、月支等 | 该柱所代表的领域被触发 |
| **大运 / 流年支合原局某支** | 流年支合日支、月支等 | 该柱所代表的领域被收拢 / 牵制 |
| **大运 / 流年支刑 / 害 / 破原局某支** | 同上但是刑/害/破 | 缓慢消耗 / 暗损 |
| **流年支与原局形成三合 / 三会** | 缺一字 + 流年补出 | **触发型激活**——拱合 / 半合在流年补出第三字时全效启动 |
| **流年与原局同字**（伏吟）| 流年地支与原局某地支相同 | **伏吟**——同字重复，加重该字的能量 |
| **流年与原局相冲**（反吟）| 流年地支冲到原局重要柱支 | **反吟**——动荡，反复无常 |
| **流年填实空亡** | 流年地支填到原局空亡的位置 | **空亡被填实**——之前虚的位置突然有事 |

**伏吟 / 反吟的特别警示**（v2.0 关键）：

| 类型 | 现象 | 心理意象 |
|---|---|---|
| **伏吟**（同字相叠）| 原局某字 + 大运 / 流年同字 | **同样的事重复发生**——往复循环的模式 |
| **反吟**（同字相冲）| 原局某字 + 大运 / 流年冲字 | **完全相反的动荡**——反复无常 |
| **岁运并临**（流年干支 = 大运干支） | 极罕见但极重 | **能量最集中的一年**——大事件高发期 |
| **天克地冲**（流年天干克日主 + 流年地支冲日支） | 流年壬克丙日 + 流年申冲寅日 | **双重冲击**——压力最大的年份 |

**太岁不可冒犯**（古法）：
- 流年地支 = 太岁——**原局无法"反向冲"太岁**（命局某支与太岁冲 ≠ 命局赢，是太岁压制命局）
- 流年若**冲日支**（"冲太岁"） → **婚姻 / 健康 / 居所** 议题被触发
- 流年若**合日支** → **关系 / 合作 / 婚姻**议题被触发
- 流年若**与日干同字**（"伏吟太岁"）→ 自我模式加重

#### 51.3 库的冲开做功（重要专项）

**辰戌丑未"四库"在被冲开时的特殊读法**（v2.0 关键，盲派核心）：

| 库 | 藏干 | 冲开后释放 |
|---|---|---|
| **辰**（水库）| 戊（主）+ 乙、癸 | 戊乙癸出墓——尤其癸水（水的库藏）|
| **戌**（火库）| 戊（主）+ 辛、丁 | 戊辛丁出墓——尤其丁火（火的库藏）|
| **丑**（金库）| 己（主）+ 癸、辛 | 己癸辛出墓——尤其辛金（金的库藏）|
| **未**（木库）| 己（主）+ 丁、乙 | 己丁乙出墓——尤其乙木（木的库藏）|

**库冲的判读流程**：

```
辰戌 / 丑未冲 →
  ├─ 库内藏干是命局用神？
  │   ├─ 是 → 库冲开 = 用神出墓 = 好冲（用神可用了）
  │   └─ 否 → 库冲开 = 忌神出墓 = 坏冲（忌神被放出来）
  └─ 库内藏干通过其他干合住？
      ├─ 是 → 释放被限制
      └─ 否 → 全效释放
```

**关键边界**（v2.0 强调）：
- 库冲≠单纯破坏 —— "冲开做功"是盲派核心读法
- 子平传统认为库不冲不发——这与"库冲一律坏"是两件事
- 议会立场：**看库藏的是什么** —— 释放出来的是用神还是忌神

#### 51.4 触发优先级总规则

当原局 + 大运 + 流年三层同时有合冲刑害互动时，**优先级**：

```
流年（爆发力最强）
 > 大运（持久力最强）
 > 原局静态（基准）
 > 流月 / 流日（短期波动）
```

**复合触发的强度**：
- **三层共振**（原局、大运、流年都指向同一动作）→ **极强触发**——见 R44 突出矛盾扫描

- **单层触发**（仅流年冲日支）→ 标准触发，看是否动到核心字段
- **跨层冲突**（如大运合日支 + 流年冲日支）→ **拉扯模式**——同一议题被"想稳定"和"想动"两种力量同时拉

**议会读法**（脱毒输出）：
- ❌ "2025 年酉年冲日支卯 → 一定会换工作 / 离婚"
- ✓ "2025 年酉年冲日支卯——你的'我'与'伴侣'议题进入高动态——这是张力，不是判决"

#### 51.5 失败模式（要避免）

### R52 · 子平 vs 盲派合冲读法 sync 框架

**规则**：八字内部的子平派 vs 盲派对合冲刑害有**真实的方法论分歧**——议会**不强行折中**（违反 SKILL.md 的对齐算法），而是**按场景分工 + 冲突时明示**。

#### 52.1 两派核心分歧地图

| 维度 | 子平派 | 盲派 |
|---|---|---|
| **合的本质** | 化与不化（看五行变化）| 收拢与做功（看能量归属）|
| **冲的本质** | 破坏与平衡（看五行得失）| 动与不动（看动出来是什么）|
| **库冲** | 一般忌冲 | 冲开做功——看库藏 |
| **刑的本质** | 命局瑕疵 | 长期张力 / 可挖掘动机 |
| **害破** | 次要可忽略 | 位置敏感时仍重要 |
| **日主合官财** | 看是否化（化气格）| 看心理吸附与调动 |
| **天干合** | 合化条件严判 | 合即"收住"——本身做功 |
| **核心问题** | "**化得真不真**" | "**谁合谁 / 谁动谁**" |

#### 52.2 议会内部仲裁规则

**规则 52-A**：**默认场景听子平**——子平是命局结构的"基础语法"，多数命局走子平判断已足。

**规则 52-B**：**特定场景听盲派**——以下场景盲派更精细：
- **库冲做功**（辰戌 / 丑未冲）→ 盲派
- **日主合官 / 财的心理动力学**→ 盲派
- **我宫 / 他宫的字段定位**（已有 R33）→ 盲派
- **合制做功**（合是否"做功"）→ 盲派（已有 R34）
- **拱合的潜在激活**（大运补字触发）→ 盲派

**规则 52-C**：**临界场景两派并陈**——两派给出不同结论时，**议会输出双视角，让用户看到张力**：
- 例（Case 005）：辰戌冲，子平视角 = "冲开土库不利"；盲派视角 = "冲开释放藏干做功"——并陈
- 例（Case 001）：**壬辰大运辰** + 原局**日支酉** 形成辰酉合金，子平视角 = "化神金是用神，半化有效"；盲派视角 = "外部资源（大运辰）喂给我宫（日支酉）"——两个视角同时为真

**规则 52-D**：**禁止伪折中**——以下表达违规：
- ❌ "两派都有道理，取中道"
- ❌ "我们综合判断认为..."
- ✓ "子平视角说 X，盲派视角说 Y，两者**不冲突**——子平看 [五行变化]，盲派看 [能量归属]"
- ✓ "子平视角说 X，盲派视角说 Y，**真冲突**——你想从 [五行平衡] 还是 [做功效率] 的角度来看这件事？"

#### 52.3 与 SKILL.md "主语对齐算法" 的对应

SKILL.md 第 3 节（Layer 3 真博弈）已经定义**时间层 / 领域层 / 因果层**的对齐三步算法。**R52 是该算法在八字内部子平vs盲派分歧的专项应用**：

| 对齐维度 | 子平 vs 盲派的典型分歧 | 处理 |
|---|---|---|
| **时间层** | 子平看终生结构 vs 盲派看大运触发 | **不同时间层 → 并列呈现**（不是冲突）|
| **领域层** | 子平看五行平衡（结构）vs 盲派看做功效率（操作）| **不同领域 → 并列呈现** |
| **因果层** | 子平看本命静态 vs 盲派看动静博弈 | **不同因果 → 并列呈现** |

**多数"分歧"其实是不同层的同时真实**——按 SKILL.md 算法，这些是**伪冲突**，并陈不折中。

**真冲突**（三层标签完全相同时）的处理：
- 例：同一时间、同一议题、同一动作（如"是否冲开库做功"），两派给出相反断语
- 处理：**明示冲突 + 元问题反问用户**："你想从 [子平五行结构] 还是 [盲派做功效率] 的角度来看这件事？"
- **最终决策权永远在用户**

#### 52.4 输出层处理（脱毒后）

主 agent 在合成给用户的最终输出时：
- **不在用户面前讨论 "子平" / "盲派" 这种流派标签**（除非用户主动问）——这是议会内部术语
- 改用**功能性描述**：
  - 子平 → "**结构性判断**" / "**五行平衡的看法**"
  - 盲派 → "**能量流向的看法**" / "**做功效率的看法**"
- 让用户看到的是**两种视角的并陈**，不是"两个学派的争执"

**与其他规则的接口**：
- 主语对齐算法详 **SKILL.md** "Layer 3: 冲突明示"
- 流派分歧的典型例 → **R34**（合制做功）/ **R47**（半合做功）/ **R51**（库冲做功）
- 议会议事流程 → **R44**（突出矛盾扫描）+ **R45**（古典格局优先）

**来源**：SKILL.md 主语对齐三步算法 + 段建业盲派与子平派的方法论差异综述 + 议会"双轨并陈不折中"哲学
**验证**：
- Case 001：原局**巳半合酉** + 大运**壬辰带来的辰酉合** → 子平说"半合 + 大运六合 = 金局倾向强化，化神金为用神" + 盲派说"原局禄（巳）合财（酉） + 大运外部资源（辰）喂入我宫（酉）= 多重做功" → **不同领域层（五行平衡 vs 能量流向）** → 并陈呈现
- Case 005：辰戌冲（双魁罡）→ 子平说"双库冲不利" + 盲派说"冲开释放藏干，看用神" → **真冲突场景** → R23 + R52 共同处理：先走 R23 魁罡专项 + R52 元问题反问
- Case 006：双午伏吟 + 时支戌 → 子平说"火过旺" + 盲派说"火做功结构强，时支戌火库收藏" → **不同领域层** → 并陈

### R57 · 桃花专项规则

**规则**：桃花（咸池）是**关系吸引模式 / 性张力 / 关系议题**的**结构标记** —— 本规则把传统命书的桃花系统化为现代脱毒可用的关系议题工具。**仅处理桃花一项，不扩展到全套神煞**。

#### 57.1 桃花的判定（两种系统并用）

**A. 四桃花（固定地支）**
**子、午、卯、酉** 本身就是桃花地支——任一命局有这四支之一即带桃花性。

**B. 局桃花（三合沐浴位）**

| 三合局 | 桃花位 |
|---|:-:|
| 申子辰水局 | **酉** |
| 亥卯未木局 | **子** |
| 寅午戌火局 | **卯** |
| 巳酉丑金局 | **午** |

**议会立场**：两种判定**并用** —— 满足任一条件即识别桃花。命局**同时满足两种**时，桃花性叠加（如亥卯未木局成 + 日支子 = 子既是四桃花又是局桃花 → "双重桃花"）。

#### 57.2 桃花的位置敏感性（接 R33 我宫识别）

| 桃花位置 | 含义 |
|---|---|
| **年支桃花** | 早年 / 祖辈 / 外部环境层的关系议题 |
| **月支桃花** | 成长 / 同辈 / 关系底色层的议题 |
| **日支桃花**（最敏感）| **配偶宫桃花** → 关系结构核心标记 |
| **时支桃花** | 晚年 / 子女 / 我追求方向的关系议题 |

**关键规则**：
- 桃花落**日支**最敏感——配偶宫直接带桃花标记，是关系结构的核心信号
- 桃花落**月支** + 与羊刃 / 禄重叠 → **羊刃桃花** / **禄桃花**（极性桃花）

#### 57.3 桃花与十神叠加（v2.0 关键扩展）

桃花地支本身只是标记 —— **真正决定关系画面**的是**桃花所在位的十神性质**（包括桃花藏干的十神）：

| 桃花 + 十神 | 现代脱毒意象 |
|---|---|
| **羊刃桃花**（桃花叠羊刃位）| 倾向被"强势 + 高吸引力 + 有锋芒"型激活；关系易触发自身极性反应（控制 ↔ 反控制）|
| **禄桃花**（桃花叠日主禄位）| 倾向被"自带能量 / 独立性强 / 自我中心"型激活；关系是两个"主体"之间的事 |
| **印桃花**（桃花在印位） | 倾向被"滋养 / 庇护 / 学识 / 母性"型激活；通过共同学习 / 心智成长结缘 |
| **食伤桃花**（桃花在食伤位）| 倾向被"才华 / 表达 / 创意 / 灵感"型激活；关系靠创造性能量维持 |
| **财桃花**（桃花在财位）| 男命常见——倾向被"有资源 / 经营感 / 物质感"型激活 |
| **官桃花**（桃花在官杀位）| 女命常见——倾向被"权威 / 制度感 / 责任感"型激活；男命读为"竞争 / 制度型伴侣" |
| **比劫桃花**（桃花在比劫位）| 倾向被"同辈感 / 兄弟姐妹型 / 平等关系"激活 |

**关键边界**：
- 桃花叠的十神**就是**关系吸引模式的方向标
- 命局**多种桃花十神并存** → 多种关系吸引模式同时存在（详 57.4 桃花互动）

#### 57.4 桃花的互动（桃花字参与 R20 v2 + R46-R52 合冲刑害体系）

桃花字本身也是地支 —— 完整参与合冲刑害互动。**桃花互动的特殊读法**：

| 互动 | 现代脱毒意象 |
|---|---|
| **桃花刑**（如子卯互刑 / 寅巳申中包含卯）| 两层关系吸引模式**互相拉扯**——结构性的"我到底要哪种"长期议题；"无礼之刑"（子卯）+ "恃势之刑"（含卯的寅巳申）特别明显 |
| **桃花冲**（如子午冲 / 卯酉冲）| 两种关系模式**互相否定**——拉扯强 / 关系议题反复；四正冲力度最大 |
| **桃花合**（如子丑六合 / 卯戌六合 / 午未六合 / 辰酉六合等）| 关系吸引模式被外部"收住"——稳定但易"被定型 / 被牵制" |
| **桃花伏吟**（如双卯 / 双子 / 双午 / 双酉）| 同一种关系模式被加倍——容易"反复进入同一类关系" / 模式锁定 |
| **桃花三合 / 三会**（如子辰申成水局，桃花酉若在其中）| 关系吸引力被**结构化放大**——"桃花成局"是关系议题的高度结构化 |

**关键边界**（v2.0 严判）：
- 桃花的合冲刑害**不独立判决吉凶** —— 必须配合**桃花叠的十神是用神还是忌神**来读
- 桃花是用神位 → 关系议题对命局是助力
- 桃花是忌神位 → 关系议题对命局是耗损
- **不预测"情史"** —— 描述结构倾向，不描述事件

#### 57.5 大运 / 流年桃花的触发（接 R51 动静博弈）

| 触发场景 | 含义 |
|---|---|
| **大运地支带桃花字** | 该十年关系议题被结构性激活（如壬子大运、丙午大运、辛卯大运、丁酉大运）|
| **流年地支带桃花字** | 该年关系议题被短期触发 |
| **大运 / 流年与原局桃花合 / 冲 / 刑** | 关系议题进入"动"的状态——具体动静看合冲性质（详 R51）|
| **大运 / 流年补出原局缺的桃花字** | "**桃花字突然到位**"——结构上意味着原本潜伏的关系吸引模式被激活 |

**关键边界**：
- 桃花年 / 桃花运 ≠ "**必有桃花事**"——是议题势能进入显化窗口，是否发生"事"取决于命主反身性选择
- "**桃花年提防 X**"类预测语严格禁用

#### 57.6 子平 vs 盲派对桃花的分歧（接 R52）

| 视角 | 子平 | 盲派 |
|---|---|---|
| 桃花的本质 | 神煞标记 / 关系议题指示器 | 关系做功路径 / 关系做功支点 |
| 重视程度 | 中等（次于格局 / 用神 / 十神）| 较高（与做功路径直接相关）|
| 处理方式 | 配合十神读 | 配合我宫识别 + 做功结构读 |
| 桃花在他宫 vs 我宫 | 不强调差异 | **重要差异**——桃花在我宫=可调动 / 在他宫=被动接受 |

**议会立场**：**两派并陈不折中** —— 子平用桃花作为"关系议题指示器"，盲派用桃花作为"关系做功路径"。临界场景两视角同时呈现。

#### 57.7 禁用 / 边界（最严）

- ❌ "桃花重则情乱 / 桃花多则克妻 / 桃花刑必离婚 / 桃花年必动情"——**封建命书旧说，严格禁用**
- ❌ "桃花见官杀则贵 / 桃花见食伤则贱"——标签化判断，禁用
- ❌ "桃花年必有桃花事"——事件预测，禁用
- ❌ "命带桃花克夫 / 克妻 / 妨家"——封建家庭伦理判定，严格禁用
- ❌ 对女命特别加重的桃花贬抑读法——性别歧视性表达，严格禁用
- ✓ 桃花是**关系吸引模式的结构标记**——描述"被什么类型激活"，不描述"会发生什么事"
- ✓ 桃花互动是**关系议题的张力诊断**——描述"两种模式拉扯"，不描述"必然出事"

#### 57.8 应用流程（标准 SOP）

```
Step 1: 扫描原局有无四桃花字（子午卯酉）
        ├─ 有 → 进入 Step 2
        └─ 无 → 检查局桃花条件（三合 / 半合成局且桃花字补出）

Step 2: 定位每个桃花字的位置（年/月/日/时支）
        └─ 日支桃花最敏感（配偶宫直接带桃花）

Step 3: 看每个桃花位的十神性质（含藏干透干）
        └─ 确定"桃花 + 什么十神"的叠加（羊刃桃花 / 印桃花 / 财桃花等）

Step 4: 扫描桃花字之间的互动
        ├─ 桃花互刑 / 互冲 → 多种关系模式拉扯
        ├─ 桃花合 → 关系模式被收住
        └─ 桃花伏吟 → 单一模式被锁定

Step 5: 扫描原局桃花与大运 / 流年的互动
        └─ 大运 / 流年带桃花字、与原局合冲刑害 → 议题触发时机

Step 6: 综合输出（脱毒）
        ├─ 描述"被什么类型激活"（结构倾向）
        ├─ 描述"两种模式拉扯"（结构张力）
        └─ 描述"议题触发时机"（动态议题）
        永远不描述"会发生什么事件"
```

### R58 · 十神标注自检（每次输出强制）

**规则**：subagent 在输出涉及具体十神判断时（特别是流年 / 大运 / 命局某干支的十神性质），**必须基于 paipan_engine JSON 中的 `天干十神` / `地支十神` 字段做最终标注**——不能自己推算。

**触发场景**（最低要求）：
- 流年 / 大运的十神类型判定
- 命局某干支的十神类型描述
- 任何在输出文本中明示"X 是日主的 Y（十神）"的语句

**自检流程**（每次输出前必走）：

```
Step 1: 扫描输出文本中所有"X 是 Y（十神名）"模式的语句
Step 2: 对每条断言，去 paipan_engine JSON 的 天干十神 / 地支十神 字段验证
Step 3: 不一致 → 必须修正
Step 4: 自检通过 → 才能输出
```

**常见误读模式**（v1.0 已知）：

| ❌ 误读 | ✅ 正确 |
|---|---|
| 日主丁 + 流年丙午 = "丙是偏财" | 丙是**劫财**（异性同五行：丙阳火 + 丁阴火）|
| 日主丁 + 流年壬 = "壬是七杀" | 壬是**正官**（异性相克：壬阳水克丁阴火）|
| 日主甲 + 流年戊 = "戊是七杀" | 戊是**偏财**（同性相克：戊阳土，甲阳木克之）|
| 用日主自己的五行（如丁火）判流年同五行（如午火）的十神 | **必查阴阳同性 / 异性** —— 火不是火的财，金才是火的财 |

**阴阳同性 / 异性快速口诀**：
- **同性**（阳-阳 / 阴-阴）= 比 / 偏 / 食 / 杀 / 偏印
- **异性**（阳-阴 / 阴-阳）= 劫 / 正 / 伤 / 官 / 正印

**严格规则**：
- 任何在合成输出阶段对十神的描述，**必须**先过 paipan_engine 标注的字段
- 如果 paipan_engine 没给标注（罕见），手动验证用：日主天干 vs 目标干（阳阴 + 五行）→ 查十神表

**触发来源**：
- 2026-05-25 Case 001 回归测试中命主反馈："2026 丙午对丁日主是**劫财不是偏财**" —— agent 在输出阶段连续误读 4 次，未做自检

**与其他规则的接口**：
- **R43 双层脱毒输出** → R58 在 R43 之前必走
- subagent 输出 JSON 时 → 内部 `rough_calc` 阶段也要走 R58

### R59 · 现实变量必问（重大决定共振场景）

**规则**：当用户提出涉及"**重大人生决定 / 启动新事业 / 跨境 / 搬家 / 创业 / 辞职 / 大额投入**"类问题时，议会**必须先收集四个现实变量**——**不允许从历史 context 中默认 carryover**。

**触发场景**（任一即触发）：
- 用户问"我能不能 / 该不该 / 适不适合做 X"，且 X 涉及职业 / 经济 / 居住 / 关系层重大变动
- 用户描述"我想开始做 X"，且 X 需要时间 / 金钱 / 精力的非平凡投入
- 用户描述"我想去 X 地方 / 移居 X / 跨境"

**必问四变量**：

| 变量 | 问什么 |
|---|---|
| **现金 runway** | 多少月生活费 buffer（不算房贷 / 父母资助 / 信用卡额度）|
| **家庭责任** | 依赖你收入的人（父母 / 配偶 / 子女 / 持续支持的对象）|
| **主业状态** | 在职 / 待业 / 准备辞 / 副业是主业兜底还是裸创业 |
| **后路 / fallback** | 万一新方向不成，回主流市场 / 原职业的"门票"还在吗 |

**关键规则**：
- **不假设**——即使用户之前提过类似 context，新问题要重新问（context 是流动的）
- **不替用户做出**"我以为你 / 默认你 / 想必你已经"型预判
- 收集完四变量**才能进入命理结构分析**

**输出格式（询问阶段）**：

```
你提到想做 X —— 这是涉及 [职业 / 经济 / 居住 / 关系] 层的重大决定。
在我用命局结构给你诊断前，我需要先确认四个现实变量：

1. 现金 buffer：[问]
2. 家庭责任：[问]
3. 主业状态：[问]
4. fallback：[问]

这四个变量会决定我给你的"时机 + 风险"建议是"裸创业模式"还是"副业试水模式"
——两者完全不同。
```

**收集后**：才进入完整的 R44 → R45 → R56 → R57 工作流。

**触发来源**：
- 2026-05-25 Case 001 回归测试 —— agent 默认命主"刚被辞退 + 无收入 + 裸创业"，但命主实际"**有主业正财 + 副业试水**" —— 风险评估方向完全相反

**与其他规则的接口**：
- **元边界 #0**（开门 / 关门自检）→ 不问现实变量就给重大决定建议 = 关门动作
- **R44** 突出矛盾扫描 → 现实变量也是矛盾扫描的对象
- **SKILL.md 的"创业共振场景必问"** → R59 是其形式化版本

### R60 · 城市方位双轨实地法

**规则**：当涉及"**地理方位选择 / 搬家 / 跨境 / 旅居 / 求职地点**"类问题时，议会**必须同时跑两法**判定每个候选城市的五行气场——**不能只用子平方位法（地理）打包**。

**双轨方法**：

| 法 | 判据 | 适用 |
|---|---|---|
| **子平方位法**（教条派）| 严格按地理方位（北水南火东木西金中土，洛书九宫）| **宏观远方方向**（如"喜东方"泛指）|
| **盲派实地法**（实操派）| 看城市的**实际能量配置**：海洋性 + 产业气 + 气候 + 文化 + 制度 | **具体城市选择** |

**实地法判定矩阵**（v1.0）：

| 维度 | 判定 |
|---|---|
| **海洋性** | 三面环海 / 港口 / 大河 → **水气重**；内陆 → 土气重 |
| **产业气场** | 金融 → **金**；科技 → 火（部分）；制造 → 金（部分）；农业 → 土 + 木；文化 → 木 + 火；商贸 → **金 + 水** |
| **气候** | 寒带 → 水；亚热带湿润 → 火 + 水；热带 → 火；温带干 → 金；高海拔 → 金 + 木 |
| **文化气质** | 商业流动 → **金水**；制度严密 → 金；自由表达 → 火；传统厚重 → 土 |
| **语言 / 法系** | 普通法 / 商业法系 → 金；大陆法 → 土；多语 + 国际化 → **金水** |

**两法冲突时**（v1.0 关键判定）：

按 **R52 子平 vs 盲派 sync 框架**处理：
- **议会立场**：**两派并陈，不强行折中**
- **默认实操优先实地法** —— 特别是当代国际金融中心 / 海港城市这种"地理 vs 实际"经常分裂的城市

**已识别的"分裂城市"清单**（v1.0）：

| 城市 | 地理方位 | 实地气场 | 分裂程度 |
|---|---|---|:-:|
| **香港** | 南方（火）| **金 + 水**（国际金融 + 海港 + 跨境 + 普通法系）| ★★★ 极分裂 |
| **新加坡** | 南方（火，赤道）| **金 + 水**（金融 + 海港 + 国际 + 双语制）| ★★★ 极分裂 |
| **东京** | 东方（木）| **水 + 部分木**（海洋 + 东方）| ★★ 中分裂 |
| **上海** | 东方（木）| **木 + 水**（江南 + 长江 + 部分金融）| ★ 较小分裂 |
| **迪拜** | 西方（中东视角）| **金 + 水**（金融 + 海港 + 国际中转）| ★ 较小分裂 |
| **海南** | 南方（火）| **火 + 水**（热带 + 海洋）| ★ 较小分裂 |
| 大部分内陆城市 | 按地理 | 与地理一致 | — |

**严格规则**：

- 输出任何"地理选择建议"前，**必须**对候选城市跑双轨判定
- 子平 + 盲派判定差距大时，**显式呈现两个视角**，让用户看到张力
- ❌ 不能用一句话"X 是南方火地"打发 —— **必须解释实地气场**
- ❌ 不能把"南方城市 / 北方城市 / 西方城市"打包成同一类 —— **每个城市单独跑实地法**

**典型应用案例**（v1.0 验证）：

**Case 001（喜金水）+ 候选"香港"**：

| 法 | 判定 | 顺水度 |
|---|---|:-:|
| 子平方位法 | 南方 = 火 → **不顺水** | ⭐ |
| 盲派实地法 | 金融 + 海港 + 跨境 = **金水双重** | ⭐⭐⭐⭐⭐ |
| **议会判定** | 两派分裂时按 R52 + 实地法 → **极顺水**（金水双层共振）| ⭐⭐⭐⭐⭐ |

**触发来源**：
- 2026-05-25 Case 001 回归测试 —— agent 默认按子平方位法把"香港 / 深圳 / 海南"打包成"南方火"，命主指出"**香港的金水很重啊**"，触发实地法的重新识别

**与其他规则的接口**：

- **R59 现实变量必问** → 跨境前必问现实变量（语言 / 签证 / 工作 / 家庭）
