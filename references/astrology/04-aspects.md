# 04 · 五大主要相位（实操版，不是百科）

**定位**：相位的**怎么用**手册。配合 R26（相位优先）/ R27（相位无好坏）/ R29（行星关系）使用。

**五大核心相位**（其他次级相位先不纳入）：
- **合相** 0°（conjunction）
- **对冲** 180°（opposition）
- **刑** 90°（square）
- **三分** 120°（trine）
- **六合** 60°（sextile）

**两类能量**：
| 类型 | 相位 | 特征 |
|---|---|---|
| **紧张相位**（冲突驱动）| 刑 · 对冲 | 推动成长，痛但动 |
| **流动相位**（顺滑惯性）| 三分 · 六合 | 容易但可能停滞 |
| **中性但最强** | 合相（看行星组合而定）| 能量融合 / 放大 / 扭曲 |

**容许度（orb）建议**：
- 合相 / 对冲 / 刑：**8°**（日月可扩至 10°）
- 三分：**6-8°**
- 六合：**4°**
- 外行星相互之间（天海冥）：相位长期存在，**容许度可放松至 5-6°**；但对个人行星影响强度主要看容许度紧密度

---

## 1️⃣ 合相（Conjunction · 0°）

**关键词**：**融合 · 放大 · 失去边界**

**本质**：
- 两颗行星"绑死"
- 分不开 → 能量叠加甚至扭曲

**怎么判断**：
- 两颗**同质能量** → 放大（火星+木星 = 更冲）
- 两颗**异质能量** → 内耗（月亮+土星 = 情感和结构撕扯）
- **个人行星 + 外行星**（如太阳合冥王）= 人格被外行星的集体能量"吞噬" or "赋能"——视乎当事人觉察层

### ⚠️ 核心坑：合相 ≠ 好

很多人把合相读作"强化增益"。**错**。合相是**最极端**的形态——两颗行星失去独立性，能量完全融合。

**诊断范例**：
- **太阳合月亮**（新月生人）= 本能与自我合一，但缺少内在对话张力 → 可能需要外界触发才觉察
- **金星合火星** = 爱欲合一 → 情感强烈但容易冲动 / 激情型关系主题
- **月亮合土星** = 情感 + 结构固化 → 情绪表达被习惯性压抑
- **火星合冥王** = 行动力 + 转化力融合 → 极致战斗力 / 也可能是隐藏暴力议题

**Case 001 应用**：金火合巨蟹 9 宫
- 金星（爱/美/价值）+ 火星（行动/欲）+ 巨蟹（保护/情感记忆）合相在 9 宫（远方/信念）
- 读法不是"温柔跨文化"（Barnum 级）
- 正确读法：**触动核心情感时战斗力爆发**——平时金星柔和，但遇到关乎"家/核心归属"议题时火星合相的能量瞬间点燃。这是独特"保护型战斗力"，在 9 宫意味着跨文化/远方领域会特别强烈。

## 2️⃣ 对冲（Opposition · 180°）

**关键词**：**拉扯 · 投射 · 关系课题**

**本质**：
- 两个极端对立
- 经常表现为"外界的人 / 关系"作为投射载体

**典型表现**：
- 你自己一边 → 压抑
- 另一边 → 投射到别人身上

**例子**：
- 金星 ☍ 火星 = 爱 vs 欲 → 感情中反复拉扯（要么找"太温柔"的人要么找"太激烈"的）
- 日 ☍ 月 = 意志 vs 情感 → 内在阳性与阴性的张力，关系中常投射给伴侣
- 水 ☍ 木 = 细节 vs 宏观 → 在具体思维和大局信念之间拉扯

### ⚠️ 核心重点：对冲的人绕不开"关系"

**人生必然需要通过"别人这面镜子"整合自己**。
- 单身无法真正避开这个主题——换人、换工作、换环境都会让同样的对冲主题再现
- **整合之路**：识别"我把哪一极投射给了谁" → 把投射收回来 → 自己活出两端

**Case 001 应用**：
- 太阳处女 11 宫 vs 海王水瓶 4 宫（若有对冲）= 服务型自我 vs 家族幻想的拉扯
- 上升天秤 vs 冥王射手（接近下降点）= 自我呈现 vs 亲密关系中的控制议题（R28 验证）

## 3️⃣ 刑（Square · 90°）

**关键词**：**冲突 · 卡顿 · 强驱动力**

**本质**：
- 两股能量"方向不兼容"
- 必须调整，否则一直卡

**表现**：
- 焦虑
- 不顺
- 反复碰壁

### ⚠️ 冷知识：刑相位 = 最容易成事的人

**机制**：有压力 → 才会动。很多"大成就者盘"都是一堆刑——不是巧合，是机制。

**诊断原则**：
- 刑相位**不是凶**，是发动机
- 若当事人反馈"生活很顺但没成就感" → 警惕刑相位被"压抑"而非"使用"
- 刑相位被活出来的人 = **内在有一种持续的不安感**，这种不安驱动他们持续行动

**刑的三种活法**：
| 层级 | 状态 | 举例 |
|---|---|---|
| 无意识 | 痛 + 抱怨 + 反复卡 | 金刑土 → 反复进入"我不值得被爱"的感情陷阱 |
| 觉察 | 痛 + 行动 | 金刑土 → 意识到"我需要先接纳自己的价值，才能接受他人的爱" |
| 整合 | 痛转化为能力 | 金刑土 → 成为情感/关系领域的深度顾问（因为你懂它的痛）|

**Case 004 应用**：水星刑月亮 + 水星刑上升 + 金海刑 = 三刑齐发
- 表面是"表达不佳 + 付出型感情"的痛苦
- 深层是强驱动力——他必须一生在"如何表达真实自己"这个主题上反复打磨
- 这解释了他身上的压力感 + 也解释了他的潜在成就天花板

## 4️⃣ 三分（Trine · 120°）

**关键词**：**天赋 · 顺 · 不费力**

**本质**：
- 能量自然流动
- 不需要努力

**表现**：
- 很会某件事
- 轻松得到

### ⚠️ 真相：三分多的人容易"舒服废掉"

**太顺 = 不成长**。
- 三分是"出厂自带的资源"，但资源不等于被使用
- **大三角（Grand Trine）**尤其危险——三分闭环，天赋流畅到人不觉得需要努力 → 中年后常有"浪费才华"的遗憾
- **解法**：三分多的人需要主动制造压力点（参加挑战性项目 / 找严格的导师 / 设置不舒服的目标）

**与刑配合读**：
- 命盘多刑 + 少三分 → 辛苦但容易出成就
- 命盘多三分 + 少刑 → 天赋高但需主动设计压力
- **配合 R25 天道/人道**：三分 = 天赋（人道舒适区），但发挥不发挥取决于是否有"天道"压力推

---

## 5️⃣ 六合（Sextile · 60°）

**关键词**：**机会 · 可用资源 · 需要触发**

**本质**：
- 有潜力，但**不会自动发生**

**表现**：
- 你用 → 它帮你
- 你不用 → 它等你

**理解为"隐藏技能"**：
- 三分是"自动触发的资源"
- 六合是"需要主动激活的资源"
- 不激活 → 永远是沉睡的潜能

**判断规则**：
- 六合出现时，追问用户："**你有没有曾经尝试过在 X 领域做 Y 事**？"
- 若答"没"——这是沉睡的六合
- 若答"试过但没坚持"——六合是间歇性被用
- 若答"经常用" ——六合被激活

## 三步实用判断公式

看到任何相位，**按这个顺序**：

### Step 1：这两颗行星在争什么？
- 识别两颗行星的**核心原型**（参考 `01-planets.md`）
- 例：月亮 vs 土星 = 情感需求 vs 控制/限制

### Step 2：相位类型决定互动方式
- 紧张相位（刑/冲） → 冲突/拉扯
- 流动相位（三分/六合） → 顺滑/机会
- 合相 → 融合/放大/扭曲

### Step 3：这个人会怎么表现？
- 内耗？（压抑一边）
- 投射？（推给别人）
- 还是天赋？（自动顺流）
- 还是觉察后的使用？（有意识地把张力转为能力）

## 关键提醒：相位 ≠ 命运

很多人学到这里会开始问：

> "那我是不是性格就是这样了？"

**错**。

更接近现实的是：

> **相位 ≠ 命运**
> **相位 = 你默认的反应模式**

你可以：
- **无意识地活它**（大多数人）→ 相位表现为"我就是这样"
- **觉察后利用它**（少数人）→ 相位转化为能力 / 工具

**这与 R25（人道 / 天道）同构**：
- 默认反应模式 = 人之道（本能 / 加重失衡 / 无意识）
- 觉察后的选择 = 天之道（调节 / 修正 / 意识化）

**这是整本书的真正核心**——占星不是给你性格标签，是给你**默认反应模式的地图**，让你知道自己**默认会怎么反应**，从而选择**是否继续这样反应**。

## ⚠️ 99% 的人死在单相位解读

**单个相位几乎没有意义**。你必须同时看：

### 1. 行星是谁（最重要）
月亮 vs 土星 vs 冥王 vs 天王——完全不同的戏剧。
**优先级：个人行星之间的相位 > 个人行星-社会行星 > 社会行星-外行星 > 外行星之间（世代层面）**

### 2. 相位类型（冲突 or 流动）
见上。

### 3. 有没有形成结构（最容易被忽略）
- T-square → 压力驱动系统
- Grand Trine → 顺流天赋系统
- Stellium → 单点聚焦系统
- Kite → 天赋+现实驱动系统
- Yod → 结构性转向系统
- **完整手册**见 `05-configurations.md`——把这些结构当作**人格操作系统**，不是相位图鉴

**只有三者一起读才算"看到相位"**。
