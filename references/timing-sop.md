# 时间维度分析 SOP · 流年 / 大运 / Profection / Transit 综合

**定位**：当用户问"某年 / 某阶段会怎样"、"XX 运势如何"、"什么时候换工作"、"今年财运"等时间维度问题时，主 agent 必须按本 SOP 走。

**本文件是 R36（三层叠加）+ R37（Profection 规范）的实操手册。**

---

## 🧭 核心隐喻（输出默认语言）

> **命盘 = 操作系统（你是谁）**
> **大运 = 行业 / 赛道（10 年环境）**
> **流年 = 市场波动（1 年触发）**
> **Profection + Transit = 当季天气（月级 / 季级）**

**输出永远不是**："你 X 年会 Y"
**输出永远是**："你的操作系统在 X 年的市场波动下，更容易进入 Y 模式"

## 🔄 四层叠加判断框架

### Layer 1 · 命盘（操作系统）

**信息源**：paipan_engine 的 bazi + astrology 本命盘部分

**调用规则**：
- R1 v3 旺衰三维法（得令/得地/得势）
- R31-R35 盲派增强
- R4-R6 十神结构
- R26-R30 占星方法论
- R22 星座深层问题
- R28 结构模式（操作系统类型）

**输出问题**：**这个人的底层操作系统是什么？哪些是 default reaction，哪些是 conscious capability？**

---

### Layer 2 · 大运（行业 / 赛道）

**信息源**：paipan_engine 的大运 10 步 + 每步的十神 / 地支十二长生位

**调用规则**：
- R16 大运天干十神 → 能量渠道
- R17 大运干支分层（天干管表面顺 vs 地支管暗处隐）
- R24 辅助量化（查大运地支对日元的力量贡献）
- R25 人道/天道（大运五行是**加重本能** vs **激活天道**）

**判断流程**：
1. 找出**当前大运的天干十神**（如 Case 006 甲木偏印）
2. 判断**地支十二长生位**（如甲寅的寅是丙火长生 → 助身）
3. 与**命盘喜用神**对照：是助神还是忌神？
4. R25 判断：是人道加重还是天道激活？
5. 生成"**赛道特征**"——这 10 年命主处在什么样的环境能量下

**输出句式**：
> "你 [年龄起] 到 [年龄止] 走 [大运干支] ——这是 [偏印/正官/七杀/...] 透天干，意味着能量方向在 [...]；地支 [干支] 为你的 [长生/帝旺/墓/...]，暗流是 [...]；整体这 10 年你的默认赛道是 [描述]。"

---

### Layer 3 · 流年（市场波动）

**信息源**：paipan_engine 的流年（当年甲子）+ 与大运/命盘的刑冲合害

**调用规则**：
- R20 刑冲两面性（冲对象是忌神→好冲；冲对象是用神→坏冲）
- R16 变体：流年天干十神 → 该年主题
- 流年 × 大运互动（同步 / 对冲 / 合化）
- 流年 × 命盘互动（与日柱 / 时柱刑冲 → 事件可能性）

**特殊检查（流年技法）**：
- **天克地冲**：流年干支**完全**冲克本命某柱 → 重大转折窗口
- **三刑**：流年引发本命地支三刑 → 健康 / 官司 / 关系危机窗口
- **反吟伏吟**：流年与本命某柱完全相同（伏吟）或完全相冲（反吟）→ 主题重复 / 强化

**判断流程**：
1. 流年天干是什么十神？
2. 流年地支与命盘 / 大运有什么关系？（合 / 冲 / 刑 / 破 / 害 / 无）
3. R20 裁定：好冲 or 坏冲？
4. 综合：**这一年的市场波动主题是什么**？

**输出句式**：
> "[年份] [干支] 对你是 [十神主题]——天干 [...]，地支 [刑/冲/合/...]。这年你更容易被推到 [描述] 的场景。"

### Layer 4 · Profection + Transit（当季天气）

#### A. Profection（希腊化年运 · 西方体系）

**信息源**：paipan_engine 的 `astrology.profection_current_year`（当前）或 `calculate_profection(...)` 指定日期

**调用规则**：
- R37 Profection 规范（Modern vs Hellenistic 两系统等价，**按生日切换**）

**产出**：
- **激活宫**：当前 Profection Year 的 house（1-12）
- **宫主题**：该宫代表的人生领域（1=自我、2=资源、7=关系 ...）
- **LOTY**（Lord of the Year）：激活宫宫头星座的传统守护星
- **LOTY 本命落位**：LOTY 在本命盘哪个宫 → 该宫也被同步激活

**判断流程**：
1. 定位**当前 Profection year**（以生日切换）
2. 读**激活宫的主题**
3. 找 **LOTY 在本命的位置**（星座 / 宫 / 相位 / 是否逆行）
4. 综合：今年的**西方视角下的生活主题重点**

**输出句式**：
> "按希腊化 Profection，[年份] 你进入 Life Year [N]，激活 [宫号]宫（[主题]）；宫头星座是 [星座]，LOTY 是 [行星]，它在你本命盘落 [星座] [宫号]宫——这意味着 [本命宫] 的议题也被激活。"

#### B. Transit（过境 · 外行星主导）

**信息源**：Swiss Ephemeris（paipan_engine 当前不默认输出，按需调用）

**主流技法**（按影响力排序）：
1. **土星过境**（Saturn return = 29-30 岁 / 58-59 岁；土星触本命核心行星 = 结构性成熟窗口）
2. **木星过境**（12 年一轮回，触本命行星 = 扩张 / 机会）
3. **天王过境**（84 年一轮；触本命行星 = 突然断裂 / 觉醒）
4. **海王过境**（165 年一轮；触本命行星 = 消融 / 理想化 / 灵性）
5. **冥王过境**（248 年一轮；触本命行星 = 深度转化 / 崩塌重建）
6. **Progressed Moon**（二次推运月亮，约 27-28 年一周期，切宫位 = 情绪主题切换）

**判断原则**：
- 只看外行星（日/月/水/金/火过境太快，一般不单独判）
- **精确度**：紧密（0-1°）> 适中（1-3°）> 宽松（3-5°，仅参考）
- **触本命核心**：触 Sun/Moon/ASC/MC 最关键，触 Venus/Mars/Mercury 次之，触 Jupiter-Pluto 主要是世代层

**常见触发时段**：
- 土星回归（Saturn return）= 29-30 / 58-59 岁 → 人生结构重整
- 木星回归 = 12 / 24 / 36 / 48 / 60 岁 → 扩张窗口
- Saturn square natal Saturn = 7-8 / 21-22 / 35-36 / 50-51 岁 → 中年 / 阶段性结构张力
- Uranus opposition Uranus = 40-42 岁 → 中年危机窗口

**注意**：
- Transit 是**可选的高精度层**——不是每次分析都要做
- 只在用户问"短期 / 某月 / 某季"时启动
- 或当 L1-L3 给出的画面需要月级精度时启动

## 🎯 四层叠加的 SOP（主 agent 用）

当用户问"XX 年 / XX 阶段会怎样"时：

### Step 1 · 输入检查
- 生辰 + 出生地 + 性别 ✓
- 目标年份 / 阶段 ✓
- 当前反馈（工作 / 感情 / 身体 / 情绪）——用于层级诊断

### Step 2 · 调 paipan_engine 获取四层数据
```bash
python scripts/paipan_engine.py \
  --date YYYY-MM-DD --time HH:MM \
  --city <城市> --gender M|F
```
输出包含：
- bazi: 四柱 + 十神 + 大运 10 步 + 当前流年
- astrology: 10 行星 + 四轴 + 宫位 + 相位 + 配置 + **当前 Profection**

### Step 3 · 逐层标注意象
**L1 → L4** 依次走完，每层产出一个"主题句"。

### Step 4 · 跨层扫描
- 检测 L2 × L3 **合冲刑破**
- 检测 L3 × L4 **主题共振**（流年主题与 Profection 激活宫是否吻合）
- 识别**真冲突**（同层同主题矛盾）vs **伪冲突**（不同层并列真实）

### Step 5 · 识别关键节点
- 大运交运期（10 年切换窗口，前后 1-2 年为过渡）
- Profection 1H 回归年（age 12/24/36/48/60 = 身份重整）
- Transit peak（若算了 transit）
- 流年 × 命盘紧密刑冲年

### Step 6 · 脱毒合成输出
按以下模板：

```
### 【意图重构】
你问的不是"XX 年会 Y"——是"怎样的结构让 Y 更容易 / 更难发生？代价是什么？"

### 【四层所见】

**L1 · 操作系统**：
（命盘骨架 + 当下的默认反应模式 + 隐藏能力）

**L2 · 赛道（[大运名]，[年范围]）**：
（10 年环境能量 + 是助缘还是逆缘 + R25 人道/天道判定）

**L3 · 市场波动（[流年]）**：
（该年的主题 + 与大运/命盘的合冲 + 激活什么）

**L4 · 当季天气（Profection + 可选 Transit）**：
（LOTY 激活的本命宫 + 该季节的短期节律）

### 【双轨共振】（R21）
（哪些主题四层都指向同一方向 → 高象征强度）
（哪些是伪冲突并列真实 → 不强行统一）

### 【能动性地图】
- 哪些结构让 X 更容易实现？（四层交集里的杠杆点）
- 哪些是必须承担的代价？
- 关键节点在哪？（具体日期 / 月份 / 事件类型）

### 【必要的诚实】
- "更容易"不等于"会"
- 时间预测是"节律地图"不是"事件表"
- 权在你的秤上
```

## 🛠 Transit 常见触发场景（按需启动）

### 土星回归（Saturn Return）
- **时段**：29-30 岁 / 58-59 岁（大约）
- **主题**：**人生结构重整**。过去 30 年的身份 / 承诺 / 工作模式需要检视
- **常见体感**：沉重、犹豫、对"做得不够"的焦虑 → 其实是系统要求重新对齐
- **输出语言**："你正在土星回归窗口——这是系统性重整期，不是错了什么"

### 木星回归（Jupiter Return）
- **时段**：约 12/24/36/48/60 岁
- **主题**：**扩张窗口**——但要看木星本命状态（若木星有困难相位，扩张可能过度）
- **常见体感**：乐观感、新机会涌现

### Uranus Opposition Uranus（天王对冲本命天王）
- **时段**：**40-42 岁**（固定窗口）
- **主题**：**中年危机 / 觉醒**——突然想打破现有结构
- **注意**：这个过境只发生一次，一辈子那一次——值得重视

### 冥王过境本命行星
- **时段**：变化大（冥王 248 年一轮）
- **主题**：**深度转化 / 崩塌重建**——过境本命核心（Sun/Moon/ASC/MC）是一生主题期
- **注意**：周期长（可能 1-3 年），不是短期事件

## 🔍 层级诊断检查（每次分析完追问当事人）

用本 SOP 产出的分析，**必须结合当事人反馈**做层级诊断：

1. **L1 层面**的操作系统描述——"你熟不熟这个默认模式？"
2. **L2 层面**的赛道描述——"过去 X 年你确实在这个环境里吗？"
3. **L3 层面**的流年主题——"今年这个主题你有感觉吗？"
4. **L4 层面**的短期节律——"最近某个事件和时间节点匹配吗？"

**四层都共振**（当事人四项都强烈反馈"是的"）→ 高象征强度，可深入
**只有部分共振** → 说明当事人在某一层处于"无意识"状态，可以指出但不强调
**完全不共振** → 重新检视分析是否有方法论错误（回到 R36 流程审计）

## 🧠 哲学锚点（不可忘）

> "时间维度不是预测未来，是**给未来更丰富的象征地图**。"
>
> 命盘给你操作系统，大运给你赛道，流年给你波动，Profection 给你节律——四层信息加起来**不是为了告诉你"会发生什么"，是为了让你在任意时间点更清楚"自己处在什么结构中、能做什么选择"**。

**如果输出让用户更怕未来、更想"等着发生"**——SOP 失败。
**如果输出让用户更清楚当下能做什么行动、更有能动感**——SOP 成功。

  → 2027 过渡 + 2028 主动出击是下一个窗口

### 【必要的诚实】

## 🎬 结语

**这是 skill 为什么需要时间维度 SOP**：
- 用户问"命盘是什么" → L1 已足够
- 用户问"大概人生方向" → L1 + L2 已足够
- **用户问"XX 年/阶段如何"→ 必须 L1+L2+L3+L4 四层全走**

不走完四层就下断语 = 偷懒 = 滑回"预测引擎"。

**唯一的例外**：用户明确说"我不需要精确时间，只要大方向" → 可以省略 L4。但不能省略 L3（流年），因为用户问的是"年"。
