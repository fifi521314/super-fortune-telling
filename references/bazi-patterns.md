## 哲学定位

**格局 = 命局的"宪法"**——决定喜忌走向、用神排除范围、大运 / 流年的"赛道"性质。

为什么古典格局优先？
1. **千年验证胜过现代"快速法则"**——印多反忌 / 身弱用印这类规则只在普通命局上有效；遇古典格局必须先识别
2. **格局是结构性诊断**——不是经验法则，是建立在五行生克 + 月令气数 + 干支配合的严密推理上
3. **R44 突出矛盾扫描 + R45 古典格局识别** = 议会的"先抓中心 → 再用古法"双步法

**与现代规则的关系**：
- 命局**构成古典格局** → 用该格局的特定喜忌
- 命局**不构成古典格局**（普通命局）→ 才走 R1 三维扶抑 + R11 排除法
- 古典格局 ≠ 一定贵命——格局是**结构识别**，贵贱是**结构 × 大运 × 流年 × 反身性选择**的复合结果

**脱毒约束**（每个格局描述都遵守）：
- ❌ "X 格主大富贵" / "Y 格命主早夭"
- ✓ "X 格的结构倾向是 Z，在适配大运下更容易展开 Z，在逆运下张力是 W"
- 永远描述**结构倾向 + 张力 + 代价**，不描述**事件**

## 通用判定方法论（所有格局共用）

### 成格的三步走

```
Step 1: 月令本气透干？
  ├─ 是 → 月令正格立（如月支申本气庚 + 庚透 = 偏财格 / 财格）
  └─ 否 → Step 2

Step 2: 月令藏干透干？
  ├─ 是 → 月令次格立（如月支寅藏甲丙戊，丙透 = 食神格 / 比劫格视日主）
  └─ 否 → Step 3

Step 3: 特殊格局扫描
  ├─ 化气格条件？（日主与紧邻干合化）
  ├─ 专旺格条件？（某五行单一极旺）
  ├─ 从格条件？（日主极弱顺势从他）
  └─ 都不成 → 走 R1 三维扶抑判普通命局
```

### 破格的统一判定原则

**破格 = 成格的关键条件被冲、合、克破坏，使格局失效或减效**。统一判据：

| 破格类型 | 判据 | 修复条件 |
|---|---|---|
| **冲破** | 月令支被紧邻冲 | 有合解冲、有通关五行 → 部分修复 |
| **合化** | 关键透干被合住 | 看合化神是否仍助格局 |
| **克破** | 关键透干被克 | 有印护、有通关 → 部分修复 |
| **混杂** | 格局喜神 + 忌神同透 | 一清一浊 → 看清浊取舍 |

**修复不等于完全无伤**——破而能修是"格损不破"，全破是"格不成"。

### 临界判定（"假格" / "败格" / "破格"）

| 状态 | 含义 | 喜忌处理 |
|---|---|---|
| **成格** | 三条件全满足 | 走该格喜忌 |
| **假格** | 形似但根缺 / 化神不真 | 部分按该格读，临界场景以 R1 复判 |
| **败格** | 成格后被破，能修复但有伤 | 该格喜忌 + 警惕修复点 |
| **破格** | 成格后被破，无法修复 | 退回普通命局，走 R1 + R11 |

### 子平 vs 盲派分歧（详 R52 + R56）

| 维度 | 子平 | 盲派 |
|---|---|---|
| 格局的本质 | 命局的"结构形态" | 命局的"做功路径" |
| 重点 | 格局成不成 + 喜忌方向 | 谁做功 + 我宫怎么调动 |
| 临界判定 | 严判（假格不算格）| 灵活（结构倾向就有效）|
| 看用神 | 顺格局喜忌 | 看"我宫能调动什么" |

**议会立场**：两派**并陈不折中**——子平定结构方向，盲派增精度（详 R52）。

## 一、十大正格（月令格局）

> **十大正格 = 月令本气或藏干透出的十神所立之格**。是子平格局法的核心 —— 任何普通命局先扫月令立正格，再看是否需要复合格局或特殊格局接管。

### 1. 正官格

#### 古今并陈三段（R62 范式）

**【古意】**
《子平真诠》："正官者，月令之正官也，正官无伤为最贵"。古代命书把正官视为"贵气之首" —— 主官位、社会地位、制度认可。**特别对女命**："正官为夫" —— 把正官等同于丈夫位 —— **这是封建社会"女性价值=婚姻"框架下的标签化判定**。

**【现代心理解读】**
正官 = **"父性 / 守护者 / 秩序"原型**。它指向命主**对制度、规则、权威结构**的天然亲和 / 共振——不是"必当官"，是"对秩序感的心理共振"。在现代职场就是"体制内 / 制度型组织 / 规则清晰场景"对这类人特别适配。**对女命**：不是"丈夫位"——是命主**内在的"父性秩序感"原型** —— 这层会**投射到关系中**（被"有责任感 / 制度感 / 守护型"的人激活），但**不是"必然走向婚姻"的预言**。

**【具体场景】**
- 对正式职位 / 头衔 / 制度位敏感（注意"敏感"≠"想要"，是"能感受到 / 容易被这类结构吸引"）
- 在大型组织 / 政府 / 体制内的展开比 freelancer / 创业模式更顺
- 倾向"按规则做事 + 看清规则后再行动"，而不是"先做了再说"
- 关系中倾向"有责任感 + 长期承诺"型，不是"激情冲动型"

---

**成格条件**（三选一）：
- 月支本气为正官（如阳干日主见阴干官 = 阳日主月支正官位）
- 月支藏正官透干，且不被合化
- 月支会成正官局（地支三合或半合成官星五行）

**破格条件**：
- **伤官见官**——天干或地支伤官紧邻正官（除非有印通关）
- 正官被合化为他物（如官星被日主合走改化）
- 正官被冲（紧邻冲 → 严重破，遥冲 → 轻破）
- 正官被劫财夺（命局劫财重 + 正官失制）

**典型组合**：
- 月正官透 + 印护官 + 财生官 = "**官印相生**"或"**财官印三宝**"
- 古典原文（《子平真诠》）："**正官者，月令之正官也，正官无伤为最贵**"

**临界判定**：
- 正官**虽透但坐绝**（如丁火日主月正官壬透坐午）→ 假官格，依旺衰复判
- 正官**与日主太近被合**（如甲日主月支辛官透但与日主邻支合走）→ 看合化方向

**喜忌方向**：
- **喜**：印（化官生身）+ 财（生官）+ 身有根
- **忌**：伤官见官 + 七杀混官（清浊不分）+ 劫财夺财

**现代脱毒意象**：
- 倾向**对制度、规则、权威**有天然亲和——但能否在体制内展开取决于身能否担官 + 大运配合
- 不是"必当官"——是"对秩序结构的心理共振"

**常见误判**：
- ❌ 看到月支正官就立官格——**没查藏干透干 + 是否被合化**
- ❌ 官杀混杂直接说"格不清"——**先看清浊取舍**（去杀留官 vs 去官留杀）

**接口规则**：R1 + R11（用神排除） / R19（调候微调） / R20 v2（冲克破格判定） / R46（合化破格判定）

### 2. 七杀格（偏官格）

#### 古今并陈三段（R62 范式）

**【古意】**
《滴天髓》："七杀者，偏官也，制服为权，不制为祸"。古代命书把七杀视为**凶神之首** —— 主煞气、压力、责任、克身。"无制为祸"、"七杀重身轻夭折"等 —— **封建社会的"凶神"标签化判定**。对女命特别贬抑："七杀混官 = 婚姻反复"等。

**【现代心理解读】**
七杀 = **"内在严师 / 外部权威投射"原型**。它指的不是"凶神来克你"——是命主**内在那个"必须独自面对的审视者"**，是对高压力 / 高责任 / 高强度环境的**天然吸附力**。七杀的能量像**未驯服的野马** —— 用得好是"创业魄力 / 高难度任务执行力"，用不好是"自我攻击 / 慢性焦虑"。Jungian 视角：**七杀是"阴影方向的英雄"原型** —— 你被激活但又害怕的能量。

**【具体场景】**
- 对压力 / 责任 / 高强度环境**结构性敏感** —— 容易感受到也容易吸附
- 在"挑战感强 / 必须独自承担"的工作里反而**有动力**——日常重复型工作消磨
- 内在常有"被审视感 / 自我评判 / 我够不够格"层议题
- 关系层（特别女命）：会被"有压力感 / 有责任感 / 强势责任型"的人激活 —— 不是"必克夫"，是"被这种类型激活后会触发自身的承受 / 较劲模式"

---

**成格条件**：
- 月支本气为七杀
- 月支藏七杀透干 + 身能担
- 月支会成七杀局

**破格条件**：
- 七杀过重无制——身弱杀重无印化、无食制 → 不成"杀格"反成"病"
- 七杀被合化（如乙庚合走七杀）
- 七杀被食神制过头（变成"制杀太过"）

**典型组合**：
- 七杀格三大良性变体：
  - **杀印相生**（详 R55）：杀重 + 印重 + 印化杀 + 印必透 — 古典原文："**必须庚透干头，则庚禄居申**"
  - **食神制杀**（详 R55）：食神重 + 七杀重 + 食神制杀 + 身能担食神
  - **羊刃驾杀**（月刃格变体）：羊刃 + 七杀 → 阳刃驾杀

**临界判定**：
- 杀**重于身**但**无印无食**：是"杀重身轻"破格，**不是**七杀格——按 R55 杀重身轻处理
- 杀**与官混**：先做清浊取舍（详 R56 SOP）

**喜忌方向**：
- **喜**：印（化杀）/ 食神（制杀）/ 比劫（抗杀）
- **忌**：杀再重 + 财（财生杀）+ 印被冲克

**现代脱毒意象**：
- 倾向**对压力、挑战、强对抗环境**有天然吸附力——可以是创业 / 高强度行业 / 军警等
- 不是"煞气重命苦"——是"通过压力激发动力的结构倾向"

**常见误判**：
- ❌ 看到七杀就说"凶"——**七杀有制就是用，无制才是病**
- ❌ "印化杀"和"食制杀"混用——**两者方法论不同**：印化是化解能量、食制是反击对抗

**接口规则**：R23（魁罡冲）/ R31（寄禄判杀力）/ R51（大运流年触发杀的动态）/ R55（复合格局深化）

### 3. 正印格

#### 古今并陈三段（R62 范式）

**【古意】**
《三命通会》："印为父母、为靠山、为学问、为庇护"。古代命书把正印视为"福气之神"——主父母庇护、学业有成、师承贵人、文凭学历。"印星不破 = 一生福禄"等。

**【现代心理解读】**
正印 = **"母性 / 滋养者"原型 + 安全基地**。它指的不是"必有靠山"——是命主**对"被照顾 / 被理解 / 被庇护"的底层需求**。Jungian 视角：正印是命主的**"心理安全基地"**——通过吸收知识 / 师承传承 / 庇护型关系建立自我滋养。强**不是**"福气满满"——是"**有强烈的被滋养需求 + 通过这条通路获得能量**"。如果印过盛 → 反成"过度依赖滋养感"。

**【具体场景】**
- 学习能力 / 吸收能力强 —— 通过书本 / 师承 / 长辈传授获得养分
- 倾向"先理解 + 找老师 + 找权威书"，不是"野路子上来就干"
- 关系中倾向被"有学识 / 有母性感 / 有庇护感"的人激活
- 压力大时会回到"被照顾"模式——找妈 / 找师 / 找权威人物寻求支持

---

**成格条件**：
- 月支本气为正印
- 月支藏正印透干
- 月支会成印局

**破格条件**：
- **财破印**——天干财星紧邻正印（除非有官杀通关）
- 印过盛反成病（详 R55 "印多反忌" 的临界判定）
- 印被冲

**典型组合**：
- 印格 + 官杀生印 = **官印相生**
- 印格 + 比劫帮身 = **印比为用**

**临界判定**：
- 印**虽透但被财紧邻克**：假印格，依实际财印博弈复判
- 印**过盛**（重透 + 多根）+ **身已极强**：才是"印多反忌"——但前提是七杀不重（详 R11 v2 / R55）

**喜忌方向**：
- **喜**：官杀（生印）+ 比劫（帮身）+ 身能担
- **忌**：财破印 + 印再重（身已强情况下）

**现代脱毒意象**：
- 倾向**学习、思考、研究、师承、母性 / 庇护型关系**
- 不是"必有文凭学位"——是"通过吸收知识 / 受庇护成长的结构倾向"

**常见误判**：
- ❌ "印多就是忌"——**先看七杀状况**，杀重时印不是过盛，是化杀的工具
- ❌ 直接套"身弱用印"——**没查印是否被破**

**接口规则**：R11 v2（印多反忌的边界）/ R55（杀印相生 / 财官印三宝）

### 4. 偏印格（枭神格）

#### 古今并陈三段（R62 范式）

**【古意】**
《三命通会》："偏印为枭神，夺食为忌，主孤独 / 早年失恃 / 性情怪异"。"枭神"古名极贬——枭即猫头鹰，古代视为不祥之鸟。偏印格被读为"必克母 / 早年坎坷 / 性格怪僻 / 不能享福"等 —— **封建社会标签化最严重的十神之一**。

**【现代心理解读】**
偏印 = **"非主流智者 / 内在隐者 / 阴影方向的知识"原型**。Jungian 视角：偏印是**"阴影里的智慧"** —— 你学的那些"别人不学的"、知道的那些"别人不知道的"、感兴趣的那些"主流不认的"。**完全不是"凶神"** —— 是命主天然的"跨界学习者 / 非主流研究者 / 神秘学共振者"原型。"枭神夺食"在现代心理学语境就是**"思维过滤器太强，让创造性输出被反复审视"** —— 是张力，不是判决。

**【具体场景】**
- 喜欢学"奇怪的东西"——心理学 / 神秘学 / 跨学科 / 冷门领域
- 思维路径**非线性**——别人 A→B→C，你可能 A→灵感→Z
- 倾向自学 / 野路子 / 跨界吸收 —— 不喜欢"标准教材路径"
- 创造性输出前要先经过"内在审视"层（这就是"枭神夺食"的现代意象）
- 关系中倾向被"有独特视角 / 有非主流知识 / 神秘感"型激活

---

**成格条件**：
- 月支本气为偏印
- 月支藏偏印透干

**破格条件**：
- **偏印夺食**——食神为用时偏印克食（古名"枭神夺食"）
- 偏印被冲、被克

**典型组合**：
- 偏印 + 七杀同透 = 偏印化杀（与正印化杀相似但更直接、能量更"野")
- 偏印 + 财星制偏印 = **财制枭** —— 古典认为偏印格常以财制枭为美

**临界判定**：
- 偏印为用 vs 偏印为忌：身弱 + 杀重 → 偏印为用；身强 + 食神为用 → 偏印为忌（夺食）

**喜忌方向**：
- **喜**（身弱时）：官杀生印 + 偏印化杀
- **喜**（身强时）：财制枭 + 食神泄秀
- **忌**：偏印夺食（除非食神已过盛）

**现代脱毒意象**：
- 倾向**非主流学习、自学、神秘学 / 玄学、独特技能、灵感型思维**
- 偏印 vs 正印的区别：正印是"标准师承"，偏印是"野路子 / 自学成才 / 跨领域"

**常见误判**：
- ❌ 偏印 = 凶——**只在夺食时凶**
- ❌ 看到偏印就说"克母"——**这是命书旧说，现代脱毒禁用此类预测**

**接口规则**：R55（食神制杀 vs 偏印夺食的临界）

### 5. 食神格

#### 古今并陈三段（R62 范式）

**【古意】**

### 6. 伤官格

### 7. 正财格

## 二、化气格（五种合化成局）

> **化气格 = 日主与紧邻天干合化为另一五行**——是罕见但极特殊的命局形态。一旦真化，命局五行属性彻底改变，按"专一行"读，喜忌反转。
> **化气格难真**——多数情况下是"假化"或"合而不化"。**真化要求三严**：化神得月令 + 化神透干旺 + 无破。

### 化气格的通用成格条件

**三严判定**（详 R50 天干五合）：

1. **化神得月令**——月支为化神五行 / 化神的禄旺地 / 化神的长生地
2. **化神透干旺**——化神在天干透出，且根多力强，不被克
3. **无破坏**
   - 合的两干**紧邻**（不能隔字）
   - 没有第三个字争合（妒合）
   - 化神不被原局其他干冲克

**假化的两种情况**：
- **假化得用**：化神虽不真，但化神方向就是命局用神 → 仍按化气格喜忌但减效
- **假化失用**：化神既不真，化神方向也不是用神 → 退回普通命局

### 1. 化木格（丁壬合化木）

#### 古今并陈三段（R62 范式）

**【古意】**
《滴天髓》："丁壬合化木，化神得令则真化，主仁慈、文教、长寿"。古代化木格被读为"君子之命 / 文人之命"。封建语境也称"丁壬合为淫慝之合"——意为感性纠缠 —— **是封建对感性能量的污名化标签**。

**【现代心理解读】**
化木格 = **人格底色的"木性转向"原型**——命主的内核从原日主的属性**转化为木的延展性**。木的现代意象：成长、扩展、仁义、文化、教育、慈悲。"淫慝之合"的现代脱毒 = "**感性 + 情感 + 直觉**层强" —— 不是道德判决，是命主对感性流动的敏感度高。

**【具体场景】**
- 内核是"长期成长 / 扩展 / 不肯折"型
- 在教育 / 文化 / 学术 / 慈善 / 心理 / 跨文化领域结构性匹配
- 决策偏长期视野——不喜欢"短期套利"
- 关系层有"感性 / 直觉 / 心智共振"导向

---

**成格条件**：
- 日主丁，紧邻干（月干或时干）为壬；或日主壬，紧邻干为丁
- 月令为木（寅 / 卯 / 亥即木的长生 / 旺 / 库 / 三合木局成）
- 木气透干 + 无金克木

**破格条件**：
- 月令非木地（如月令是申酉戌金地）→ 化神无根 → 不化
- 命局**庚辛金透干**克木 → 破化
- 第三个丁或壬出现 → 妒合 → 化力大降

**典型组合**：
- 丁壬合化木 + 月令亥卯未三合木局 + 甲乙木透 = 真化木格
- 命主转化为"全木命"——按曲直格类似的喜忌读（详专旺格曲直格）

**喜忌方向**（真化后）：
- **喜**：水（生木）+ 木（同党）+ 火（泄秀木）
- **忌**：金（克木）+ 土（耗木）

**现代脱毒意象**：
- 真化命主**人格底色转向木性**——成长、扩展、仁义、文化、学术、教育、创意
- 化气格命主常有"性格转变期"——化神得运时是命主的真正展开期

**常见误判**：
- ❌ 看到丁壬透就说化木——**月令必须是木地**
- ❌ 假化按真化读——**假化要减效**

**接口规则**：R50（天干五合 + 真化判定流程）/ R47（三合木局支持化神）

## 三、专旺格（五行单一极旺）

> **专旺格 = 命局五行单一极旺 + 日主属于该五行 + 一气不杂**——本质是"日主与命局同党"的极端形态。喜忌**顺其性**——不抗反顺，让单一五行充分展开。
> 五个专旺格分别对应五行：曲直（木）/ 炎上（火）/ 稼穑（土）/ 从革（金）/ 润下（水）。

### 专旺格的通用成格条件

1. **日主属于某五行** —— 如曲直格日主必甲乙木
2. **该五行单一极旺**——满足以下任一：
   - 地支**三合或三会该五行局**（如寅午戌 / 巳午未火局）
   - 该五行**地支占 3 支以上 + 天干透 2 个以上**
   - 月令为该五行**禄旺帝旺地**
3. **无克神** —— 命局没有强力克日主五行的字（克神微弱可忽略）
4. **不杂他气** —— 命局没有显著的他五行干扰

### 专旺格的核心特征

- **本质**："**日主就是命局**"——所有能量集中在一个五行方向
- **喜忌反转**：不要克泄耗（如曲直格忌金克），要顺生顺泄（喜水生木 + 火泄秀）
- **罕见**：真专旺格在实操中很少，多数是假专旺（有微弱克神或杂气）

**现代脱毒意象**：

## 四、从格（日干极弱顺势从他）

> **从格 = 日干极弱无根 + 命局某一行或几行极旺 → 日干不抗反顺，从该旺行**。本质是"日主放弃自己 + 顺势从他"的极端形态。
> 从格的喜忌**与扶抑派完全相反**——身极弱不用印，反而顺势走该旺行的喜忌。
> **从格 vs 假从**：真从必须无根（包括天干印比、地支墓库微根都没有）；假从有微根 → 不能真从，按"身弱"普通命局处理。

### 从格的通用成格条件

1. **日干极弱**——天干无比劫 + 无印；地支无禄、刃、长生（连墓库藏干都不能透出）
2. **某五行或几行极旺**——满足以下任一：
   - 单一五行成局（三合 / 三会）
   - 单一五行**地支占 3 支以上 + 天干透 2 个以上**
   - 多五行混杂但都是**克 / 泄日主**的（从势格）
3. **无救应**——没有任何来救日主的字

### 假从的临界

- 日主有**微根**（如地支墓库藏干透天）→ 不真从
- 处理：仍按身弱普通命局走 R1 + R11（弱身用印 / 用比劫）
- **关键边界**：假从最容易被误判——见到日主弱就说从，是初学者常错

- 日干**极弱到完全顺从克泄耗**
- 是从财 / 从杀 / 从儿 / 从势的统称

**注**：实际操作中常细分为前面四种（从财 / 从杀 / 从儿 / 从势），"从弱格"作为统称使用较少。

### 1. 杀印相生

#### 古今并陈三段（R62 范式）

**【古意】**
《穷通宝鉴》："七杀重 + 印重 + 印化杀 + 印必透干 = 杀印相生格，主大贵"。古代命书把杀印相生读为"贵命之首" —— 主**通过学问 / 师承化解压力 / 走仕途 / 大有成就**。

**【现代心理解读】**
杀印相生 = **"通过吸收 / 学习 / 庇护转化压力"的高级人格组合**。Jungian 视角：命主同时激活了"**内在严师**（七杀）"和"**滋养者母性**（印）"两个原型 —— 印化解杀的张力 → 表现为"**用学习 / 思考 / 内化把压力转化为成长**"的能力。这是"**学者型领导 / 顾问 / 教师 / 高知职业**"的人格底色。

**【具体场景】**
- 在高压力环境中**通过学习 / 思考化解压力** —— 不是回避，是消化
- 学者型领导 / 顾问 / 高知职业 / 转化型管理者
- 关系层倾向"通过共同学习 + 心智成长建立联结"

---

**成格条件**：
- **七杀重**（透干 + 多根 / 月令支持）
- **印重**（透干 + 多根）
- **印化杀**——印贴近七杀，能化解杀气
- **印必透干**（古典关键条件——古书原文"必须庚透干头"）
- 身能担印

**破格条件**：
- **财破印**——天干财紧邻印，财克印 → 印不能化杀 → 破格
- 食神制杀——印化杀和食制杀是两种方法论，混用会乱
- 印被冲克

**典型组合**：
- 古典原文（《穷通宝鉴》论壬水生午月）："**壬日而值戊申时，杀印相生，但月令在午，为戊土之旺气，而申金虽系壬水长生，因受午火威胁，其生水之力以减，必须庚透干头，则庚禄居申**"
- 现代典型：戊七杀透 + 庚金印透 + 壬水日主有根

**临界判定**：
- 杀印**虽具备但印未透**——退回普通命局，按身弱用印处理
- 杀印**具备但被财破**——破格，按身弱被困处理

**喜忌方向**：
- **喜**：印（核心用神，越透越好）+ 比劫帮身担印
- **忌**：财（破印）+ 食伤（制杀过头 / 印被食伤泄）

**现代脱毒意象**：
- 倾向**通过学习 / 师承 / 知识权威化解压力**——通过吸收（印）转化挑战（杀）的能力
- 杀印相生格命主**常显学者 / 顾问 / 高知职业 / 转化型领导**

**常见误判**：
- ❌ 看到印多就说"印多反忌"——**先看七杀状况**（详 R11 v2）
- ❌ 杀印相生不要财——**财来生杀但同时破印 → 必须远离**

**接口规则**：R11 v2（印多反忌的边界）/ R55 中的"杀重身轻"区别 / R51（大运财来破印的触发）

**验证案例**（rules-engine.md R11 v2 已记录）：
- 1994-06-15 宁波男 `甲戌 庚午 壬申 戊申` —— 双申印 + 戊杀透 + 庚透干头 + 壬水有根 = 经典杀印相生格

### 2. 食神制杀

#### 古今并陈三段（R62 范式）

**【古意】**
《子平真诠》："食神制杀，一将当关，万夫莫开"。古代命书读为"贵命" —— 主**用才华 / 表达对抗压力 / 自主成事**。

**【现代心理解读】**
食神制杀 = **"通过创造性输出对抗 / 转化压力"的人格组合**。Jungian 视角：命主同时激活了"**内在严师**（七杀）"和"**创造的孩子**（食神）" —— 用食神的"自然输出"去克制七杀的"压制感"。这是"**技术型 / 艺术型 / 表达型领导**"的人格底色 —— 通过专业能力化解外部对抗，而不是通过吸收（那是杀印相生的方式）。

**【具体场景】**
- 在高压环境中**通过"做出东西 / 输出专业 / 创造产品"应对压力**
- 技术型 / 艺术型 / 表达型领导 —— 用专业说话而不是用职位说话
- 关系层倾向"通过共同创造 + 才华吸引建立联结"

---

**成格条件**：
- **食神重**（透干 + 多根）
- **七杀重**（透干 + 多根）
- **食神制杀**——食神贴近七杀，能克制杀气
- **身能担食神**（食神泄身，身弱则食神反成耗）

**破格条件**：
- **偏印夺食**（枭神夺食）—— 偏印克食神 → 制杀工具被破 → 破格
- 食神被合化
- 七杀过重食神制不住（"制杀不及"）
- 食神过重无杀可制（"制杀太过"）

**典型组合**：
- 古名："**一将当关，万夫莫开**"——食神是制杀的"将"
- 现代典型：庚金食神透 + 乙木七杀透 + 戊土日主有根 + 印不夺食

**临界判定**：
- 食神虽具但身弱——食神不是用而是耗 → 退回身弱用印
- 食神具但杀更重——制杀不及 → 升级为"杀重身轻"或转杀印相生

**喜忌方向**：
- **喜**：食神有根 + 财星泄食神（食生财）+ 身有根
- **忌**：偏印夺食 + 印化杀（与食制杀方法论冲突）+ 食伤过头

**现代脱毒意象**：
- 倾向**通过创造 / 输出 / 技艺对抗压力**——把杀（压力）转化为食神（输出）的产物
- 食制杀格命主**常显技术型 / 艺术型 / 表达型领导**——通过专业能力化解外部对抗

**常见误判**：
- ❌ 食神 + 七杀就说食制杀——**必须身能担食神**
- ❌ 食制杀格喜印——**印夺食是破格**

**接口规则**：R55 中的"食神格 vs 七杀格 vs 食神制杀格"区别 / R51

### 3. 伤官见官

#### 古今并陈三段（R62 范式）

**【古意】**
《三命通会》："伤官见官，祸患百端"。古代命书读为**忌格** —— 主"才华与制度位的剧烈冲突 / 多灾多难 / 仕途受阻"。**对女命特别贬抑**："伤官见官必克夫" —— **封建对"有才华女性 + 不愿守规矩"的双重污名化，严禁使用**。

**【现代心理解读】**
伤官见官 = **"才华型反叛者 + 体制位 = 必然摩擦"的结构性张力**。Jungian 视角：命主同时激活了"**叛逆者**（伤官）"和"**父性秩序**（正官）"两个原型 —— 这两个原型本质相反，不通关就是**持续冲突**；通关（有印通关）就升级为伤官佩印（详 #4）。**对女命**：完全去除"克夫"封建预言 —— 真实结构是"对常规婚姻 / 制度型关系结构敏感、容易看到不合理处" —— 不是凶兆，是"清醒地拒绝不合适的关系"。

**【具体场景】**
- 看到"权威说的不对 / 制度不合理 / 同事在错的方向走"会**本能反应**
- 在严格科层 / 老旧组织中**结构性不舒服**
- 必须**主动找有印通关的环境**（学习导向 / 知识型组织 / 师徒型团队）→ 升级为伤官佩印
- 关系层倾向"互为挑战 / 互为平等"

---

**成格条件 / 性质**：
- 命局同时有**伤官**透 + **正官**透 + 紧邻或同柱

**性质**：**伤官见官**是**忌格**——伤官本性叛逆，见到正官就要冲克，造成命局张力 / 摩擦。古典认为"伤官见官，祸患百端"。

**例外（升级为良性变体）**：

- **伤官佩印**：伤官见官 + 有**印通关**（印克伤官 + 印生官）→ 良性结构（详下方）
- **伤官伤尽**：伤官重 + 官全无 → 单纯走伤官路线，反而清

**破格条件 vs 修复**：
- **无印通关 + 伤官官同透紧邻** → 严重破格（无救）
- **印透干通关** → 升级为伤官佩印

**典型组合**（破格版本）：
- 丙日 + 月伤官己土透 + 时正官癸水透 + 无印 + 紧邻 = 典型伤官见官败格

**喜忌方向**（破格状态）：
- **喜**：印（救——通过通关变成伤官佩印）+ 食神（吸收伤官能量）
- **忌**：再加官 / 再加伤官 / 财（财生官加重冲突）

**现代脱毒意象**：
- 破格倾向**与权威 / 制度持续摩擦** —— 不是预测"必失业"，是结构上"不容易在体制内顺展开"
- 升级后倾向"**有特殊才华但需要合适表达通道**"

**常见误判**：
- ❌ 看到伤官见官就说凶——**没查印是否能通关**
- ❌ "女命伤官见官克夫"—— **封建命书旧说，严格禁用**

**接口规则**：R56（清浊取舍）/ R55 伤官佩印 / R52（子平 vs 盲派对伤官读法的分歧）

### 4. 伤官佩印

#### 古今并陈三段（R62 范式）

**【古意】**
《滴天髓》："伤官佩印，富贵双全"。古代命书读为**贵命** —— 主"才华有承载 / 学者型创意人 / 才情兼备"。

**【现代心理解读】**
伤官佩印 = **"叛逆才华 + 学识庇护"的最优组合**。Jungian 视角：命主同时激活了"**叛逆者**（伤官）"和"**滋养者**（印）"—— 印克伤官但同时护身 → 表现为"**才华有学识做基础 / 突破有理论做支撑**"。这是"**学者型创意人 / 高知艺术家 / 跨界专家**"的人格底色。

**【具体场景】**
- 才华有"理论基础 + 学识深度" —— 不是野路子型创意人
- 在创意 + 学术结合的领域（科研、学术写作、文化评论、跨界研究）结构性发光
- 关系层倾向"知识 + 才华双重共振"

---

**成格条件**：
- **伤官重**（透干 + 多根）
- **正印重**（透干 + 多根）
- **印克伤官 + 印护身**——印能克伤官避免伤官过泄，同时印能护身
- 身能担印

**破格条件**：
- 财破印——财来克印 → 伤官失制
- 印太重——印多反成忌（详 R11 v2 边界）

**典型组合**：
- 甲日 + 月伤官丁火透 + 印壬水透 + 通根 + 财远离 = 伤官佩印良性结构
- 古名："**伤官佩印，富贵双全**"——伤官的才华 + 印的稳定 → 才华有承载

**临界判定**：
- 伤官见官 → 加印 → 是伤官佩印还是仍是伤官见官？看印是否能同时克伤护身

**喜忌方向**：
- **喜**：印（核心）+ 比劫帮身担印
- **忌**：财（破印）+ 再加伤官（过泄）

**现代脱毒意象**：
- 倾向**才华型职业**——创造力（伤官）+ 学习庇护（印）的双重支撑
- 伤官佩印格命主**常显学者型创意人 / 高知艺术家 / 跨界专家**

**常见误判**：
- ❌ 伤官+印就说伤官佩印——**必须身能担 + 印能克伤护身**
- ❌ 伤官佩印 = 必富贵——**结构倾向不是事件预测**

**接口规则**：R55 中其他复合格局 / R11 v2

### 5. 财官印三宝

#### 古今并陈三段（R62 范式）

**【古意】**
《子平真诠》："财官印三宝，文武双全"。古代命书读为**最贵命格之一** —— 主"综合发展 / 富贵双全 / 大事业"。

**【现代心理解读】**
财官印三宝 = **"三大资源原型相生相成"的最优组合**。Jungian 视角：命主同时激活了"**资源**（财）"、"**秩序**（官）"、"**学识**（印）"三个原型，三者相生（财生官 + 官生印 + 印生身）形成**完整的支持链**。这是"**综合发展 / 多领域协同 / 稳定大事业**"的人格底色。

**【具体场景】**
- 不依赖单一能量源 —— 资源、权位、学识都有结构支撑
- 适合"综合管理 / 跨领域协调 / 战略型角色"
- 长期发展稳定 + 厚度足

---

**成格条件**：
- **正财透干通根**
- **正官透干通根**
- **正印透干通根**
- 三者**相生相成**：财生官 + 官生印 + 印生身
- 身能担

**破格条件**：
- 任一星被冲克 → 链条断
- 财印紧邻冲突（财克印）→ 链条乱

**典型组合**：
- 古名："**财官印三宝，文武双全**"——子平真诠经典良性结构
- 现代典型：日主身有根 + 月正财透 + 时正官透 + 年正印透 + 三者不互冲

**临界判定**：
- 三宝俱全但**财印紧邻**——清浊不分 → 看是否能用官通关
- 三宝俱全但**身极弱**——担不动 → 退回身弱

**喜忌方向**：
- **喜**：身有根 + 三宝俱全不破 + 大运配合
- **忌**：任一星被克 / 被合化

**现代脱毒意象**：
- 倾向**结构性贵气**——资源（财）+ 权威（官）+ 学识（印）+ 身能担 = 综合支撑
- 财官印三宝格命主**常显综合发展 / 多领域协同 / 稳定大事业**

**常见误判**：
- ❌ 三宝就是必大贵——**结构倾向，仍需大运 + 反身性选择展开**

**接口规则**：R56（清浊取舍 — 财印紧邻的处理）

### 6. 杀重身轻

#### 古今并陈三段（R62 范式）

**【古意】**
《三命通会》："杀重身轻，终是夭折之命"等。古代命书对杀重身轻读为**败格 / 凶兆** —— 主"被压力击垮 / 多灾多难 / 命途坎坷"。**封建语境的判决式预言，严禁直接套用**。

**【现代心理解读】**
杀重身轻 = **"压力源大于承载力"的结构性临界**。Jungian 视角：命主"**内在严师**（七杀）"原型过强，"**自我主体**（日主）"承载力不足 —— 表现为"长期感受到外部压力 + 内在资源不够应对"。**这不是"凶命预言"，是"修复点提醒"**：
- 加印 → 升级为杀印相生（用学习修复）
- 加食神 → 升级为食神制杀（用创造修复）
- 加比劫 → 抗杀但需谨慎
- 完全无救 → 走"接受压力 / 顺势"的从杀路径

**【具体场景】**
- 长期感受到"被压制 / 被审视 / 不够格"
- 在高压环境中**结构性承受力较弱** —— 需要外部支持系统（师承、学习社群、心理支持）
- 关键：**这是修复型命局** —— 通过主动建立支持系统能转化结构

---

**成格条件 / 性质**：
- **七杀重**（透干 + 多根 + 月令支持）
- **身偏弱**（日主无强根 / 比劫少 / 印缺）
- **无救应**（既无印化杀，也无食制杀，也无比抗杀）

**性质**：**杀重身轻**是**破格**或**败格**——命局有"被压制"的结构倾向。

**修复条件 vs 退路**：
- **加印** → 升级为杀印相生（详 #1）
- **加食神** → 升级为食神制杀（详 #2）
- **加比劫** → 抗杀但需谨慎（比劫帮身但耗财）
- **完全无救** → 走"接受压力 / 顺势"路线，类似从杀格但不真从

**典型组合**：
- 日主无根 + 月时七杀透 + 杀坐禄 + 无印无食无比劫 = 典型杀重身轻

**喜忌方向**：
- **喜**：印（化杀 + 护身）+ 比劫（抗杀，但勿过强）+ 食神（制杀，但需身能担）
- **忌**：财（生杀加重）+ 再加杀

**现代脱毒意象**：
- 倾向**长期承受压力**——不是预测"必失败"，是结构上"在高压环境中需要特殊修复机制"
- 杀重身轻命主**常需要外部支持（学习 / 师承 / 团队）作为修复点**

**常见误判**：
- ❌ 杀重身轻 = 注定凶——**结构倾向，可通过印 / 食 / 比修复**
- ❌ 把杀重身轻误判为从杀——**关键看日主是否真无根**

**接口规则**：R55 杀印相生 / R55 食神制杀 / R51 大运补救的机制

## 六、魁罡格（指针 R23）

## 七、杂格附录（争议大，临界使用）

> **以下杂格在古典命书（《三命通会》《滴天髓》等）中有记载，但现代命理实操中争议较大、误判率高**。
> 议会立场：**仅作"额外信号"使用，不作主格局判定**。任何杂格判断都不应覆盖正格 / 化气 / 专旺 / 从格 / 复合的主结构识别。

**通用警示**：
- ❌ 不要见到杂格表面条件就直接判格
- ❌ 不要用杂格做事件预测（如"金神格主立功封爵"）
- ✓ 杂格作为"命局有特殊倾向"的额外说明 —— 永远配合主格走

---

### 1. 飞天禄马（暗冲格）

**简述**：日主与月支或时支某字组合，**暗冲**出隐藏的禄或马（驿马）。

**举例**：庚日见多个子（子暗冲午，午中有丁正官）→ "暗合官星"

**议会立场**：极少独立成格——多数情况下是主格的"附加信号"。**禁用单独判贵贱**。

---

### 2. 拱禄拱贵

**简述**：两支之间**隔字拱出**日主的禄或贵人。

**举例**：日柱甲寅 + 时柱甲辰 → 寅辰之间拱出"卯"（甲禄）

**议会立场**：拱合在 R47 已有完整处理。**杂格中的"拱禄"判定与 R47 重叠**——建议走 R47 拱合的标准判定，不另立杂格。

---

### 3. 金神格

**简述**：日柱时柱见**乙丑、己巳、癸酉**（古名"金神三日"）+ 命局有制（火制金神）。

**议会立场**：古典认为"金神主刚毅 + 建功立业"。现代命理对金神格的判定标准不一，**议会暂不纳入主判定**。

---

### 4. 井栏叉格

**简述**：庚日生 + 地支**申子辰**三合水局 + 时柱见井栏字。

**议会立场**：与从格、专旺格高度重叠——按从格 / 专旺处理更安全。

---

### 5. 倒冲格 / 朝阳格 / 其他

**简述**：通过特殊地支组合"冲出"虚字、"朝向"特定方位等的杂格集合。

**议会立场**：**统一不纳入主判定**——这些杂格在《三命通会》中数量极多（数十种），但现代实操经验显示误判率高、与主结构判定容易冲突。如有命主自行了解过相关杂格，可作为补充讨论，但不作议会主断。

### 关键决策点

#### 决策点 1：特殊格局 vs 月令正格

**判据**：
- **极端命局**（一气专旺 / 极弱无根 / 真化）→ 特殊格局
- **一般命局**（多种五行 + 日主有根）→ 月令正格

**误判预防**：
- 真专旺 vs 假专旺（有微弱克神时是假）
- 真从 vs 假从（日主有微根时是假）
- 真化 vs 合而不化（化神不得月令时是假）

#### 决策点 2：单一正格 vs 复合格局

**判据**：
- **月令正格 + 另一十神同等突出** → 检查是否构成复合格局
- **月令正格 + 其他十神都弱** → 走单一月令正格

**例**：月令正官透 + 印也透通根 → 不是单纯正官格，而是"官印相生"复合

#### 决策点 3：清浊取舍

**当命局喜神 + 忌神同透时**，必须做清浊取舍：

| 场景 | 取舍方向 | 判据 |
|---|---|---|
| **官杀混杂** | 去杀留官 vs 去官留杀 | 看哪个更突出 + 月令支持哪个 |
| **食伤混杂** | 留食伤秀气，去抑制者 | 看哪个能担当用神 |
| **印枭混杂** | 留正印 vs 留偏印 | 看与日主搭配 |
| **财劫混战** | 用官杀制劫保财 | 看官杀位置 |

#### 决策点 4：调候何时升一级（R19）

**调候升一级条件**：
- 月令气候**极端**：大寒（亥子丑月）/ 大热（巳午未月）/ 极燥（戌月燥土）/ 极湿（辰丑月湿土）
- 命局缺**修正气候的五行**（如夏月命局无水）

**调候 vs 格局喜忌冲突时**：调候**优先**（详 R19）

#### 决策点 5：破格的修复可能性

**判据**（详九章详细总论）：
- **能修**：破格点有救应字（如财破印有官通关）→ 格损不破
- **不能修**：破格点孤立无救 → 退回普通命局

## 九、破格条件总论

### 破格的统一判定原则

**破格不是"格局完全失效"，而是"格局的关键支撑被攻击"**——通常分四类：

#### A. 冲破

**判据**：月令支或关键透干支被紧邻冲

| 冲的位置 | 严重度 |
|---|:-:|
| 月日冲（核心位置）| ★★★ 严重 |
| 月时冲 / 年月冲 | ★★ 中度 |
| 年时冲（遥冲）| ★ 轻度 |

**修复**：
- 合解冲（详 R51）→ 部分修复
- 通关五行（如金克木有水通关）→ 部分修复

#### B. 合化破

**判据**：关键透干被合化为他物

**修复**：
- 化神方向就是格局喜神 → 不算破，反成助力（如官星被合化为印星，若印星是用 → 不破）
- 化神方向是忌神 → 严重破

#### C. 克破

**判据**：关键透干被紧邻克

**修复**：
- 有印通关 → 部分修复
- 克神远离 → 减效

#### D. 混杂（清浊不分）

**判据**：格局喜神 + 忌神同透紧邻

**修复**：清浊取舍（详上 SOP 决策点 3）

### 破格修复的等级

| 等级 | 判定 | 处理 |
|---|---|---|
| **成格** | 破格点全无 | 走该格喜忌 |
| **格损不破** | 破格点有救应 | 走该格喜忌 + 警惕修复点 |
| **败格** | 破格点无救但格局基本结构仍在 | 走该格喜忌 + 重大减效 |
| **破格** | 破格点无救且格局基本结构崩塌 | 退回普通命局，走 R1 + R11 |

### 子平 vs 盲派对破格的分歧（详 R52）

| 维度 | 子平 | 盲派 |
|---|---|---|
| 破格判定 | 严判，三破即不成格 | 灵活，结构倾向仍有效 |
| 修复要求 | 救应必须紧邻 | 看做功路径整体 |
| 临界处理 | 退回普通命局 | 仍部分按格读 |

**议会立场**：**两派并陈**——子平严判用于"格成不成"的二元决策；盲派灵活用于"结构倾向"的连续描述。
